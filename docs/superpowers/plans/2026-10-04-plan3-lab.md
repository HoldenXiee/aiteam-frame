# 实验室（Lab）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 把 aiteam 的唯一创建入口从顶层 `createAgent(spec)` 换成 `createLab(opts)` 返回的实验室对象——由实验室持有环境，agent 必须加入实验室、由实验室启动。

**架构：** 新增 `src/agent/lab.ts`。实验室持有环境（`agentDir` / `cwd` / 模型目录开关，**两个目录必填** = 缺省拒绝），对外只有 `agentDir`、`cwd`、`createAgent(spec)`、`inspectEnv()` 四个成员。实例 spec 只留「用哪些」：角色、技能、插件、模型、思考档、自定义工具、权限、上下文默认；`agentDir` / `cwd` / `modelNetwork` / `catalogBaseUrl` 移出 spec，只有实验室能声明。顶层 `createAgent` 与 `inspectEnv` 不再导出。

**技术栈：** TypeScript（无构建，直接 `node` 跑 `.ts`）、`node:test`、pi SDK 0.99.1、本机假 provider（零 API 成本）

**规格：** [`docs/DESIGN.md`](../../DESIGN.md)（手写版，唯一设计源）+ [`docs/DESIGN-解读.md`](../../DESIGN-解读.md) §3.6（实验室的转写与四条答复）。执行者两份都读。

## 全局约束

- 不新增依赖，不加构建步骤：`package.json` 不动。
- 全部测试走本机假 provider；`PI_OFFLINE=1` 钉死；零 API 成本。
- **库不含任何策略**：实验室只持有环境。不持花名册、不持护栏、**不做生命周期管理**（`lab.dispose()` / `lab.list()` 已明确封存，本计划不实现，也不预留字段）。
- `agentDir` / `cwd` **必填**；缺省一律拒绝。不保留任何「静默回落宿主目录」的路径：`defaultAgentDir()` 与 `AITEAM_AGENT_DIR` 一并删除。
- **不做宿主目录禁令**：`agentDir` 恰好等于 `~/.pi/agent` 时本计划不抛错（Q5 只定到「缺省拒绝」）。这条按登记处理，见「交接」。
- 类型名：`AgentInit` → `AgentSpec`（环境字段移出，改名让断裂显式）。
- 文案与注释用中文，与现有代码一致。不写「TODO」「待定」「处理边界情况」。
- 每个任务结束时：`npm run typecheck` 无输出，且 `npm test` 全绿。

## 审查重点（Review Focus）

1. `agentDir` 传的是空串 `""`（不是 `undefined`）→ 必填校验必须把空串当缺失。测试见任务 1 步骤 1。
2. `cwd` 指向不存在的目录 → 必须当场显式报错，不能让 pi 在后面某个时刻静默失败。测试见任务 1 步骤 1。
3. 两个实验室用同一个 `agentDir` → 必须共用同一份 modelRuntime（`getSharedRuntime` 按 `agentDir`+网络开关缓存）。测试见任务 1 步骤 1。
4. `lab.createAgent()` 不传 spec → 必须能起（spec 全可选）。测试见任务 1 步骤 1。
5. `docs/` 与 `AGENTS.md` 里还留着旧的 `createAgent({...})` 片段 → 读者照抄编译不过。检查见任务 4 步骤 3。

```ts
// test/lab.test.ts
import { test } from "node:test";
import assert from "node:assert/strict";
import { createLab } from "../src/agent/lab.ts";
import { getSharedRuntime } from "../src/agent/create-agent.ts";
import { fauxAgentDir, fauxCwd, FAUX_MODEL_REF } from "./helpers.ts";

test("实验室必填两个目录：缺失与空串都拒绝", async () => {
  await assert.rejects(() => createLab({ cwd: fauxCwd } as never), /agentDir/);
  await assert.rejects(() => createLab({ agentDir: fauxAgentDir } as never), /cwd/);
  await assert.rejects(() => createLab({ agentDir: "", cwd: fauxCwd }), /agentDir/);
  await assert.rejects(() => createLab({ agentDir: fauxAgentDir, cwd: "" }), /cwd/);
});

test("cwd 不存在时当场报错", async () => {
  await assert.rejects(
    () => createLab({ agentDir: fauxAgentDir, cwd: join(fauxCwd, "no-such-dir"), modelNetwork: false }),
    /不存在|cwd/,
  );
});

test("lab.createAgent 不传 spec 也能起，且真的能跑一轮", async () => {
  const lab = await createLab({ agentDir: fauxAgentDir, cwd: fauxCwd, modelNetwork: false });
  const a = await lab.createAgent();
  const r = await a.io.prompt("说一句话");
  assert.ok(r.text.length > 0);
  a.dispose();
});

test("同一个 agentDir 的两个实验室共用同一份 modelRuntime", async () => {
  const opts = { modelNetwork: false } as const;
  const lab = await createLab({ agentDir: fauxAgentDir, cwd: fauxCwd, ...opts });
  assert.equal(
    await lab.modelRuntimeForTest(),
    await getSharedRuntime(fauxAgentDir, opts),
    "实验室必须复用宿主级共享 runtime，不能自己另建一份",
  );
});

test("lab.inspectEnv 只读报告这个实验室的环境", async () => {
  const lab = await createLab({ agentDir: fauxAgentDir, cwd: fauxCwd, modelNetwork: false });
  const report = await lab.inspectEnv();
  assert.equal(report.agentDir, fauxAgentDir);
  assert.equal(report.cwd, fauxCwd);
});
```

- [ ] **步骤 3：实现 `src/agent/lab.ts`**

签名必须逐字如下：

```ts
import type { ModelRuntime } from "@earendil-works/pi-coding-agent";
import type { Agent, AgentSpec } from "./types.ts";
import type { EnvReport } from "./env.ts";

export interface LabOptions {
  /** 环境目录：凭证(auth.json)、模型目录(models.json)、技能、插件、SYSTEM.md 都从这里找。必填 */
  agentDir: string;
  /** 工作目录：这个实验室启动的全部 agent 共用。必填 */
  cwd: string;
  /** 模型目录是否联网刷新，默认 true */
  modelNetwork?: boolean;
  /** 覆盖模型目录源，默认 https://pi.dev */
  catalogBaseUrl?: string;
  /** 直接注入 modelRuntime（测试 / 高级用）；不传就走宿主级共享的那个 */
  modelRuntime?: ModelRuntime;
}

export interface Lab {
  readonly agentDir: string;
  readonly cwd: string;
  createAgent(spec?: AgentSpec): Promise<Agent>;
  inspectEnv(): Promise<EnvReport>;
}

export async function createLab(opts: LabOptions): Promise<Lab>;
```

实现要点（函数体由实现者写，这里只钉住决定不了的部分）：

- 必填校验在**最前面**，`undefined` 与空串一视同仁，错误文案里必须出现字段名（`agentDir` / `cwd`）。
- `cwd` 必须当场检查存在性（`existsSync`），不存在就抛，文案含 `cwd` 与该路径。
- runtime 走 `getSharedRuntime(agentDir, { modelNetwork, catalogBaseUrl })`；`opts.modelRuntime` 优先。**不要**自己 new 一个 runtime。
- `createAgent(spec)` 转调现有的 `createAgent({ agentDir, cwd, modelNetwork, catalogBaseUrl, ...spec })`（本任务阶段两者并存）。
- `inspectEnv()` 转调现有的 `inspectEnv({ agentDir, cwd, modelNetwork, catalogBaseUrl })`。
- `modelRuntimeForTest()`：返回步骤 3 里拿到的那份 runtime 引用。它是**测试探针**，在 `Lab` 接口上用 `/** @internal 仅供测试断言 runtime 复用 */` 注明。
