# viz-ui · hunt 研究数据可视化

离线单页。**一个文件**（`dist/index.html`）打开后用「选择 hunt.json」载入数据；
数据由仓库里的导出器生成，页面**不联网、不改数据、不自己编数字**。

```
可视化数据生成.cmd
   ├─ ① npx tsx research/clusters/micro/vizdata.ts   →  data/hunt.json（约 3.8MB）
   ├─ ② npm run build（首次会 npm install）            →  dist/index.html（约 180KB，自包含）
   └─ ③ 打开 dist/index.html
        └─ 页面里选（或拖入）data/hunt.json
```

## 五个页签

| 页签 | 看什么 |
|---|---|
| **时间轴** | 项目泳道（颜色=活/挂起/死，橙圈=判「补的」）+ 运行/产物/争辩三条车道。默认 24 小时，5 档窗口，拖图面平移；**同一位置的点聚成带数字的圆**，点它放大到那一刻 |
| **实验** | 表格 ⇄ 卡片两种形态；搜 claim/现象/预期，按项目/结局/判决筛；点一行开抽屉 |
| **产物** | 485 份产物全文，可搜；右侧读原文 |
| **争辩** | 270 次挑战（谁→谁、判决）+ 16 段长文辩论 |
| **账本** | 数据来源与条数、成本（★ 分成"有金额"与"明说未声明"两栏）、每小时事件数、出生封口、库修订漂移、勘误、外部材料 |

抽屉里是**实验内部**：载体目录 / 真跑的命令 / 真实输出（可展开）/ 退出码 / 耗时 / 对照 / PREREG 是否早于执行 / 预期在 PREREG 第几行命中 / 现象 / 同侪判决 / 猜想状态 / 来源。

## 开发

```bash
cd viz-ui
npm install
npm run dev        # 开发服务器（此时可用 ?data=../data/hunt.json 自动载入）
npm run build      # 产出单文件 dist/index.html
npm run typecheck
```

## 设计约定（改之前先看）

- 视觉规范写在 `DESIGN.md` §4；验收用 `npx impeccable detect`（当前 5 个页签 **0 条**）。
- **不引入图表库**：时间轴是手写 SVG —— 少一层依赖，也少一堆默认丑样式。
- **不做内容判断**：结局/判决/现象全部照抄账本；页面只负责摆出来。
- 数据契约在 `src/types.ts`，与 `research/clusters/micro/vizdata.ts` 一一对应；
  改字段必须两边同改并把 `SCHEMA` 加一（载入时会校验，版本不符直接报错，不静默）。
- ★ 三个"静默坏掉"的坑写在 `scripts/inline.mjs` 注释里（`$&` 替换坑、脚本位置坑、`</script>` 截断坑），
  每个都配了显式检查 —— 因为它们的表现都是**白屏**，不报错。

## 已知边界

1. 产物用文件 mtime 当时间：那是"最后一次被写"，不是"第一次出现"。
2. 成本只有心跳里 6 行、其中 1 行有金额 —— 页面照实说"只能算 1/6 行"，不补也不猜。
3. 拓扑事件只有 593 条（旧日志被清过），所以"每小时事件数"只覆盖有日志的那几小时。
4. `file://` 下不能自动 fetch 本地文件（浏览器同源策略）⇒ 必须手动选一次文件。
