**实现时踩到三个「静默白屏」**（都写进了 `scripts/inline.mjs` 的注释与检查）：
① `String.replace` 替换串里的 `$&` 被当成特殊序列 ⇒ 原标签又插回去；
② 内联脚本留在 `<head>` ⇒ `type="module"` 原本延迟、内联后同步执行，`#root` 还没解析（React #299）；
③ 包内若含 `</script>` 字面量会把脚本截断。
★★ 共同点：**页面全白、控制台几乎没提示** —— 所以每条都配了显式断言，宁可构建失败，不要"看起来成功"。

## 1. 旧图为什么"没法分析"（不是审美问题）

| 病 | 证据 |
|---|---|
| **只画了"活动"，没画"研究"** | 旧图能答"谁跟谁说话、规则触发几次"，答不了"这条实验在测什么、测出了什么" |
| **实验内部完全没有** | 你点出的那条：只有产物/争辩的计数曲线，**没有载体跑的命令、输出、退出码、耗时** |
| **一张图塞四件事** | 泳道 + 产物 + 争辩 + 轴标全挤在一屏，元素上千 ⇒ 什么都在、什么都看不清 |
| **视觉像"AI 默认稿"** | 深底 + 荧光青 + 圆角小卡 + 满屏等距网格 —— 正是 impeccable 的 `dark-glow` / `ai-color-palette` / `nested-cards` / `monotonous-spacing` 那几条 |

★★ 关键判断：**不是"换库重画"，是换信息结构** —— 谁在屏幕上、一次显示多少、点下去看什么。

## 2. 数据契约（这是前端唯一依赖，冻结后可离线重放历史）

`npx tsx research/clusters/micro/vizdata.ts [--out=路径]` → 一个自包含 JSON。

```
meta     生成时刻 / 实验室路径 / 各类条数 / ★ 缺账清单（缺的格子不画 0，画「没记」）
span     全局时间跨度
experiments[134]  ★ 全部 27 个字段，重点是内部：
   claim · killCondition · expected(+expectedAtLine) · prereg(+preregBeforeRun) ·
   carriers[ { dir, cmd, exit, out(真实输出全文), outLines, ranAt, ms } ] ·
   control{dir,cmd,exit,at} · phenomenon · verdict · reviewedBy/reviewNote ·
   conjecture/conjectureState/conjectureEvidence · source · externalCheck · outcome
runs[102]        真跑的命令 + 耗时（port.jsonl，★ 唯一带 ms 的账）
seals[37]        出生封口：PREREG/驱动/判据 sha、窗口两端、写了几行
challenges[270]  谁挑战谁、判决（真意外/补的/…）
debates[16]      长文辩论（整段 text）
errata[6]        勘误（哪份产物哪一格的数是错的）
products[485]    产物**全文** + 它引用了哪些 E 号
external[1]      设计者投递的网上文章（输入，不是产出）
librev[188]      集群自己那份 lib 的修订指纹（漂移）
cost[]           心跳里的成本行（原文 + 解出的 token/$）
events[]         拓扑事件（规则触发 / 工具调用 / 派活）
```

★ 三条纪律写在生成器里：**缺数据 ≠ 0**（`warn` + 「没记」徽标）；**时区统一本地毫秒**；
**dist 离线可用**（数据是外部文件，页面从不联网）。

## 3. 三个页签 + 一个抽屉（信息层级）

### 3.1 时间轴（第一屏 · 默认打开）

```
┌ hunt 研究时间轴                                                   [载入数据] ┐
│ 跨度 10-19 01:01 → 10-28 07:53 · 134 实验 · 268 次运行      [全部|7天|24h|6h] │
├───────────────────────────────────────────────────────────────────────────┤
│  10-26 12:00        10-27 00:00        10-27 12:00        10-28 00:00      │
│                                                                            │
│  X2-HO  61 ─────●───────●───●(死)──────●────────●──────●                   │
│  X2-IS  29 ───────●───────●───●───────●─────●(挂)                          │
│  X1     16 ──────────────●(死)──────●────────●                             │
│  …（每个项目一行，行高 56px，只有圆点，不放文字）                            │
│                                                                            │
│  运行 ──────────▬▬▬────▬─▬▬▬──────▬▬▬▬─────▬──▬▬     ← 载体真跑（长度=耗时）│
│  产物 ──▏▏▏▏─▏▏▏─▏▏▏▏▏▏▏▏──▏▏▏▏▏▏▏▏▏▏▏▏─▏▏▏▏▏▏                          │
│  争辩 ──────▪▪▪▪────▪▪▪▪▪▪──────▪▪▪▪▪▪▪▪──▪▪▪▪                            │
└───────────────────────────────────────────────────────────────────────────┘
   点任意元素 → 右侧抽屉（不遮挡时间轴，时间轴整体左缩）
```

**低密度靠这五件事**（不是靠删数据）：
1. **只有点/条，行内不放任何文字**；文字只出现在轴标和抽屉里；
2. **默认窗口 = 最近 24 小时**（24h 大约 40–60 个元素，一屏看得完），要看全程点「全部」；
3. **行高 56px、上下留白、无网格线**（只有一条基线 + 每日分隔虚竖线）；
4. **颜色只表示三态**：活 / 挂起 / 死（+ 橙圈 = 判「补的」），不再给每个项目配色；
5. 缩放是**离散档位**（全部 / 7 天 / 24h / 6h / 1h），不做自由滚轮 —— 自由缩放让人一进来就迷路。

### 3.2 实验（可分析的"表"，不是卡）

一行一条实验，**行高 44px**，三列：`E134 · X2-IS · claim 前 60 字 · 结局 · 判决`。点击行 → 同一个抽屉。
顶部一行筛选：项目 / 结局 / 判决（真意外·补的·未审）/ 只看有输出的。

> 为什么不是卡片流：134 张卡一屏只能放 6 张，且卡内字段不等长 ⇒ 扫不住。
> 表格能一眼比较，抽屉负责"看清一条"。

## 4. 视觉规范（按 impeccable 的 62 条反模式清单写，不靠"我觉得好看"）

| 维度 | 定什么 | 为什么（对应规则） |
|---|---|---|
| 底色 | **纸白** `#fbfaf7`，正文墨黑 `#1b1a17` | 不用深底荧光（`dark-glow` / `ai-color-palette`） |
| 强调色 | 一个 **深青** `#0f6b5f`（活）+ **赭红** `#b3261e`（死）+ **琥珀** `#9a6b00`（挂起） | 三态一色，不搞渐变 |
| 字体 | 标题 `Georgia, "Noto Serif SC", serif`；正文 `system-ui, "Microsoft YaHei"`；数字/输出 `Consolas, "Cascadia Mono"` | 避开 `overused-font`（Inter/Roboto/Geist…） |
| 字号 | 正文 15px / 次 13px / 标签 12px 起（**不再往下**） | `tiny-text` / `undersized-ui-text` |
| 行高 | 正文 1.65 | `tight-leading` 反面 |
| 疏密 | 区块间距 24/40px 两级，**不用 8px 等距铺满** | `monotonous-spacing` |
| 卡片 | 只用**一层**：内容区直接落在纸面上，用 1px 细线分区 | `nested-cards` |
| 边框 | 不用「一侧粗色条」 | `side-tab`（最典型的 AI 味） |
| 动效 | 只做 **120ms 的抽屉滑入**，无常驻脉冲/光晕 | `pulsing-dot` / `radial-halo` |
| 明暗 | 只做**一套**（浅色），不做主题切换 | 少即是多 |

★ 验收：`npx impeccable detect viz-ui/src` 必须 **0 条**（这是机器判据，不是我说了算）。

## 5. 交互与工程

| 项 | 定 |
|---|---|
| 打开方式 | 双击 `viz-ui/dist/index.html`（`base:'./'`，file:// 可用） |
| 载入数据 | 首屏一个大按钮「选择 hunt.json」+ **整个窗口可拖入**；也可 `?data=` 走相对路径（本地服务时用） |
| 记住上次 | `localStorage` 只记**文件名与条数**，不存内容（6.5MB 不进 localStorage） |
| 空/坏数据 | 明确说「这个文件不是 vizdata.ts 导出的（缺 meta.counts）」，不白屏 |
| 依赖 | React 18 + Vite 5，**零 UI 库、零图表库**（SVG 手写：少一层依赖、少一堆默认丑样式） |
| 打包 | `npm run build` → `viz-ui/dist/`（~200KB），`node_modules/`/`data/` 进 .gitignore |
| 生成命令 | `可视化数据生成.cmd` = ①跑 `vizdata.ts` ②打印路径与条数 ③打开 `dist/index.html` |

## 6. 我不做的事（边界）

1. **不替你决定"研究什么问题"** —— 只把数据摆全（你的原话）。
2. **不判"这条实验好不好"** —— 结局/判决字段照抄账本，前端不做二次判定。
3. **不引入"AI 摘要"** —— 你分析的是原始 claim/输出/现象，不是我的转述。
4. **不动集群代码** —— 这次只加 `vizdata.ts`（只读账本）与 `viz-ui/`。
