# env-style —— 报告写作规范

这是**这个 agentDir 里自动发现**的技能，只有这个环境有。

写报告小节时遵守：

1. 每个小节标题以 `## ` 开头；
2. 每个小节末尾单独一行 `依据：C1、C2`（列出该小节引用的语料 id）；
3. 不要编造语料里没有的 id。

**要检验它有没有生效**：删掉这个文件再跑，报告小节末尾的「依据：」那行就没有了——
技能是**软约束**（靠模型读了照做），不是代码强制的。
