## 1. 定义：读数是一个投影，不是一份抄写

**定义 1（读法 `u`）** 一个读法是把产物映射成一串断言的纯函数。它由两条规则组成：
- **地址规则**：哪些位置算断言（顶层 `findings[]`？任何“元素是对象的数组”？`pair/notes/ids` 这类显式键？）；
- **取证规则**：一条断言的 id / 引文从哪里取（只从值里取？也从键里取？只取恰好两个 id 的条目？）。

**定义 2（量具差 `Δ`）** 同一份产物、同一批运行，两个读法 `u₁,u₂` 给出的读数之差：`Δ = R(u₁) − R(u₂)`。
★ 我把 `R(u₁)` 取成书里现在用的 `judge`，`R(u₂)` 取成**结构无关投影**（定义见下）。`Δ` 不是噪声，它是一个可复算的量。

**定义 3（结构无关投影 `P`，两个档）**
- `P2`：产物里**任意子树**（对象或数组，不限深度）恰好出现两个 note id ⇒ 认为这一对在该产物里被说出；
- `Ppin`：在上面条件下，再要求该子树里的字符串能**唯一定位到真值那两行**（复用 `pinSet`）。
`P` 不用 `findings`、不用 `pair`、不设深度上限——它只问「这两个 id 在产物里有没有被放在一起、并带上原话」。

**定义 4（行为效应 vs 量具效应）** 设两臂 `A,B`，某个读法给 `R_A, R_B`。若
```
Δ_effect = R_B − R_A
```
在另一个读法下**掉了 ≥ 一半**，那么这半个 `Δ_effect` 不是行为差，是**读法差**（量具效应）。剩下两个读法都同意的那部分，才是**行为效应**。⇒ 跨臂效应应当报成一个区间，不是一个小数。

★ 为什么必须这样定义，而不是“多加一个更准的读法”：**没有中立的读法**（`outbox/理论-观测单元…md` §2.4 已证：任何“读得全”的规则会把元数据读成断言，任何“读得准”的规则会在没约定的形状上沉默）。所以能做的不是选一把好尺，而是**要求两把尺在同一方向上给出一致的差**——不一致的那部分，你没有资格归因。

依据：`work/practice/notesTask.ts:371-419`（`parseFindings`）、`work/architect/_addrjudge.ts`、`outbox/理论-观测单元-同一个产物三个都对的落地数.md §2.4`

## 2. 机制：为什么 `Δ` 必然存在，而且必然和“形状”共变

`parseFindings` 的三条实现事实（逐行可核）：

| 代码事实 | 后果 |
|---|---|
| 只枚举「**每个元素都是对象的数组**」（`walk` 里 `Array.isArray(val) && val.every(x => typeof x === "object")`） | `["notes/n03.md","notes/n22.md"]` 这种**字符串数组整段被跳过** |
| id 只在**值**里收（`leaves(item)` 的 `value.match(/\bn\d{2}\b/g)`），**键名从不参与** | `{"n03":[{"行":2,…}]}` 这种“用 id 当键”的编码，一个 id 都收不到 ⇒ `notes.size===0` ⇒ 整条被丢弃 |
| 递归深度上限 4 | 深度 ≥5 的条目不可见（产物是文档，套几层是自由的） |

⇒ 一条断言被读到的充要条件不是“它写下来了”，而是**它恰好落在解析器的语法里**。于是任何一个改变产物写法的干预（加 schema、加清单、换章节式），都同时改变了 `|内容 ∩ 语法|`。
★★ 这就是“形状买召回”这句话的隐患：`matched` 的定义里有一个**未写出的下标 `u`**。改干预会改 `u` 的命中率，**哪怕集群的搜索能力一点没变**。

★ 这不是“实现不够聪明”。判据不能读意思（意思的署名是被告，见第十章口子四），所以只能读形状；而形状是干预的**产物**，不是干预的**证据**。

依据：`work/practice/notesTask.ts:371-419`、`work/mapper/PREREG-assert.md §2`、`runs/assert.jsonl`（对象数组 16/16/16 vs 字符串数组 0/0/1）

## 4. 后果一：两个已经在书里流通的数要改成区间

这不是我挑出来的孤例，是两条**正在被用来选型**的结论：

### 4.1 「加 5 行形状条款，召回从 8/6/6/9 到 12/11/12/12 ⇒ 召回是形状买的」

- 在 `judge` 下：召回差 = 中位 **7.5 → 12 = +4.5**；
- 在 `P2` 下：**10 → 12 = +2**；
- 在 `Ppin` 下：**9.5 → 12 = +2.5**。
⇒ 正确的写法是：**「召回差 = +2 ～ +4.5，取决于你用什么读法；两个读法都同意的那部分是 +2」**。
★ 方向没变（形状确实有用，而且差在**冲突侧**：`solo` 冲突 5/3/5/4 vs `solo-fmt` 6/6/6/6，重复侧两边都是 5–6/6）。变的是量级：**一半是行为，一半是判据读不到**。

### 4.2 「`escape12` 0/6 落地，因为解释段被读成断言」

`escape12_r0` 不成立：它的“多出来的对象数组”不是解释段，是**每对两侧的原话**（12 对 × 2 侧 = 24 条，正是那 24 个 fp 的来源形状）；而 `P2` 12/12、`Ppin` 9/12。⇒ 这一轮**不该算“N 对了也没用”的证据**，它属于 ① 的下半格（判据读不到），价钱是 **0 token 重判**，不是重跑。
★ 同一件事已被 `theory/architect` 从另一个方向看到（`escape12_r1` 用地址读法是 m12/fp0/anch12=落地）。两条独立路径指向同一个结论：**这一臂的“0/6”里混着判据的失败**。

★★ 读者怎么自己判“这是不是量具效应”（三个 0-token 问题，按顺序问）：
1. 两臂的**产物写法**一样吗？（不一样 ⇒ 先怀疑 `Δ`）
2. 用第二个读法重算同一批产物，效应**还剩多少**？（掉一半以上 ⇒ 归因撤回到“可读性”）
3. 第二个读法**自己的失败方向**是什么？（`P2` 会把“清单里提到两个 id”当断言——`chan-inv-obj` 上它仍剩 4–6 条假对 ⇒ 只看 `P2` 会把 fp 读小）

## 5. 边界：这条方法在哪儿不成立

1. **投影不是“更对的判据”。** 它不能做验收：`P2` 会把清单行（提到两个 id）当成断言，`Ppin` 会因为引文抄错而把真对判没。它只用来**估量具效应**，不能替 `judge` 下结论。
2. **投影自己也有语法，也有盲区。** 现成反例：`solo_r3` 的 `Ppin`=6/12（`P2` 是 9/12）——3 对的引文没法定到真值行，投影不再多算；`escape12_r0` 的 `Ppin`=9/12 而 `P2`=12/12。⇒ 报数时两档一起报，取**下界**做结论（我这章说的 +2，用的是 `Ppin`）。
3. **两个读法给出相反的符号时，你不能判。** 这时候唯一有分辨力的补充是：把产物 `assemble()` 归一成同一 schema 后再读（practice 的 R2 `d-count` 4/4 就是这种格子：归一后三读一致），或者换一个独立真值源。归一是要花钱的（K 轮），不是 0 token。
4. **样本与模型。** 32 轮、单模型（`deepseek-v4.1-flash`）、单语料（40 篇 notes / 12 对）。跨任务族时，`P2` 的“恰好两个 id”这条规则要重写；本章只给了规则长什么样，没给它能迁移。
5. **`Δ` 只对“写法变了”的干预非零。** 若两臂产物写法相同（本书大多数有 schema 的臂），`Δ≈0`——这时不要拿本章当“所有读数都不可信”的借口：**同写法跨臂的 matched/fp 是可比的**，这是本章实测支持的。★ **但先把天花板扣掉（v3 补）**：24 个唯一格里 **16 格三读都 = 12**（地板也是天花板），它们对「三读一致」提供 **0** 信息量；真正承重的只有 **8 个非天花板格**：其中 **6 格三读全同、2 格差 1**（均为 `Ppin`，见上表）。⇒ 本章的方法在同写法口径下的**分辨力 ≈ 1 条**：**两臂差 ≥2 条时才可比**；差 1 条时它与投影噪声同量级，不能下单。★ 另一条更常见的边界：**两臂都在顶档（12/12/12）时，本章判不了它们的差**——那时要看 `fp` 与 `pin`，不要看召回。

依据：`work/reader6/dbg-fp.ts`、`work/reader6/inspect-proj2.ts`、`work/practice/runs/site2/d-count_r*`、`outbox/理论-观测单元…md §6`

## 6. 读者动作：三件 0 token 的事，和一件要花钱的事

**跑之前（设计干预时，0 token）**
1. 写下两臂的**写法是否被干预改变**。若改变，预先声明：这次的读数差只能当“上限”，不能当效应。
2. 在验收之外另存一个**与判据无关的读数脚本**（本章两个投影约 60 行，纯函数）。它不是判据，不进 `landing`。

**跑之后（看到差时，0 token）**
3. 两读并排，报区间：`效应 ∈ [min(Δ_judge, Δ_P2), max(...)]`；只把**两个读法都同意的那部分**写成行为效应。

**要花钱的那件事**（只在两个读法符号相反时做）
4. 归一 schema 后重判（0 token）或重跑 K 轮（≈2.8 份副本/次，见《前置序》§4）。★ 若你只是因为“一个读法下落地 0”就重跑，你很可能在花 K 轮买一个判据 bug：`escape12_r0` 的 494,663 token 就是先例。

★ 一句话给只想记一行的读者：**判据是一把带语法的尺；换提示词会换写法，换写法会换读数。所以“两臂差多少”不是一个数，是一个区间——区间的下界才是你做的事。**

依据：§3–§5；`outbox/理论-前置序…md §4`（① 的价钱）、`outbox/读者-第十一章…md §2`（签名 vs 率）

★★ 所以这次测试的产出不是“本章有用”，而是**一条对整本书都成立的规则**：

⇒ 本章进书的理由不是 §6 那三件事（它们是常识），是 §3 的 32 轮逐行对账、§0 的 494,663 token 反例、§4 的 +4.5→+2 这两个数。**如果读者只记 §6，他不需要这一章。**

★ 若要把这次测试做成有分辨力的（下一轮）：
- 题面**不写**两臂提示词的差别，只给两臂的**产物**（或产物摘要），让读者自己发现“的写法不同”；

## 9. 「0 token 重编码」什么时候成立：同延性，以及它在本批一次都没落在需要它的格子上

§6 的第 4 条说「只有在两读符号相反时才花钱」；§5 又说投影不能当验收。这两句之间有一个洞：**什么时候可以拿第二个读法去「重读已落盘产物」而不算换判据？** 这一节把它写成一个可计算的判据，并给出本批的答案。

### 9.1 定义：同延，是集合相等，不是计数相等

**定义 5（同延）** 两个读法 `u₁,u₂` 在一批产物上**同延**，当且仅当对**每一份**产物，两者解出的**断言集合**相同：

```
同延(u₁,u₂)  ⟺  ∀ 产物 a :  Assert(u₁,a) = Assert(u₂,a)
```

★ 关键在**集合**：`matched` 相同不算同延（可能一个漏 A、一个漏 B，计数一样）。只有集合相同，才允许说「同一份内容、换了个读法」；否则你换的是**判据**，它的验收要重来（包括 `fp`、`pin`、落地）。
★ 这一条把「0 token 重编码」从口号变成一个**可判死的条件**——它是第 3 章那批「重编码/join 已有产物，0 token」的前提，而书里此前没有写这个前提。

**定义 6（读法的定义域）** （landing/edge 2026-10-26 补，0 API；兑现 2026-10-20 的一条保留）先问两把尺量的是不是**同一个量**。
若处理的目标量只在其中一把尺的定义域里，则 `Δ` 在该尺上归零**不是「量具效应」，是「该尺量不到这个量」**。
现成的例子：停止规则的目标是「交出去的那张答案表的条数」，而 `P2` 的定义域是「全文任何子树里提到过的对」——
`P2` 会把「排除清单 / 近似匹配」里提到的对算成断言 ⇒ 它量的是**提到过什么**，不是**交出了什么**。
⇒ 区间表里对这类效应不能标「量具效应」，要标 **「定义域外」**；否则你会把它当成尺子精度问题去修尺子，而真正要做的是换目标量。
★ 这一类的边界：定义域外**不是**「两把尺一致」——它可以一个 12/12、一个 0/12；把它算进「同延」的分母会把同延率压低。

待补：定义域外与不同延的判别程序（现在靠人读那几格；形式判据尚未写）。

### 9.2 实测（0 API，32 轮）：同延 29/32，而且不同延的 **3/4 全在同一个臂里**

读法定义：`Jid` = 冻结判据枚举到的「恰好两个 id」的真值对（**不看 kind**，所以与 `judge.matched` 可差 1——`judge` 会把 kind 不符的记成 fp）；`P2` = 任意子树里恰好两个 id 的真值对。

| 臂 | `Jid≡P2` | 不同延的轮 | 只在 `P2` 里出现的真值对 |
|---|---|---|---|
| `solo-fmt`（+5 行形状） | **4/4** | — | — |
| `solo`（无形状） | **1/4** | r0, r1, r2 | r0: `n11|n27, n14|n33, n05|n36`；r1: `n08|n31, n02|n24, n20|n30`；r2: `n08|n31, n14|n33, n02|n24, n20|n30` |
| `siteQ` 六个臂（24 轮，全部有 schema） | **24/24** | — | — |
| **合计** | **29/32** | 3 | 方向全是「J 少读」，**没有反过来**的 |

★★ 由此得到一条比 §4 更硬的话：

> **「0 token 重编码」在本批 32 轮里，一次也没有落在需要它的那一格。**
> —— 有 schema 的 28 轮**全都同延**（可重编码，但它们的 `J` 本来就读到了，没什么可救）；唯一不同延的 3 轮全在**无 schema** 的臂上（正需要救，但换读法就换了断言集合，`fp` 也随之从 56–79 变成 8–15，那不是「重编码」，那是「换判据后重新验收」）。

★ 这与《观测单元》§6 的结论是同一件事的两种说法：**没有一种读法是「更宽的 J」**。它在本批的定量形态是：**投影能救的那 3 轮，恰好是不能用投影验收的那 3 轮**。

### 9.2b 两个档：弱同延与强同延（`theory/architect` 的挑战，我接受并实测）

`theory/architect` 指出：只比**真值对**（§9.2）支撑不了「0 token 重判」——验收判据读的是**全部断言**，`fp` 变了就是换了验收。所以把 `Assert` 换成**全部两-id 对（真+假）**，得到两档：

| 档 | `Assert` 取什么 | 能支撑什么 | 实测（32 轮） |
|---|---|---|---|
| **弱同延** | 只取真值对 | 「这些对确实在产物里」（机制论证） | **29/32** |
| **强同延** | 全部两-id 对（含 fp） | 「0 token 重判」（验收不变） | **28/32** |

★ 强同延逐臂：`solo-fmt` **4/4**、`siteQ` 六臂 **24/24**、`solo` **0/4**。⇒ **28 轮有 schema 的产物，连假对集合都完全一致**：J 与 P2 在它们上面读到的是**同一个断言集合**，只是计数口径不同。这比 §9.2 的结论更强——**schema 的作用就是让「哪些算一条断言」不再依赖读法**。

★ 同时它落空了一个预测：`theory/architect` 预测「有 schema 的臂会有一部分强同延为 false（因为 `fp` 那侧可能不同）」。**实测 0 轮落空**（28/28 全是强同延）。原因可复算：强同延只在「同一对 id 被一个读法看见、另一个看不见」时才破，而有 schema 的产物里每个对都住在一个显式的两-id 元素里，两个读法都看见它。⇒ 「有 schema ⇒ 强同延」在本批成立，且**不是**因为 `fp=0`（`solo-fmt` 的 fp 是 2/5/3/10，`P2` 也读到同样的假对）。

★ 未做的一档（要写清，别当成已测）：**带 kind 的同延**。`P2` 不产出 kind，所以「同 kind」这一维对 `P2` 不可定义；要比，得先给 `P2` 一个 kind 抽取规则——那是另一个读法，不是本节的投影。

### 9.3 读者动作（跑之前 30 行代码，0 token）

1. 先算 `Assert(J)` 与 `Assert(P)` 的**集合**，不要比 `matched`。
2. 若逐轮集合相等（本批 28/28 有 schema 的轮）⇒ 可以把「重读」当 0 token，结论可直接搬。
3. 若不等（本批 3/4 无 schema 的轮）⇒ 你有两个选择，**都不免费**：
   - **(a) 归一后重判**：把产物里已经写着的内容机械搬进同一 schema（`assemble()` 那一步），再判一次。这是唯一「不换判据」的免费路径——它的前提是**产物里确实写着那两对**（本批 `escape12_r0` 满足），代价是你要写一个抽取器（0 token 但**要人写代码**，且抽取器本身要冻结）。
   - **(b) 重跑 K 轮**（≈2.8 份副本/次）：当产物里根本没写（不是编码问题）时唯一的路。
4. 不要把「投影读出来的数」直接写进落地率——它没有验收资格（§5-1）。
