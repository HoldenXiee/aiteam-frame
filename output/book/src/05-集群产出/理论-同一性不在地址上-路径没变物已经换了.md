## 0. 一句话，和一张能判死活的表

**一个物的身份是它的内容，不是它被挂在哪个地址上。** 这句话在有代码的地方是常识（内容寻址），在**读数**这件事上它不是常识，而且违反它的代价不对称：读数的地址（路径、字段名、章节里那串字符、臂名）**永远不变**，而物（产物字节、判据代码、成员清单、那个数的副本）**天天在变**。

于是所有的「同一个数，两次算出来不一样」都能被压进一张 2×2：

| | **物没变**（md5 同） | **物变了**（md5 异） |
|---|---|---|
| **地址没变**（路径/名字同） | ✔ 可复算（这是你要的状态） | ★★ **换物**：读数静默污染。旧读数**不可救**（除非那一行落了 md5） |
| **地址变了**（换了路径/换了章节） | 搬家：可救，改指针即可 | 什么都没冻住：连「同一批」都不成立 |

★★ **它判什么死活**：两个读数不同时，**不许先问公式**，先取两次的交集逐份比。
- 交集内逐列全同、只有新行 ⇒ **域长大**（可救：把 n / 快照 id 带上，旧数在旧域上仍是命题）；
- 交集内有列变了 ⇒ **换物**（不可救：那几份产物已经不是原来那几份）。

★★ **定义域（v3，接受 practice 的保留）**：这张 2×2 的**输入必须是「两次读数都带逐行读数」**。
标量对——书里最常被撞到的那种，例：`00a` §3.5 的 `16/48` 与 `18/48`——**落在域外**：「交集」这个对象根本不存在，2×2 的两格都无处落脚。
域外只剩 **md5 级**判定（整批产物 md5 全同 ⇒ 同物；全异 ⇒ 只能重算，**无法定位是哪几份换了**），
而**处置**是先把标量拆成逐行（批级标量 ← 逐行 `landing` 列），0 token，拆完才回到本表。详见 **§4.1**。

★★★ 这不是分类癖：**这两种失效的处置完全相反**，而书里现在只有一个词（「D 变了」）把两者盖在一起。本 lab 的 `00a` 词 3 v4 那行就写着「φ 没变、P 没变、`K` 没变，而数变了 ⇒ 一定是 D 变了；去找输入清单，不要去找公式」——这句话在 §3-B 的现场里**会把 3 份换物误判成域长大**，于是你会去查清单（清单是对的），而永远查不到那 3 份。

## 1. 定义：地址、物、身份

| 词 | 定义 | 它判什么死活 | ✘ 长得像但不满足 |
|---|---|---|---|
| **地址** | 你用来**指**一个东西的名字：`work/practice/runs/siteJ3/a1q_r0/report.json`；`词 5 那一格`；`16/48` 这串字符；臂名 `S1Q1` | 判「谁在指谁」：同一个地址在两次读数里指到两样东西 ⇒ 那个对照不成立 | 「路径一样，所以是同一份产物」——§3-B 有 3 份反例 |
| **物** | 地址背后那个东西的**内容**：产物字节、`φ` 的源码字节、成员清单、真值表、书里那个数的取值 | 判「变没变」：`md5(物)` 前后一致才叫「没动」 | 「我没改它」——`exp-state.ts:44` 里那行 `arm === "E1" ? run_${rep}s : SHARED` 就是代码**默认**覆盖，作者没改任何东西 |
| **身份** | `(md5(物), 生成它的那条命令)` 这一对。★ 只给 md5 不够：两份不同命令产出的同字节文件，复算时你仍然不知道该重跑哪一条 | 判「这个数还能不能复算」：身份在 ⇒ 能；身份不在 ⇒ 只能引用，不能复算 | 「有 git 锚」——git 锚的是**这份工作区里那一份**，它不保证别人盘上那个路径下是同一份 |
| **求和域 `D`** | 把**单份**读数加总成**批读数**时，你实际扫过的那一批份（清单，不是目录树） | 判「率的分母从哪来」：`n = |D ∩ 闸|`；`D` 变大 ⇒ 率会动，但每份的读数不动 | 「判据的一半」——★ 见 §2，这是 `00a` 里唯一一处我认为**必须改**的地方 |

★★ **`D` 与「判据」不是并列的**。这一点值得单独说，因为它是本章唯一的定义修订：

```
单份读数   =  φ(p ; T)                    ← 不含 D。p 是产物，φ 是判据，T 是真值
批读数/率  =  |{p ∈ D : φ(p;T) = 落地}| / |D ∩ 闸|   ← D 只在这里出现，而且只出现在加总里
```

`00a` 词 3 v4 把判据写成 `C = (φ, D)`，于是「同一份产物永远同一个数」这句纯度定义和 `D` 被放进了**同一个对象的两半**——但 `φ(p)` 根本不读 `D`。这不是措辞问题，它有一个可测的后果：如果 `D` 是判据的一半，那 `D` 一换，**同一份产物**的读数就该跟着换；而 §3-C 量到的恰恰相反（388 份里 385 份逐列一个字节都没变）。⇒ 正确的封装是：**`φ` 是判据；`D` 是求和域。`(φ, D)` 是「一次批读数」的身份，不是「判据」的身份。**

## 2. 机制：为什么地址**总**被当成身份

不是粗心。是三个方向上都在奖励它：

1. **写盘是默认覆盖的。** `run_shared/report.json` 这种命名不是谁写错了，是「省目录」的自然写法（`work/practice/exp-state.ts:44`）。于是**五臂 36 轮共用 1 份产物**，而目录树看起来一切正常：`ls` 有目录、有 `report.json`，只是它现在是最后一轮的那份。
2. **算 md5 要额外一步，记路径不用。** 报数的成本结构决定：路径是你**已经有的**，md5 是你**要加的**。所以「同一批」这个词被反复用来代替「同一份清单」。
3. **读数是可加总的，而加法抹掉身份。** `39/45/40 → 49/55/50 → 56/62/56`，三个汇总数看起来是「同一件事在长大」；只有取交集逐份比，你才看得见这三次里**有 3 份是换了物**。

⇒ 结论不是「要小心」，是：**同一性必须由装置留下，不能由作者记得。** 作者记得的东西，在 40 份文档、三个团队、两天之后必然失守——§3-D 就是这个失守的率。

## 4. 判据：交集法（0 API，拿到两个读数就能跑）

> ★ **v3（2026-10-23，接受 practice 的保留）**：本节补了 **§4.1 定义域**——交集法只覆盖「两次读数都带逐行读数」；**标量对（`16/48` vs `18/48`）在域外**，交集不存在，只有 md5 级判定，处置是先把标量拆成逐行。这处差点让读者把「施加不了的 2×2」当成「我算错了」。

```
给定：两次读数 R1、R2（同一 φ 家族、同一 T；各自带份清单）
1. I = 份(R1) ∩ 份(R2)。若 |I| = 0 ⇒ 你什么都没冻住，后面不用做了。
2. 对 p ∈ I 逐份比 φ(p)（不是比汇总数）。
3. I 内全同 + 只有新增     ⇒ 域长大。处置：旧数加 n / 快照 id，结论仍成立。
4. I 内有列变            ⇒ 换物。处置：那几份的旧读数作废；查 md5，查有没有别的命令在写同一路径。
5. 若出现了「旧有新无」（gone > 0）⇒ 留存失败（00a 的 ③），比换物更贵：连字节都没了。
```

★ **这个判据为什么能判死活**：它同一套步骤在 §3-B 与 §3-C 上给出**两个不同的结论**（换物 3 份 / 纯域长大），而这两个现场是**同一对快照、同一条命令**。如果它只是「重新排个版」，它不可能在同一份数据上分出两种处置。
★ 它的成本：两次快照的逐份表 + 一个 Python 集合比较，0 token、60 秒。★ 不做它的成本：§3-B 那 3 份会让你去查清单（清单是对的），然后你会得出「读数不稳定」这种既不真也不可操作的结论。

### 4.1 ★ 定义域：交集法只覆盖「两次读数都带逐行读数」——标量对落在域外（practice 的保留，已补）

★★ 这一步必须写在判据旁边，否则读者会拿它去施加在它施加不了的地方：

| | 域内 | **域外** |
|---|---|---|

## 5. 边界：这条什么时候不成立

1. **确定性装置不需要它。** 读数若能从源码重算（编译产物、纯算术的汇总），「重跑即复现」，没有换物问题——**换物的定义里就要求有「一次不能重来的外部行为」**（模型的抽样）。所以本章只管 `landing / fp / token` 这一类。
2. **md5 只保证「没变」，不保证「对」。** 两个都忠实于同一条 `K` 的实现，md5 不同而读数也不同（§3-A 的 9 vs 14）——**md5 能让你看见分叉，不能替你选谁对**。选谁对要第二个实现独立写（这就是 `J1` 那个实验在做的事）。
3. **换物只在跨过判定阈值时才有害。** §3-B 的 3 份换物改了 `m` 却没改 `land`。⇒ 危害 ≈ `P(换物) × P(跨阈值 | 换物)`。这条边界给出一个反直觉的排序：**最危险的不是「大改」，是「半成品」**——半成品的 `m` 从 0 涨到阈值附近，它跨阈值的条件概率最高（本批 3 份全是这种）。
4. **「地址变了、物也没变」不需要修。** 书里把一份文件从 `work/` 挪到 `outbox/`，只要 md5 同，旧读数继续有效；别把「搬家」当事故。
5. **同名不同物的合法情形**：臂名。同一臂名的两轮**本来就**是两份不同的产物——所以 §3-B 那类比较的口径必须是「份」，不是「臂」。★ 这与《输入同一性》是同一件事的两面：那边说「臂名是输入的一部分」，这边说「臂名不是产物的身份」。

## 6. 处置：三条装置规则 + 一条书侧规则（都便宜）

| # | 规则 | 落在哪 | 成本 | 不做会怎样 |
|---|---|---|---|---|
| ① | `runs/*.jsonl` **每行**落 `artifactMd5`（产物本身的 md5），不是只落路径 | 跑的时候多算一次 md5 | < 1 ms/份，0 token | §3-B 那种换物**事后无法发现** |
| ② | 快照写**新文件**，永不原地覆盖；文件名带时刻（`snap-odomain-<ISO>.out.txt`） | 一行 `writeFileSync` | 0 | `250 份` 那批数永久不可复核（已发生） |
| ③ | `φ` 与 `D` 各落一个 md5：判据源码 md5 + 份清单 md5 | 报告头两行 | 0 | 分不清「判据变了」和「样本变了」，而两者处置相反 |
| ④ | **书里每个数只有一个定义处**，其余地方引用 **id**（例：`N-16-48` 指向那个格子），不抄那串字符 | 写的时候 | 0 | §3-D：41 处副本，6–8 处 stale，且落点恰好是**读者会照抄的那几格** |

★★ 为什么是**这四条而不是「小心抄写」**：前三条把同一性交给装置（不依赖谁记得），第四条把「数的身份」从字符变成 id——**同一个数在四个地方的 md5 必然分叉，因为它们是四次不同的生成**（§1 定义：身份 = 内容 + 生成它的那条命令）。你没法让四份副本「保持同步」，你只能让它们**不需要同步**。

## 7. 这一章能被判死的地方

- 若能找到一个现场：`D` 长大了、一批份的 `φ` 读数**也**变了，而那批份的 md5 一个都没变 —— 那么「域长大不污染逐份读数」这条就错了，`D` 与 `φ` 的分封装要重做。
- 若 §3-B 那 3 份换物其实是**同一份产物被两次读到不同的地方**（解析器读了不同的缓存），那不是换物，是 `φ` 不纯 —— 判法：那 3 个路径下现在的 `report.json` 的 `m` 确实是 34/40/104、**且 `mtime` 晚于 05:44:49Z**。★ 这条已核（→ 05:48:41 / 05:49:27 / 05:50:55Z，晚 4–6 分钟）⇒ **换物成立，且成因是「扫到了半成品」**。
- 若「交集法」在你的装置上跑不出两种结论（例如你的读数是一整批一次性算出来的，没有逐份行）——那说明你**连第一步都不具备**，先补逐份行，别补解释。
