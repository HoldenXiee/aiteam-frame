## 0. 先说清楚这一章不是什么

不是"最佳实践清单"。清单的问题是**每一条都对，所以选不出来**。
这一章的前提是一个已经被量过的模型（《判据定价》《一个数什么时候成为等式》）：

> **生产者做三件事：读出你的判据、找到能通过它的最便宜产物、交出去。**
> 落地不是"它努力不努力"，是**判据的四个槽里有没有空槽**。

四个槽、四个症状、四个杠杆，一一对应。★ 关键命题：**杠杆不可互换**——用错杠杆，落地不会变好，钱会变多（§2 有 0 token 的负对照）。
★ 表里有 **5 行**：`真漏` 与 `超报` 是同一个「数/停止」杠杆的**两个方向**（`proposed≤真值` vs `proposed>真值`），所以仍是四个杠杆；拆成两行是因为**修法相反**（一个要停止规则，一个要上界）。

### 1.1 两个单位不能换：`matched` 是分量，`landing` 是合取（theory/mapper 的挑战逼出来的）

上一版的第 3 行写「找不够 ⇒ 形状 或 数，两条都能修，形状更便宜」。这句话**在 `matched` 上对，在 `landing` 上错**——而本章的承诺是后者。同批 32 轮（`work/practice/runs/j2x2.jsonl`，单写者，四臂同批）：

| 臂 | `matched`（中位） | `fp` | `pin`（逐轮） | **`landing`** | tok/轮（中位） | **tok/次落地** |
|---|---|---|---|---|---|---|
| `S0Q0` 无形状无数 | 8 | 18–92 | 8,8,8,7,6,5,3,4 | **0/8** | 247k | **本批 0 次；下界 ≥792k** |
| `S1Q0` **只有形状** | **12** | 1–8 | 12,11,12,12,12,12,12,**8** | **0/8** | **62.6k** | **本批 0 次；下界 ≥201k** |

| `S1Q1` 形状 + 数 | 12 | **0** | **11**,12,12,12,12,12,**11**,12 | **6/8** | 71.5k | **95k** |

★★ **v4 订正（2026-10-23，theory 的挑战，我按 `runs/j2x2.jsonl` 复算后接受）**：本表上一版的 token 列写 **260k / 64k / 88k / 78k**，盘上**找不到出处**——它不是中位（247,156 / 62,616 / 84,293 / 71,546），也不是均值（253,969 / 61,953 / 85,487 / 70,745）。⇒ 已全部换成中位，并从同一批重算派生列：`S0Q0` 下界 247.2÷0.312=**792k**（旧 833k）、`S1Q0` 下界 62.6÷0.312=**201k**（旧 205k）、`S0Q1` 每落地 84.3÷0.375=**0.225M**（旧 0.23M）、`S1Q1` 71.5÷0.75=**95k**（旧 0.10M）。★ §6 的边际价（247.2→62.6、247.2→84.3、62.6→71.5=**+8.9k/+14%**）用的**本来**就是这一套，所以 §6 不动——换句话说，本章同一批读数曾有两套成本，只有一套能复算；现在只剩一套。

三件事：
1. **形状把 `matched` 抬满（8→12），但买不到 `landing`**：它的产物仍在同一张表上多报 1–5 条（`proposed` 13–17），而 `landing` 要求 `fp=0`。⇒ 「召回」与「精度」是两个合取项，**同一个杠杆可以修一个、修不了另一个**；把两者并成一句「找不够」会让读者在 `matched=11` 的现场选错杠杆。
2. **`matched=11` 是哪个故障，得看 `proposed` 与 `fp`**：真漏是 `proposed ≤ 真值`（`S0Q0`：proposed 7–18、fp 18–92）；超报是 `proposed > 真值` 且 `fp` 小（`S1Q0`：13–17、fp 1–8）。前者要停止规则，后者要上界——**这是本章第 1 行拆成两行的理由**。
3. **`S1Q1` 那 2 个失败不是 `fp` 也不是 `matched`**：r0/r6 的 matched=12、fp=0 但 `landing=false`，卡在 `pin`（两侧引文没有双侧唯一定位，pin=11）。⇒ `landing` 是三件合取（`matched` ∧ `fp=0` ∧ `pin`），**任何单列读数都不是它**；也所以「数买 landing」要拆开说：**数买 `matched` 与 `fp`，`pin` 仍可能掉 1**（`S0Q1` 有一轮 6，靠数也拉不住）。这也是本书反复要给读者的那个概念：验收单位一旦选错，后面的价全错。

★ 由此修正上一版的两句话：①「形状更便宜」只在**每轮**成立；按**次落地**只能给下界（`S1Q0` 0/8 ⇒ CP 单侧 95% 上界 0.312，62.6k÷0.312 = **≥201k**；v4 订正，旧版写 64k÷0.312=≥205k，分子来自那张无出处的表）。★ 不写 ∞：0/8 是「这 8 轮没落地」，不是「永远落不了地」（口径同 `00a` §3）。②不要把「加形状」当作「找不够」的统一解：它只修召回，不修超报。

★★★ **拿到一份 `landing=0` 的产物，先做这一步（v3，本章加在四个杠杆之前）**：把 `matched / fp / pin` 三列并排列出来。
```
只有「其它两列满、只差一列」 ⇒ 可归因到那一列，按表选杠杆（例：S1Q1 r0/r6 = m12 / fp0 / pin11 ⇒ 只差 pin）
两列或三列同时不满      ⇒ 不可归因；按「哪一件更便宜」选，不按「哪一列最差」选
```

## 2. 为什么"加错杠杆"不会变好（负对照，0 token）

三组已经跑过的"加错"现场，方向都是**零**：

| 你可能会加的东西 | 它试图修什么 | 实测 | 为什么无效 |
|---|---|---|---|
| **"一条都不能少，也不许多报"**（禁口令，无数） | 多报 | `demand` proposed 19/14/19/22、落地 0/4；`pol` proposed 12–31、落地 1/4 | 禁口令不提供可核算的停止点（它不是数） |
| **按数据切半 + 并集**（想用分工买召回） | 找不够 | `split-data` matched **0/6**、fp 10–19 | arity-2 的配对跨半，格不在任何写者的视野里 |
| **多一个计数工人（k=2/3）**，而计数本身没有方差 | 数错 | 16 轮 23/24 次数对；k 臂的**计数**与 k=1 不可区分 | 中介变量无方差 ⇒ k 对"计数"这一格买不到东西（★ 只此而已。`r7` 的 landing 按臂分家：`selfq2` 0/4 vs 其余 3/4；随机把 4 个偏离轮全放到**任意一臂**的概率是 **4/1820 ≈ 1/455**（我上一版写的 `1/C(16,4)=5.5e-4` 是**先把臂指定了**再算的，不可当显著性用）。装置把「路径里一个字符」与「k 个计数工人先跑完」绑在一起 ⇒ **这一格只能判「不是抽样」，判不出 k 的效应**） |

★ 这张表的用处不是"别做这些"，是**判断自己是不是在加错杠杆**：如果你加的东西**没有改变"生产者当场能核算的那个量"**，那它大概率是零。

## 3. 一个完整的落地流程（把四个杠杆排进时间线）

```
人给一句话（意图）
   │
   ├─ ① 抽谓词：这句话要判什么？（"重复" / "打架" / "超时上限"）
   │     └─ arity = 一条真值跨几个元素？跨 2 个 ⇒ 下面所有"切半"都必须禁止
   │
   ├─ ② 定断言单位：一条答案长什么样？（二元条目 + 引文）  ← 杠杆：形状
   │     └─ 判据要能"数得清条数"；否则后面三件都没有单位
   │
   ├─ ③ 分区 + 每格一个数：把"一共 N"拆成"k_i 条 P_i"，每格给一个写者  ← 杠杆：落点
   │     └─ 写者在写作时能数到自己那一格吗？不能 ⇒ 先改分工/视野
   │
   ├─ ④ N 从哪来：人知道吗？
   │     ├─ 知道 ⇒ 直接给（但必须按 ③ 落到格上）
   │     └─ 不知道 ⇒ 让集群先数（自数），再枚举；数错了就退回到"验收不要 N"
   │
   └─ ⑤ 交出去之前：产物条数 == Σk_i ?  ← 纯函数，0 token
         └─ 不等 ⇒ 数没生效，回到 ③（不要去改措辞）
```

★ 每一步都对应一个**可判的检查**，不是"建议"：
- ② 之后：`produced` 是否为真、判据解出的条数是否 > 0；
- ③ 之后：`proposed` 是否等于 Σk_i；
- ④ 之后：N 与真值是否一致（有真值时）；没有真值时，这一格**无法验收**，要换制度（《第八章》）；
- ⑤ 是落盘 `assert`：`proposed == matched + fp_二元 + dup + dropped`（两批 31/31 残差 0）。

## 4. 什么时候**不要**用这张表（边界）

1. **没有真值、也没有 N**（开放世界）：③④ 都无处落。这时本章给的不是杠杆，是"**去建一个可核的记录**"（动作日志/引文锚），把问题从"判对错"换成"判有没有做过"。
2. **谓词本身不可判**（"写得好不好""有没有洞见"）：形状只能让它**可读**，不能让它**可判**。这时落地率不是目标，应该改成抽样人读（《第七章》的判定单位与价钱）。
3. **任务在天花板上**（所有臂都满分）——★ **「到顶」必须分口径说，否则会把还能修的任务扔掉**：task2c 同一批里，**内容口径**已到顶（`open` 的**主表单独**落地 4/4、`gap` 4/4、`recipe` 3/4 ⇒ 命令类/内容类杠杆在那里是空操纵），但**交付口径**没到顶（全产物落地：`recipe` 3/4 vs `open` **0/4**、`gapnofmt` **0/4**）。⇒ 先分别量两个口径，再决定抛弃任务：内容到顶而交付没到顶的任务，**仍然有分辨力**（且那一格是 0 token 的容器问题）。本 lab 另两次真天花板（换载体 4/4 轮 8/8；gapcover 12 轮里 11 轮满 `matched 12 / fp 0 / anchored 12`）在两个口径上都满。
4. **单模型、单语料**：所有读数来自 `deepseek-v4.1-flash` × 40 篇笔记 / 12 对真值。换模型、换语料规模，量级会变（计数工人的准确率跨批就从 8/12 漂到 12/12）。

## 5. 用它推一个没见过的现场（★ 这一节是本章的自检）

现场（取自本 lab 之外的一个真实任务）：**"把这 200 条工单里重复报修的挑出来，给我一份我能核对的清单。"**
没有给数量，没有给"什么算重复"，产物是一份 Markdown 报告。

按 §1 的表推一遍（不跑）：

| 症状（我预期会看到） | 空槽 | 杠杆 | 我预期动了之后读数怎么变 |
|---|---|---|---|
| 报告是散文分节，判据解出 0 条 | O | 形状：每条 = 两个工单号 + 两侧原话；★ **先问你的判据读哪个字段**，只把「判据会读成断言」的那个容器改掉，**别把有用的清单删了** | `produced` 从 false → true；条数从 0 → 可数 |

★ 这个推演能被判死的方式：**如果形状 + 分格数 + 自数 N 三件都做了，产物仍然"挑不全"**，那说明这个任务的主故障不在判据槽里（可能在语料：重复报修需要跨字段 join，而写者看不到全表）——那就回到 ③ 的视野检查，而不是加第四个杠杆。

## 7. 这一章可以被判死的地方

1. **反例 A**：出现一个现场，症状是"条数自由"，但加了分格数之后 `proposed` 仍自由（且格确实落在单写者上）。⇒ 落点那条杠杆作废。
