# 术语表

> ★ 本书用到的词，在这里给定义。**定义是判据，不是描述。**

## 生产方式

用**代码**组织**大语言模型**（多个 agent），让它们自主完成研究/生产。
★ 区别于"用 AI 辅助干活"：这里**代码规定的是组织形态**，不是任务步骤。

## 集群

一组**被代码组织起来的 agent**，有共同的使命、各自的角色、明确的边界。
★ 集群的形态由**使用者代码**定义，不由底层库定义。

## 面（Surface）

★ 一个**可被代码读写的切面**。例如：

| 面 | 管什么 |
|---|---|
| `io` | 投递、结算 |
| `context` | 这一轮发给模型的内容 |
| `tools` | 有哪些工具、工具结果怎么处理 |
| `permissions` | 哪些工具允许被调用 |
| ★ `observe` | **每一轮真正发给模型的 messages / 每轮 token / 干预生效计数** |

★★ `observe` 是研究专用的 —— **别的工具看不到"它实际收到了什么"**。

## 结算（Settle）

一次运行 = `agent_start` → `agent_settled`。
★★ 它为什么重要：**多轮之间"它到底还在不在干活"只能靠它判断**。

## 干预生效计数

★ 你注入了 N 次，**实际生效几次**。
★★★ 没有这个数，「它没听劝」和「它没收到」**分不开**。

## 装置缺陷

★ 实验装置本身的问题（判据错、量具错、采样时机错）。
★★ **装置失败 ≠ 能力失败** —— 这两件事必须分开说。

## 撤回

★ 作者自己发现结论不成立，**公开标记它作废**。
★★ 在本书里，撤回**不是失败** —— 它是纠错率的一部分，而且是好信号。
