# 用代码组织 agent ——「先果后因」的生产范式

> 把这个文件夹复制到任何一台装了 **Node ≥ 24** 的电脑，就能开始用这套生产方式。
> 不需要 `npm install`，不需要联网，不需要编译。

---

## 这是什么

一种用**代码**组织大语言模型来干活的方法，和它长出来的底层库、一本书、以及给 AI 的说明书。

| 目录 | 是什么 |
|---|---|
| **`AGENTS.md`** | ★ **给 AI 助手读的操作手册**。你把它和整个文件夹一起交给你的 AI，它就知道怎么干活 |
| `README.md` | 本文件：给人看的快速开始 |
| `src/` | 底层库源码（18 个文件 / 约 4000 行）—— 唯一导出入口 `src/index.ts` |
| `node_modules/` | 依赖（114 个包，已自带，**不用 npm install**） |
| `book/` | 《如何用好近乎零成本的智力》—— 40 章，另有单文件合订本 `book/全书.md` |
| `examples/` | 13 个可跑示例（离线假模型，**$0**） |
| `demo/` | 一个看得见的环境（凭证 / 技能 / 扩展）+ `smoke.ts` 自检 |

**一句话概括这套方法**：你不写实现，你写的是**目标、分工、判据、停手点**；实现由 AI 逼近。
而组织它们的不是提示词，是代码 —— 因为「什么情况 → 做什么」能写成代码，用嘴说不精确。

## 三十秒上手

```bash
node demo/smoke.ts
```

看到「全部通过」就行了。它会做三件事：环境自检（不花钱）→ 真模型回一句话（约 $0.0001）→ 确认书在读得到的位置。

想再确认一步，挑个示例跑（离线假模型，零成本、零风险）：

```bash

```

## 然后怎么用

### 如果你想自己写

```ts
import { createLab } from "./src/index.ts";

const lab = await createLab({ agentDir: "./demo/agent", cwd: "./demo/work" });
const agent = await lab.createAgent({
  id: "写者",
  model: "opencode-go/deepseek-v4.1-flash",
});

const r = await agent.io.prompt("把材料整理成一张表");
console.log(r.text);
if (r.error) throw new Error(r.error);
await agent.dispose();
```

存成 `.ts` 文件，`node 你的文件.ts` 直接跑（Node 24 原生支持，无需构建）。

### 如果你想交给 AI 干

把这个文件夹整个交给你的 AI 助手，说：

> 「读 `AGENTS.md`，然后按它的指引，帮我用 `src/` 设计一个集群来做这件事：……」

`AGENTS.md` 是**专门为 AI 写**的：库的七个面怎么用、从一句话到可验收的五步、
四条最容易踩的坑、以及二十条用钱换来的纪律。它不需要你再解释一遍。

## 三个你该知道的边界

**1. 这不是「用 AI 帮你写代码」。**

| | 用 AI 辅助编程 | 这里 |
|---|---|---|
| 谁在干活 | AI 帮**你**写代码 | **你写代码去组织 agent 干活** |
| 你写的是 | 产品代码 | **组织的代码**：拓扑、规则、边界 |

一个当场能用的判据：**「我是在告诉它做什么，还是在规定它什么时候做什么？」**
前者是拿它当工具，后者是在组织它。

**2. 书不是规范。** 它每一条都是**在特定条件下**成立的观察，**条件是它的一部分**。
别把条件抠掉只用结论。

**3. 只有一种模型有凭证。** `opencode-go/deepseek-v4.1-flash`，在 `demo/agent/auth.json` 里。
`faux/*` 是本机假模型，用来测装置，**不能用于测模型行为**。

## 出问题了

| 症状 | 原因与出路 |
|---|---|
| `Cannot find module '@earendil-works/...'` | `node_modules/` 必须和 `src/` 在同一个文件夹下 —— Node 是向上找 `node_modules` 的 |
| `ERR_MODULE_NOT_FOUND` 指向你的 `.ts` | 缺 `"type": "module"`（`package.json`），或路径写成了绝对路径 |
| 模型报 `429 usage limit` | 换了 key 或额度用完。换一份 `demo/agent/auth.json` |
| 顶层 `await` 报错 | 同上：必须是 ESM（`"type": "module"`） |
| 想换模型 | **不要换**。没有别的凭证 |
