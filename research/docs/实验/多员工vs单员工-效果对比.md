# 多员工 vs 单员工：**效果按工作类型分开看**

> 2026-10-19 · 数据源：`research/labfirst/lab-3b` 的 git 历史（79 vs 87 个提交）
> ★ 分界点：**13:20**（`--employees=3` 首跑）

---

## 〇、一句话

> ★★★ **多员工买的不是"干得更多"，是"更多地在推翻自己" —— 而且推翻的是别人指出的、它自己看不见的东西。**

---

## 一、总账（★ 先说不是答案的那个数）

| | 单员工 | 多员工 |
|---|---|---|
| 总提交 | 79 | **87** |
| 产物（outbox）| 62 | **88** |
| 时间跨度 | ~7 小时 | ~4 小时 |

★★ **提交数几乎持平、产物多 26 份** —— 但如果只看这个，**看不出多员工好在哪**。

---

## 二、★ 关键切分：把工作**按类型**分开

| 工作类型 | 单员工 | 多员工 | 差别 |
|---|---|---|---|
| **① 勘误 / 更正 / 撤回** | **5**（6.3%）| **25**（28.7%）| ★★★ **4.5 倍** |
| 　└ 其中「**接受**别人的纠正」| **0** | **19** | ★★★ **0 → 19** |
| 　└ 其中「**回应 X 挑战**」| **0** | **16** | ★★★ **0 → 16** |
| 　└ 其中「**撤回**」| 1 | 3 | 3 倍 |
| **② 新研究结论**（P 号）| 相当 | 相当 | ★ **持平** |

★★★ **⇒ 多员工提升的不是"产出量"，是"纠错率"** —— 而且是**被外部纠正的那一类**。

---

## 三、★★★ 最本质的差别（一句话）

```
单员工的那 5 条勘误：  全部是**自我纠正**（"我自己发现错了"）
多员工的那 25 条：     19 条是**接受别人的挑战**（"你指出的，我之前看不见"）
```

★★★ **这正是 `C7`（它判不了自己）的实证与解法**：
- **单员工**：只能纠正**自己能看见的**盲区
- **多员工**：别人的角度 = **它的盲区的探照灯**

★ 挑战者的分布也说明问题：
```
回应 instrument-skeptic  ← 11 次   ★ 量具视角（找判据/量具缺陷）
回应 hands-on            ←  3 次
回应 falsifier           ←  2 次
```
★★ **`instrument-skeptic`（先怀疑量具）是被回应最多的** ——
★ 因为它挑的正是**别人最容易忽略、又最致命**的东西（**数据是怎么量出来的**）。

## 四、★★★ 实例：一条完整的辩证链（只有多员工才有）

```
① inspector            提 DEFECT：P44 缺安慰剂臂
② instrument-skeptic   SPC 控制图：P44 的 off-L10 是 23 点里唯一越限点
③ falsifier (P67)      拿 P44 原脚本重跑 48 轮
       · 新批 A 6/8 早停、新批 B 5/8 早停 ⇒ 合计 11/16（比基线 7/16 还多）
       · ★★ 基线在同一时段是稳的 ⇒ 消失的不是"线服从"，是这个处理效应本身
       ⇒ ★★★ P44 headline 与机制归因双双撤回
```

★★★ **三个角度串成一条链，最后一步推翻了前面的结论。**
★ **单员工阶段没有任何一条这样的链** —— 它的纠正都是"自己回头发现"。

---

## 五、★★ 但有一个代价：**多员工没让产物变少，反而变多**

我跑前预测 `D2`：**"收敛会合掉一些产物 ⇒ 产物数 ≤ 单员工"** —— ★ **不成立**（+26 份）。

★★ 原因：**挑战没有让它收敛，而是让它开了新实验** ——
★ `P67` 就是被挑战逼出来的 **48 轮新跑**，不是"改几个字"。

★★★ **⇒ 多员工的产出形态是"质的追加"，不是"量的合并"。**
★ 这**不是坏事**，但**推翻了"辩证会收敛"的直觉**。
