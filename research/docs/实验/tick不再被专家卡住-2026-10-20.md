## 1. 病（实测数据）

| 窗口 | tick 实际 | 按 `THROTTLE_MS=30s` 应该 |
|---|---|---|
| 180s | **1** | ~6 |
| 600s | **3** | ~20 |

⇒ **实际频率只有设计值的 1/6 ~ 1/7**。原因：`tick()` 串行 `await` 每条规则，
而规则里有 **9 处 `await fire(...)`**，专家每次跑 3–6 分钟。

第一版我只改了 `onSettled` 一处 → 180s 实测 **tick 仍然只有 1 次**。

查日志发现真正卡住的是 `onPlateau`（它有 **2 处** `await fire`）。

**⇒ 纪律㉑：一件能力多个入口 ⇒ 全堵才有效。**

## 3. 最终做法：改**唯一入口**，不改 9 处调用

```ts
export function makeRules(ctx: TriggerCtx) {
  const { state, fire: fireNow } = ctx;

  const fire = ((role, why, focus) => {
    if (ctx.closing?.()) return Promise.resolve("");
    void fireNow(role, why, focus).catch((e) => {
      ctx.trace("fire", `⛔ ${role} 失败（tick 不会等它，但必须让人看见）：${e.message}`);
    });
    return Promise.resolve("");   // ★ 等的是"叫了"，不是"说完"
  }) as TriggerCtx["fire"];
```

★ **9 处 `await fire(...)` 一行都没改。**

### 3.1 语义变化（必须说清）

| | 改前 | 改后 |
|---|---|---|
| `await fire(...)` 返回 | 专家的回答 | **`""`** |
| 等不等专家 | 等（3–6 分钟）| 不等 |

★★ 唯一需要返回值的是 `onSettled`（要读 `VERDICT: STOP|CONTINUE`）——
它**显式改用 `fireNow(...).then(...)`**，绕过这层包装。

### 3.2 为什么不用简单的 `void fire(...)`

★★★ `onSettled` 要读 `VERDICT` 来更新 `state.verdict`。
`void` 掉就永远拿不到那行 ⇒ `state.verdict` 停在旧值 ⇒
依赖它的 `onPlateau` 等规则跟着坏 —— **修一个坏两个**。

⇒ 所以：**tick 不等，但结果照样回到该去的地方**。

## 4. 改异步才有的新风险（已堵）

| 风险 | 为什么以前没有 | 怎么堵 |
|---|---|---|
| **inspector 积压** | `await` 天然串行，一个 tick 最多一位 | `state.inspectorInFlight` + `inspectorSince` |
| **一次失败永久停摆** | 同上 | `.finally(() => inFlight = false)` |
| **专家挂了没人知道** | 以前 `await` 会抛到调用方 | `.catch` 里记 `⛔` |

★ 实测日志（积压被挡住时说清原因）：
```
上一位 inspector 还在跑（已 Ns），不重复叫
```

## 5. ★★★ 顺带抓出两个「写了没接上」

### 5.1 第 4 次：`gate("toc")` 拼错名字

```ts
// runner.ts（错）
onTocDrift: gate("toc"),     // ★ gate 内部拼 R["onToc"]，而函数叫 onTocDrift
```

⇒ `undefined` ⇒ **规则永远不跑，而且不报错**。
★ 名字只差五个字母（`Toc` vs `TocDrift`），静默失效。

### 5.2 ★★★ 第 5 次：`gate("index")` 也一样

```ts
onChapterIndex: gate("index"),   // ★ 拼 R["onIndex"]，而函数叫 onChapterIndex
```

★★★ **`onChapterIndex` 从上线起就没跑过一次。**
那是我五条猜想里判据最硬的一条（纯函数、离线可证），
**结果是它一直在空转** —— 而我不知道，因为「没跑」和「跑了没触发」在日志里长得一样。

### 5.3 防复发：wiring 断言

`dev/test/settled-async.test.ts` 里加了一条：


★★ 这条断言**写的时候立刻抓到了第 5 次**（我只知道第 4 次）。

★ 行为测试抓不到这个 —— 因为行为测试直接调 `rules` 对象，不经过 `gate`。
