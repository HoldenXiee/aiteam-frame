# 换一个角度：从「它缺什么就补什么」到「它的世界是**构造**出来的」

> 2026-10-16 · 研究员指出「实验规划有问题，没有创新性实验」之后的重想。
> **本文不改方向 —— 它换一个角度看同一批数据。**

---

## 0. 我先承认设计上的问题

**我的 6 条成果，全都是同一个形状：**

> **「它缺 X → 那就给它 X（或者别给）」**

| # | 缺什么 → 补什么 |
|---|---|
| P1 | 看不见代价 → 把代价挂到结构边界上 |
| P2 | 没有分阶段 → 给个死区 |
| P5 | 不知道有哪些文件 → 给它 `ls` |
| P6 | 交接面留空 → 明确选衰减或放大 |
| P7 | 合并规则赌错 → 先测方向再选规则 |
| ★ **新**（读目录） | 不知道自己在哪 → **把路径写死** |

**全部是"补缺"。** 这就是为什么它们都"必要但不有趣"。

---

## 1. ★ 而新挖出来的那个现象，指向一个完全不同的角度

看这条原始轨迹（§读目录现象）：

```
 2. read draft/survey.md      ← 成功了
 3. read ../survey.md
 4. read draft                ← 目录
 5. read .
 6. read ../survey.md         ← 又在试
 ...
38. read work/draft/survey.md ← 第 17 次
```

**它在干什么？** 表面看是"路径不清"。**但换个说法**：

> ★ **它在用「试错」来**推断**自己的位置。**
>
> **它没有"我在哪"这个变量，只能靠"这个路径成不成立"倒推。**
> **试一次不行，就换一个写法再试 —— 每一次试错都是一次**实验**，
> 而实验结果（成功/失败）是它唯一能拿到的关于"世界形状"的信息。**

**这就不是"缺信息"的问题了，是：**

> ★★ **它能感知到的"世界"，只有通过**它自己发出的动作**才能建立。**
> **动作不只是执行 —— 动作是**测量**。**

---

## 2. 这个角度能重新解释我已有的**全部**发现

**把它们重读一遍 —— 不是"缺什么"，而是"它怎么建立对世界的认知"：**

| 现象 | 旧解释（缺什么 → 补什么） | ★ **新解释（认知是怎么构造的）** |
|---|---|---|
| **P5** 盲猜 192 次 | 缺枚举手段 | ★ **它在用"猜中的次数"当搜索策略** —— 每一次 read 都是一次探测 |
| **P6** 交接面留空最差 | 没明确选 | ★ **留空 = 让它去**推断**上游到底给了什么**，而推断靠试错 |
| **P7** 错误方向被提示翻转 | 提示写了什么 | ★★ **提示是它唯一能拿到的"世界说明书"** —— 它照着说明书调自己的输出分布 |
| **F′** 结构隔离做不到 | （我自己以为）藏起来就行 | ★★ **提示说"你只有这些"，它的世界就真的只有这些** —— **不是物理可达性，是它的世界模型** |
| **P1** 代价方差 40× | 它看不见代价 | ★ **它没有"我已经花了多少"这个知觉** |
| ★ **读目录** | 路径不清 | ★★ **它没有"我在哪"这个知觉 —— 位置要靠试错测出来** |

> ★★ **一条统一的线索**：
> **它的世界里没有「我没测过的量」这种东西。**
> **凡是它不能通过"发出一个动作、看返回什么"感知到的东西，对它就不存在。**

## 3. ★ 这就直接指向 `DESIGN.md` 里那条我完全没碰的话

回头看 `DESIGN.md` 第 60 行：

> 「**人**是以新的工具去"劳动"……**人的价值就在于去使用知识、工具来改造现实世界**。
> 但**要最大化的利用这个工具**，而我们这个项目就是去研究这个问题，
> **让人更好的利用这个工具，让人们能更大程度去实现自己的价值**。」

**我之前把这段当成"研究意义"读过去了。** 现在它读起来完全不一样：

> ★★ **如果"它的世界是靠动作构造的"，那么"设计系统"这件事的性质就变了。**
>
> **不是在**给一个已经懂事的执行者**配资源**，
> **而是在**为它构造一个它可以感知到的世界**。**
>
> ★ **人的位置就在这里**：
> **人是那个**蠢世界**的**设计者** —— 决定世界长什么样、什么能被感知到、什么不能。**

**而这句话说的是「通过代码」：**

> ★ **代码就是构造那个世界的手段。**

## 4. ★ 从这个角度，有几个**完全不同的实验**可以做

**注意：这些都是新角度，不是在候选清单上打钩。**

### ★★ 实验 α：**感知面**实验 —— 什么"能被它感知到"？

**问题**：同一个任务，我**只改变它能看到什么**（不改变它能不能做到），看行为怎么变。

**设计**：给它同一个文件，但用三种方式存在：
| 条件 | 它看到什么 |
|---|---|
| A 无提示 | 只有 `ls` 能发现 |
| B 提示里说"文件 X 存在" | 知道有，得找 |
| C 路径写死 | 直接可读 |

**观测量**：调用数、目录读率、**是否开始试错**。

**为什么这是新角度**：它测的不是"给不给工具"，而是
★ **「一个事实以哪种形式存在于它的世界里」对行为的影响。**

> 我已有数据里**正好有这三档的痕迹**（copy=0.0% vs solo=6.4% vs S1=9.1%），
> **但从没被当成一个实验去跑。**

---

### ★★ 实验 β：**代价的可见性** —— 我能让它"看见"自己花了多少吗？

**问题**：P1 说"它看不见代价"。**那如果我让它看见呢？**

**设计**：在**每一次工具返回**里附带一行 `[已用 12 次调用 / 3.4k token]`。
**对照**：不带这行。

**观测量**：总调用数、是否提前收敛、任务成败。

**为什么这是新角度**：
★ **P1 现在是"因为它看不见，所以别指望它"（一条限制）。
换个角度就变成"能不能**给它造一个它现在没有的感官**"（一个设计问题）。**
>
> 而且这是 `DESIGN.md` **丙类（利用）**的正面入口 ——
> **不是避开它的缺陷，是给它装上它没有的东西。**

---

### ★★ 实验 γ：**世界的说明书** —— 提示的"语法"而不是"内容"

**问题**：P7 发现提示**一句话**就翻转错误方向。
**那提示的**结构**（不是内容）呢？**

**设计**：同一个任务，三种提示：
| 形态 | 例子 |
|---|---|
| 陈述式 | "只报真实的缺陷" |
| **规则式** | "若 X 则报，若 Y 则不报" |
| **可执行的检查清单** | "逐条核对：①…②…③…" |

**观测量**：错误方向、**是否出现"逐条核对"的行为**（可从调用序列看）。

**为什么这是新角度**：
★ **P7 测的是"说了什么"，这里测"怎么说"** ——
**也就是**世界的说明书用什么语言写，它照着执行的精度不同**。**

---

### ★★ 实验 δ：**给它一个"我在哪"的感官**

**问题**：读目录现象说明它没有"位置"知觉。

**设计**：**不改提示**，而是改**工具** ——
把 `read` 的每次返回**前面加一行**：`[当前目录: /work/draft]`。
**对照**：不加。

**观测量**：目录读率、重复读率。

**为什么这是新角度**：
★ **这是"用代码给它造一个感官"** —— 而 `DESIGN.md` 说「**通过代码**」。
**`agent.tools.onResult` 这个面正好能做这件事，而我几乎没用过它。**

---

## 5. 这四个实验的共同点

| | 它们都在问 |
|---|---|
| α 感知面 | 一个事实**以什么形式存在** |
| β 代价可见性 | 能不能**给它造一个新感官** |
| γ 说明书语法 | **怎么描述世界**它执行得更准 |
| δ 位置感官 | 同上，用**代码**而不是提示 |

> ★★ **共同点**：**不问"它缺什么"，问"它的世界长什么样"。**
>
> **而"世界长什么样"是**设计者**决定的 —— 这正好是 `DESIGN.md` 说的
> 「通过代码使用 LLM」和「人的位置」。**

---

## 6. 与现有规划的关系

**这不是替换，是加一个轴。**

| | 现有规划 | ★ 这条新轴 |
|---|---|---|
| 问法 | 它缺什么 → 补什么 | **它的世界长什么样** |
| 产出 | 修补类做法（P1–P7） | ★ **构造类做法**（怎么造世界） |
| 对应 `DESIGN.md` | 乙/丁类（特性/分析） | ★ **甲/丙类（设计/利用）** |

**我建议**：下一步先做 **δ（给它位置感官）** 或 **β（代价可见性）** ——
因为：
1. **用 `agent.tools.onResult` 就能做，不用新基建**（局部我已经建了）
2. ★ **它们直接填 `DESIGN.md` 五类里空着的甲/丙类**
3. **成本低**（只改工具返回，不改系统）

## 6.5 ★★ 一次已发生的证伪（2026-10-16）★★

**本文写完后的第一个实验（δ·位置感官）就落空了。**

我把 7 个现象统一到「它的世界是构造出来的」，并推断
「`read` 目录 = 它没有**位置知觉**」。**δ 实验证伪了这条**：

| 证据 | |
|---|---|
| 有 `ls` 的实验：目录读 **0.05%** | |
| 无 `ls` 的实验：目录读 **7.69%** | ★ **154 倍** |
| δ 三档（给不给位置信息） | ★ **零差异**（都是 0%） |

**真正的因果是 `ls`**（能列目录），**不是"位置知觉"**。

⇒ 详见 [`读目录现象-含自我更正.md`](读目录现象-含自我更正.md)。

★ **框架本身还没被推翻**（其余 6 条不受影响），
**但按本文 §7 预先写下的判据：落空 1 个（δ），框架仍可留，但要带着伤疤看。**

## 7. 诚实的局限

1. **§2 的"统一线索"是一个**解释**，不是实测** ——
   它有解释力（能装下 7 个现象），但**我还没做过针对它的判据性实验**。
2. α 实验的三档**是历史数据的**事后归纳**，不是前瞻对照。
3. **β/γ/δ 都还没跑** —— 它们现在只是"设计"，不是"发现"。
4. **风险**：把现象统一到一个漂亮框架里，可能是**过度拟合**。
   ⇒ ★ **判据**：如果 α–δ 里有**两个以上做出预测并且落空**，这个框架就该被丢掉。
