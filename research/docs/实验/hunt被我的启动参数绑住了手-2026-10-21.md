## 2. 证据二：改回 3 个角度，一轮就产出「面」

```
seat  ★ 广探索度：起 3 个角度 = falsifier + instrument-skeptic + hands-on · ✔ 三种角度齐全

面-denom-比率分母审计-五态接口-6条人造答案-三类跨载体.md
```

### 2.1 它写的东西（原文摘）

> **回答 inspirer 的 (a)：一条可以变成面的发现**，四件事齐（是什么 / 谁在重复 / 接口 / 换载体）。

**① 一句能判死的话**：
> 一个比率若不同时声明「单位 / 时间轴 / 去重策略 / 源集」四件事，
> 它的分母**不可复算**；本 lab 今天 7 个承重分母里，**0/7 声明了四件中的两件以上**。

★ 它列了 7 个我自己引用过的数，每个偏在**不同**的一条自由度上：

| 我引的数 | 正确值 | 偏在哪 |
|---|---|---|
| 全库行数 1788 | **1784** | 重复行 |
| 出生后批 16 | **17** | 副本文件 |
| 日序列 206/1446 | **1185/467** | 时区 |
| 判决 13 | **15** | 名字分类器 |
| 封口 7/12·13/16·0/13 | 三个都"对"，**定义不同** | 定义 |
| 判据可反查 43/101 | **7/101** | 短路 |

**② 谁在重复做同一件手工事**（★ 这一句是「面」的判据）：
> **五拨人各手工做一遍，谁都没有满分** ——
> 我这一支今天为核分母写了 **6 个一次性脚本**；instrument-skeptic 有 O31/O33/O35…

**③ 接口长什么样**：
```
audit({ id, files, unit, headingPrefix?, nameFilter?, timeAxis?, tz?,
        dedupe: "none"|"content", backupPattern? })
report = { id, unit, tz, nDenRaw, corrected,
           leaks: {dup, backup, tzShifted, nameClassified},
           checked: [...], verdict: "OK"|"NO-MEMBERS"|"LEAK:<类>"|"UNCHECKED:<类>" }
```
> - **谁能调**：任何研究员、任何审查者、任何门（写产物前一行）；零依赖、零 API、单文件
> - **它不猜分子**：只审分母。因为本 lab 的 7 次翻车全在分母上
> - **五态里两个是拒绝态**：`NO-MEMBERS`（分母 0 ⇒ 不许写比值）、`UNCHECKED`（有类没查 ⇒ 不许写 PASS）
> - **6 条人造答案 6/6 PASS**

**④ 换一个载体还成立吗**（★ 它自己说这是「面与普通观察的分界线」）：

| 载体 | verdict |
|---|---|
| `runs/*.jsonl` 按行 | `LEAK:DUP+TZ` |
| `runs/*.jsonl` 按批 | `LEAK:TZ` |
| `outbox/*.md` 按标题 | `LEAK:NAME` |
| `outbox/*.md` 不声明标题 | `UNCHECKED:BACKUP+TZ` |

> **三类成立，一类必须降级为声明式**（BACKUP 不可通用）。
> ⇒ 这不是缺点，是边界。

### 2.2 ★★★ 它还自己记了两处自伤

1. v1 的 BACKUP 类**在真语料上假警报 10 倍**（报 31 行，实际 3 行）⇒ **修法先咬自己**
2. 6 条人造答案**第一版只过 4/6** ⇒ 规则：泄漏类必须先声明载体有没有那条轴

## 5. 顺带修的第二处：配额口径

第一版配额判据是「自审数 ≥ 研究结论数（只数 `P<数字>`）」——
★★ **它把 `面-denom` 这类真研究漏掉了**（纪律㉞：口径太窄）。

改为**占比**：

```ts
/** 自审占比 ≥ 50% 就停（三个角度里 `先怀疑量具` 占 1/3，50% 是宽裕的上限） */
if (share >= 0.5) return { allowed: false, ... };
```

实测：
```
生病时  34/54 = 63%  ⇒ 停
三角度正常 ≈ 1/3     ⇒ 放行
```
