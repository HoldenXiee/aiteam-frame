## 一、旧的那份为什么废掉（不是审美）

| 病 | 具体表现 |
|---|---|
| **只画了活动，没画研究** | 能答「谁跟谁说话、规则触发几次」，答不了「这条实验在测什么、测出了什么」 |
| **实验内部完全缺失** | 只有计数曲线；**没有载体跑的命令、真实输出、退出码、耗时** |
| **一屏塞四件事** | 泳道+产物+争辩+轴标，元素上千 ⇒ 什么都在、什么都看不清 |
| **视觉像 AI 默认稿** | 深底+荧光青+圆角小卡 —— 正是 impeccable 的 `dark-glow` / `ai-color-palette` / `nest-ted-cards` |

★★ 结论：要换的是**信息结构**（谁上屏、一次显示多少、点下去看什么），不是换个库重画。

## 二、新结构：导出器 / 页面 彻底分开

```
research/clusters/micro/vizdata.ts   ──(只读账本)──▶  viz-ui/data/hunt.json （3.8MB）
                                                              │  手动选 / 拖入
viz-ui/  (React + Vite，零图表库)      ◀──────────────────────┘
   └─ npm run build ─▶ viz-ui/dist/index.html（**单文件 180KB**，双击即用，零服务）
```

★ 为什么**导出器**单独存在：前端要能双击打开（`file://` 下不能 fetch 本地文件），
所以数据必须是**自包含的一坨**；同时"哪些字段值得画"属于内容判断，不该散在 UI 代码里。

## 三、页面：五个页签 + 一个抽屉

| 页签 | 内容 | 低密度做法 |
|---|---|---|
| **时间轴**（第一屏） | 项目泳道 + 运行/产物/争辩车道 | 默认只开 24 小时；行内只有点与 E 号；**同一位置的点聚成带数字的圆**，点它放大到那一刻 |
| **实验** | 表格 ⇄ 卡片（都要） | 44px 行高，列固定；筛项目/结局/判决 |
| **产物** | 485 份全文，可搜 | 左列名 + 右读原文，单层细线分区 |
| **争辩** | 270 次挑战 + 16 段长文 | 一行一次，判决用色块 |
| **账本** | 来源/成本/事件/封口/库漂移/勘误/外部材料 | 成本**分两栏**：能算的金额 & 明说未声明的行 |

**抽屉（实验内部）** —— 设计者最缺的那块：
载体目录 → 真跑命令（深底等宽）→ **真实输出**（18 行折叠，可展开全部）→ 退出码 / 耗时 →
对照（预期失败的那次）→ 跑前预期（★ 是否**早于**执行、在 PREREG 第几行逐字命中）→
现象 / 同侪判决 / 模型 / 外部核对 / 猜想状态 / 来源 URL。

## 四、实现里踩到的三个「**静默白屏**」（这轮最值得记的）

| # | 现象 | 真因 | 修 |
|---|---|---|---|
| 1 | `file://` 打开**全白** | ES module 脚本被 CORS 拒绝（`Cross origin requests are only supported for http/https`） | 打成 **IIFE** 并把 JS/CSS **内联**成单文件 |
| 2 | 内联后仍全白，控制台只有 `Minified React error #299` | 内联脚本留在 `<head>` ⇒ 原本 `type="module"` 是**延迟**执行，变普通 `<script>` 后**同步**执行，`<div id="root">` 还没解析 | 脚本挪到 `</body>` **前**，并加断言「脚本必须在 root 之后」 |
| 3 | 脚本说"内联成功"，但标签还在 | `String.replace` 的**替换串**里 `$&` / `` $` `` / `$1` 会被当特殊序列解释，打包后的 JS 里到处是 `$` ⇒ 把原标签又插回去 | 改用**函数形式**替换 |

★★★ 三个的共同点：**表现都是白屏，几乎不给提示**。
所以现在每条都配了**显式断言**（宁可构建失败）：标签没内联 → 报错；`</script>` 数量不对 → 报错；
脚本位置在 root 之前 → 报错。这与「量具必须证明它该失败时会失败」（纪律㉙）是同一条。

★ 第四个小坑：`fmtDur(字数)` 把「16 段辩论共 10.8s」当成了时长（字数不是毫秒）—— 已改成"共 N 字"。
再次印证：**字段名对不上语义时，页面会一本正经地撒谎**。

## 六、边界（别把图当结论）

1. **研究问题不该由界面预设** —— 页面把全部数据摆出来，选什么看是你的事（你的原话）。
2. **结局/判决/现象全照抄账本**，页面不做二次判定；「这条研究好不好」是人的判断。
3. **产物时间 = 文件 mtime**（最后一次被写），不是首次出现。
4. **成本只 1/6 行有金额** —— 页面写明"只能算 1/6 行"，不补不猜。
5. **拓扑事件只有 593 条**（旧日志清过），"每小时事件数"只覆盖有日志的那几小时。
6. `file://` 下不能自动取本地文件（浏览器同源策略）⇒ **每次要手动选一次 JSON**；跑本地服务时可用 `?data=相对路径`。
