## 五、修法（已落地并验证）

### ① 单实例锁 `lock.ts`

- 启动**先抢锁**（在 `mkdir`/`writeFile` **之前** —— 否则并发者已经清了 `_topology.log`）
- 锁里写 PID；**PID 还活着 ⇒ 拒绝启动**，文案说清后果与出路
- **陈旧锁自动接管**（否则崩溃一次就再也起不来）
- 退出/`SIGINT`/`SIGTERM` 都释放

**验证**：真实活 PID → 拦住 ✓；陈旧 PID → 接管 ✓

### ② 一条操作纪律（值得进手册）

★★ **停集群不能只杀"启动时看到的 PID"** —— npx/tsx 是**子进程链**。
```powershell
# ★ 正确做法：按命令行杀，不按 PID
Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Where-Object { $_.CommandLine -like '*lab-3b/index.ts*' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```
★★★ **并且启动前先查一遍**（这正是单实例锁要挡的事）。
