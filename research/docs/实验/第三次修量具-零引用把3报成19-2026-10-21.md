# 第三次修我的量具：「零引用」把 3 报成了 19（2026-10-21）

---

## 0. 一句话

★★★★★ **「散记」这个代理量基本失效** —— 真孤岛只有 **3 份（3%）**，我报了 **19 份（18%）**，夸大了 **6 倍**。
而且「最孤立的最长」是**前 3 名的错觉**，真孤岛比平均**更短**。

---

## 1. 我怎么错的

```ts
// 旧判据：只数出度
const isolated = all.filter(x => x.cites === 0);   // ← 「它没引用别人」
```

★★★ **「没引用别人」不等于「被孤立」**：
别的章引用它、它不引用别人 ⇒ 那是**源头章**，本来就该如此。

### 实测分解（103 份）

| 角色 | 判据 | 份数 | 是不是病 |
|---|---|---|---|
| ★★ **island** | 出 0 **且** 入 0 | **3** | ✔ 真散记 |
| **source** | 出 0、入 >0 | **16** | ✘ 源头，正常 |
| **sink** | 出 >0、入 0 | **14** | ✘ 综述型，正常 |
| **connected** | 两边都 >0 | 70 | ✘ |

### 1.1 ★★★ 而且「最孤立的最长」是错觉

| | 字数 |
|---|---|
| 真孤岛 3 份 | **13663 / 10660 / 5543** |
| 平均（103 份）| **约 20000** |
| 最长的 2 份（我曾当成"最孤立"）| 39039 / 26298 —— ★ 它们是 **source**，被别人引用 |

★★ 我此前写「最孤立的 5 份全是最长的（37984 / 27957 / …）」——
★★★ **那是只看了排序里的前几名**，把"引用最少"当成了"最孤立"。

---

## 2. ★★★ 为什么这个错比我以为的严重

### 2.1 这个错数**每轮都被递给集群**

```ts
`## 📌 书的形状：${z.length}/${r.all.length} 份是**孤立的小岛**（零引用）`
```

⇒ 集群每轮都看到「19 份是孤岛」，**于是去救 16 份本来就好的源头章**。

★★ 这与 seal 那次是同一个失败模式：
**量具贴错标签 ⇒ 逼被测对象做无用功。**

### 2.2 而且它污染了趋势判断

我一直报「零引用 52% → 30% → 18%」，把它当成"在变好"的证据。
★ 现在知道：那个比例的主体是**源头章的多少**，跟"散记"关系不大。

---

## 3. 修法

```ts
export type Isolation = {
  cites: number;      // ★ 出度（它引用了谁）
  citedBy: number;    // ★★★ 入度（谁引用了它）—— 这一半是这次补的
  role: "island" | "source" | "sink" | "connected";
};
// ★ 只有两边都为零才是散记
const isolated = all.filter(x => x.role === "island");
```

### 3.1 读数现在长这样

```
103 份 · 平均引用 3.7 份
★★ 真孤岛 3 份（3%，★ 出 0 且入 0）
· 只出零 16 份（★ 被依赖的源头，正常）
· 只入零 14 份（★ 综述型，正常）
```

★★★ 三种角色**分开报** —— 这样集群不会把"源头"当成"病人"。

### 3.2 真孤岛名单（3 份）

```
13663 字 · 实践-一条是什么-一句话在真代码上缺的那一格
10660 字 · 理论-两笔账-内容余与记账税-落地失败的分解
 5543 字 · 实践-修好一项下一项就暴露-三元合取的瓶颈会搬家
```

## 4. ★★★ 这是第三次，而且三次都是同一个病

| # | 我的错 | 真值 | 差 |
|---|---|---|---|
| 1 | 用**当前 mtime** 判"两次签字间产物变过没有" | 60/61 没动 | 真值 **13/61** |
| 2 | 用**全部历史**当"机制出生后"的分母 | 96% 没覆盖 | 真值 **~70% 已覆盖** |
| 3 | 用**出度**判"孤立" | 19 份散记 | 真值 **3 份** |

★★★ **三次都是「口径里混进了不属于这个问题的东西」**：

| 混进了什么 |
|---|
| 现在的时间（当成了当时） |
| 机制出生前的数据（当成了它的绩效） |
| 入度为零的另一半（当成了"没被依赖"） |

★ 而**三次都是集群发现的，不是我自查的**。

⇒ 这给了一个可执行的判据（补进纪律）：

> **报一个比例之前，先问「分母/分子里有没有混进不属于这个问题的东西」。**

## 6. ★★★ 这对"书是不是散记"意味着什么

★ 我之前的判断「它是提炼过的实验记录，不是教学材料」**部分依据是错的**（那个 18%/30% 的零引用率）。

★★ 现在诚实的说法：

| 有证据的 | 没有证据的 |
|---|---|
| 真孤岛只有 3 份 ⇒ **书是连着的** | 「散记」不是主要病 |
| 术语未定义 0% | — |
| 前置倒挂（承重）0 处 | — |
| 引用落空 13% | — |
| ★ 但**读者能不能学会**，我一个数都没有 | ✘ 这是真缺口 |

★★★ **我的所有判据量的都是「书内部自洽」，没有一个量「人能不能学会」。**

★ 而设计者的原话是：「**如果学过前置知识（或类似知识）就能轻松学会**」。

⇒ 下一个该造的判据，应该是**那个**，而不是继续修自洽性。
