# 认知规律：把「能不能顺着学」变成可算的量（2026-10-20）

> 设计者原话（这一整个模块的设计依据，逐字）：
> 「其实主要的就是**违反了人的认知规律**，在学习陌生知识，
> **如果学过前置知识（或类似知识）就能轻松学会**，
> 反正**要符合人的认知规律**」

---

## 0. ★★★ 这句话我之前没听懂

我上一轮的诊断是「术语多 + 结构乱」，然后打算治这两样。

★★ 设计者指出的是**更根本的东西**：不是"词多"，是**认知顺序错了**。

> 学陌生知识时，**学过前置知识就能轻松学会**。

⇒ **一本书如果要求你"先懂后面才能懂前面"，它就违反了认知规律。**

★ 术语多是这个错误的**症状**（因为没定义就用 = 假定读者已知），
结构乱是这个错误的**另一个症状**（顺序不是按学习依赖排的）。

---

## 1. 翻译成两个可算的量

### 1.1 前置倒挂（forward reference）

```
一份产物引用了排在它**后面**的东西
⇒ 读者必须"先读后面才能懂前面"
⇒ 违反前置知识律
```

★ **为什么不算是内容判断**：只问「提到了谁 + 谁排得晚」，
不判断该不该引用、也不定该怎么重排。

★★ 合格的教科书：**倒挂 = 0**（所有引用都指向已在前面讲过的内容）。

### 1.2 术语未定义率

```
正文用到的黑话，有多少在定义页里出现过
```

★ 认知规律的另一半：**第一次出现的词必须当场定义**，否则读者停在那里，后面全白读。

★★ 同样不判"定义得好不好"，只判**有没有出现过**。

## 2. ★★★ 实测读数

```
order  目录 29 份 · ★ 前置倒挂 8 份（28%）· 倒挂 9 处 · 最远跨 27 份
terms  黑话 2914 次 · 41 种 · ★ 定义页没覆盖 21 种（51%）
       未定义：Arm H_CONTENT_NEEDED H_w J2 J3p J49 J5b R0 R1 R10 R11 R12 W3 W4 κ κ2 …
```

### 2.1 ★★★ 「最远跨 27 份」是什么意思

目录 29 份。**读者读到第 1 份，就被要求理解第 28 份的产物。**

⇒ 这就是「违反认知规律」的**最硬证据**：
不是"有点乱"，是**顺序系统性倒置**。

### 2.2 为什么只有 28% 有倒挂，问题却这么重

★ 因为**大部分产物根本不引用任何东西**（零引用 38%）。

⇒ 那 38% 的问题不是"倒挂"，是**完全切断**：读者读到它，不知道前面哪份是它的前提。

★★ 两个数合起来看才是完整的病：

| 病 | 比例 |
|---|---|
| ★ 零引用（无来处，读者不知从哪读起）| **38%** |
| ★★ 前置倒挂（引用的是后面才讲的）| **28%** |
| 引用且正序（正常）| 约 34% |

### 2.3 术语：定义页只覆盖一半

定义页里已经有了 `PREREG` / `arm` / `matched` / `fp` / `R7` / `S1Q1` / `2×2` / `J99` …
★ 但 **`R0`–`R12`、`W3/W4`、`J2/J3p/J49/J5b`、`κ/κ2`、`H_w`** 全部没定义。

★★ 问题在于：**定义了 R7 却没定义 R1-R6** —— 读者读到 R3 时无处可查。

## 3. 我在这一轮修的自己的错

### 3.1 判据把表格读数当成了术语

第一次跑：
```
未定义 54 个：00×4 0×0 0×4 0×7 0×8 10×3 11×6 12×12 …
```

★ 这些是**表格里的落地率读数**（"0/4 落地"写成 `0×4`），不是术语。

⇒ 修：只认 `2x2` 这种**实验设计名**，不认 `数字×数字`。
★★ 修后：54 种 → **41 种**，未定义 23 → 21。

### 3.2 一个我以为有的缺陷，实测没有

我担心：两份文件名前 12 字相同 ⇒ 判据分不清谁引用谁。

★★ 实测**不会** —— 代码里 `if (g === f) continue` 正确跳过了自身。
★ 假设作废，不需要修（已写进测试注释，省得以后再猜）。
