### 为什么会这样？（不是懒，是方法的结构）

```
1. 跑一个系统
2. 看它哪里坏了（卡死/漏检/烧钱）
3. 归因到某个 LLM 本性
4. 写"该怎么做"来避免它
```

**这个流程的产出必然是"别做错"** —— 因为**起点是故障**。

> ★ 要产出"利用"，起点必须是**成功**或**特性**，不是故障。

## 1. ⚠️ 先更正一个我犯的错（留痕）

**初稿里我把「成本几乎为零的智力」翻译成了"速率"，这是偷换。**

| 我说的 | 实际是 |
|---|---|
| Shannon 的 `R`（速率） | **信道里每秒传的比特数** |
| 我实验里的 token | **模型 API 的计费单位** |
| `DESIGN.md` 里的「成本几乎为零」 | ★ **智力便宜**（一个类比） |

**三个不同的东西，我当成了一回事。**

更糟的是：**你的话里便宜的是「智力」，不是「token」。**

> 「有效且高质量地使用这**成本几乎为零的智力**」

**智力便宜 ≠ token 便宜。**
- token 便宜只是**智能便宜的当前定价形式**（而且会变）
- 智力便宜说的是：★ **一个"能想事情的东西"几乎不要钱**

**这不是学术洁癖**：两者导出的设计不同。

| 按「token 便宜」设计 | 按「智力便宜」设计 |
|---|---|
| 多跑几遍摊平成本 | ★ **如果"想事情"不要钱，什么样的系统值得搭？** |

**后者才是 `DESIGN.md` 说的那个范式。**

### 那信息论还剩什么用？

**只剩一个形状，而且是个朴素的形状：**

**这个形状是对的**，而且它跟我要问的是同一件事。
**我不该把它叫"速率"，也不该假装在做信息论的正统换算。**

**正确的说法**：本文借的是**「存在一条权衡曲线」这个形状**，

**不是** token、不是比特、不是秒。

## 2. 借来的形状：一条**投入-质量**权衡曲线

```
质量（产物多好）
  │
  │╲
  │ ╲   ← 这条曲线存在吗？是什么形状？是「物理定律」还是「工程限制」？
  │  ╲
  │   ╲___
  └──────────── 投入（跑几遍 / 派几个 / 想多久）
```

★ **它说的是：不存在"又省又好"的免费午餐 —— 只存在"你愿意投入多少换多少质量"。**

### 这直接重构了我已有的全部发现

| 我的发现 | 用这条曲线说 |
|---|---|
| **P6**：衰减便宜 42%、漏检 3% | ★ **这就是在曲线上选了一个点**：用一点质量换掉了大量投入 |
| **F′**：给清单多花 2.4 倍，准确率不变 | ★ **往右走但没往上走** —— 曲线外的点，纯浪费 |
| **P1**：代价方差 40×、结果一样 | ★ 投入在**曲线外波动** —— 花更多钱没买到更高质量 |
| **P5**：盲猜 192 次调用 | ★ 投入**爆炸**而质量**反而更低**（没找到） |

### ★★ 关键的区别

> **我一直在问「该怎么做」，而正确的问法是「我现在在曲线的哪一点上」。**

| 旧问法（我做实验的方式） | 新问法 |
|---|---|
| 它卡死了，怎么救？ | 这次运行在曲线的哪一点？ |
| 给清单好不好？ | 给清单把点往哪移了？ |
| 哪种系统更好？ | 哪个系统的曲线**整体更靠左上**？ |

★ **新问法立刻产出一个可测的东西**：
**画出不同系统设计的曲线，看它们是"在曲线上移动"还是"把曲线整体推上去"。**

- **在曲线上移动** = 调节（不是改进）
- **曲线整体上移** = ★ **真正的设计改进**

> ★ **这正好是 `DESIGN.md` 的戊类（怎么去思考去优化）**：
> **变量能移动点的位置；设计能把曲线整体抬起来。**

## 3. **质量度量本身就是设计决策**（这是 `DESIGN.md` 甲类）

"产物多好"里的 **"好" 是你定义的**。而 ML 领域有个重要修正
（[Blau & Michaeli 2019](https://proceedings.mlr.press/v97/blau19a/blau19a.pdf)）：

> **低失真 ≠ 高感知质量**，而且**优化一个常常牺牲另一个**。

★ 这对我们**直接相关**：

| 我现在的判据 | 它测的是什么 |
|---|---|
| T-A：分组对不对（二值） | **任务是否达成** |
| token / 秒 | **投入** |
| ❌ 完全没测 | ★ **产物的可用性** —— 拿去做事够不够好 |

**这解释了「四栏空着的『质量』那一栏为什么空」**：
我一直把「质量」等同于「任务判据过没过」，
**而这两件事可以互相牺牲。**

> ★ **所以「质量」不是一个指标，是一条独立的轴。**

## 4. 回到 `DESIGN.md` 原文：丙类缺的是什么

重读这两句，现在读出不一样的东西：

> 「**有效且高质量**地使用这成本几乎为零的智力」

★ **「有效」和「高质量」是两个词，不是同义词。**
- 有效 = **任务达成**
- 高质量 = ★ **另一条独立的轴**（产物的可用性）

**我一直在只优化第一个。** 这就是为什么四栏里「质量」空着。

> 「**因为有什么特性，所以可以怎么利用**」

★ **丙类的正确起点不是【故障】，是【特性】**。
而 LLM 最独特的特性，就是你点出的那句：**成本几乎为零**。

**这个特性（丙类的起点）能开出什么？**

| 特性（乙类发现的） | 可以怎么利用（丙类） |
|---|---|
| ★ **智力几乎不要钱** | **多做几次不心疼** —— 冗余、多版本、反复重跑 |
| 采样有随机性（B4） | **用随机性当探索** —— 同一个问题走不同的路 |
| 不主动分工（B2） | **分工由代码写死**（P3 已得） |
| 无状态（B5） | **上下文要自己搬**（⇒ 交接面设计） |

★ **而这些恰好就是那条曲线横轴上的动作**：
**用投入（次数）换质量 —— 而当投入几乎免费时，这个交换的代价是零。**

> ★★ **所以那句话的意思是**：
> **智力几乎不要钱 = 那条曲线的横轴上，往右走几乎不花代价。**
>
> **所以整个"新范式"的核心问题变成：**
> **在一个"投入几乎免费"的世界里，最优的设计是什么？**
>
> ⚠ 而我的所有实验**都在"省 token"** ——
> **`DESIGN.md` 说的是"成本几乎为零"，而我一直在按"成本很高"来设计。**

## 5. 三条立刻可做的东西

### ★ ① 画出第一条**投入-质量曲线**

**问题**：同一个任务，扫「投入多少」（派几个 agent / 跑几遍 / 给多大上下文）× 看「产物多好」。

**观测量**：投入（token、agent 数、回合数）× 质量分。

**判别力**（三种结果都有价值）：
- 曲线**光滑上升** → 有真实权衡，可以谈"最优工作点"
- 曲线是**阶梯** → 存在**阈值**（比光滑更可操作）
- **没有单调关系** → ★ **"多投入就更好"是假的** —— 直接推翻一大批"给它更多"的做法

> ★ 这条**把我所有散落的发现统一到一张图上**，而且**可测、可画、结论硬**。

### ★ ② 测「**零成本冗余**」—— 第一条丙类做法

**问题**：N 遍取交集 vs 精心跑 1 遍，哪个产物更好？

★ **这是"用投入换质量"的直接实验**：遍数 = 投入，交集质量 = 质量。
**判别力**（正反都有价值）：
- 取交集更好 → ★ **一条丙类做法**（"用次数换质量"）
- 取交集没用 → ★ **说明它的错误是系统的而非随机的** —— 同样是硬结论

> ★ **这条同时填 `DESIGN.md` 的丙类，和「成本几乎为零的后果」那一栏。**

### ★ ③ 把「**质量**」做成一条独立的轴（不是二值判据）

**问题**：怎么量"产物拿去做事够不够好"？

**可判的方案**（不用人评）：
- **覆盖度 + 精确度**：`groupsFound/真组数` 与 `groupsFalse` —— **已是计数，只需合成**
- **可核对性**：产物里每个断言能不能对回原文
- **稳健性**：多份产物的一致性（②天然产出）

> ★ **没有这条，①②都做不了** —— 而它正好是那四栏里最根本的「质量」。

## 6. 结论：实验规划需要怎么跟

### 对照结论

**不是做得不对 —— `DESIGN.md` 的五类都算。是我五类里只做了乙/丁两类。**

| 现状 | 该有的 |
|---|---|
| 5 条做法全是乙/丁类 | 补**丙类**（从【特性】出发，不从【故障】出发） |
| 我在"省 token" | 若投入真便宜，**该问"怎么花"而不是"怎么省"** |
| 判据二值 | 需要一条**独立的"质量"轴** —— 否则曲线画不出来 |

### 规划的调整

```
★ 新增 ③  质量度量            ← 那两栏的共同前置（四栏里最根本的空）
★ 新增 ①  投入-质量曲线         ← 从无到有建立坐标系；把已有 5 条全部重新安置
★ 新增 ②  零成本冗余            ← 第一条丙类做法
原有  G  可分解程度            ← 判据现成，仍值得做
原有  A  沙箱编排
原有  D  T-E / O2
原有  E  跨任务验证
```

★ **原候选 B（零成本冗余）与 ② 合并** —— 它们是同一件事。

**新顺序**：`③质量度量 → ①投入-质量曲线 → ②零成本冗余 → G → A → D → E`

> ★ **为什么把这三条提到最前**：
> 1. **它们填的是空栏**（丙类 / 质量 / 成本几乎为零的后果）—— 空栏说明我在**重复生产同一类成果**
> 2. ★ **它们互相咬合**：③ 是 ①② 的前置，① 是 ② 的坐标系
> 3. **① 能把已有的 5 条全部重新安置** —— 这是整体感的来源
