# projection-named

## 什么时候用

写任何「成立 / 解除 / 判不出 / 差 N 点 / p=…」的判决，或把别人的一个数转引进自己的标题、表格格、结论句时。

## 判据（★ 能判死）

一律在判决句里写出它是在哪个读法（整份产物 / 只喂主表 / 关系级）与哪个源集（书源 / 草稿 / 哪份 jsonl）下量的；禁止出现「p=… ⇒ 解除/成立」而不带读法；禁止把一个源集的数与另一个源集的数拼进同一个表格格。

## 怎样算违反

`理论-成员边界与基数` v8 §① 写「num vs gap2：p = 0.0014 ⇒ (b) 解除」——这是**交付口径**（整份产物喂 judge2）；同一批**内容口径**（只喂主表）是 num 7/8 vs gap2 8/8、p=1.0、差 0。两种都真，结论相反，而句子没写读法 ⇒ 读者按它把一条挂账关掉，机制其实没被检验。同型：`理论-词的划界` §0 表 A 写「7 行被判（只覆盖 4 对）」——7 行来自 `lb5-trace.json`（实际是 U2+P8 = 8 行），4 对来自目标单（5 行覆盖 4 对），两个源集拼成一格，7/4 两边都不成立。

## 为什么需要它（★ 实测证据）

本轮复算：`work/theory/b-layer/verify.out.txt` 逐行打出 task5 的两个口径（交付：open 0/8、num 1/8、gap 7/8、gap2 8/8；内容：6/8、7/8、7/8、8/8），同一批数据同一判据，num vs gap2 的 p 从 0.0014 变 1.0。同一份 `理论-成员边界` 文件里 v8「解除」与 §7「未解除」相隔 239 行并存，读者无论读到哪个都以为自己读完了。`work/landing/{lb5,order}/lb5-trace.json` 两份同名文件逐字节形状相同：10 行、U2/P8、P 覆盖 6 对。

## 怎么做

写作时按三步落到字面：

1. **先写主语住在哪一层。** 「谁更值钱 / 谁更准」的主语若是主表里的成员，就用内容口径；若是「交出去的产物能不能被验收」，就用交付口径。主语决定读法，不是读法决定结论。
2. **同一批各算一遍，再下判决。** 两个读法的判决不同 ⇒ 不是「哪个对」，是**你的条件缺了「读法」这一层**：把它补进条件，而不是把结论二选一。补法示例：「(b) 在**内容口径**下解除 ⇔ num 与 gap 的内容落地差 ≥3/4 且 Fisher p<0.05」。
3. **转引别人的数时连口径一起搬。** 只搬数不搬口径 = 把一个集合的元素贴到另一个集合的格子里。表格里每个数都要能回答「这个格的分母是谁」。若一时查不到口径，就在格里写「口径未标（不可转引）」，不要写一半。

★ 自查（跑前 0 token）：把你要写的那句读一遍，问「另一个读法下这个判决会反过来吗？」会 ⇒ 补读法。答不出 ⇒ 你还没算另一个读法，先别写「解除」。
