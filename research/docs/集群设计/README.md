# 集群设计（两个集群分开）

★ 设计者裁定（2026-10-19）：
> 「在这建两个文件夹，把这两个研究员集群的设计文档**分开放**。」

| 文件夹 | 集群 | 它的活 |
|---|---|---|
| [`hunt/`](hunt/) | **第一集群**（主线） | 广探索 / 冗余 / 创新 —— **宁可重复、宁可错，只怕没找到** |
| [`forge/`](forge/) | **第二集群**（沉淀） | 产出本方向的最终产物 `research/book`（教科书）|

★ **两个集群必须分开优化**（设计者逐字）：
> 「两个必须分开，两个集群的职责不同，**不可能同时优化，只能分开优化**，
> 只有分开优化，最终才都能实现好的结果。」

---

## 为什么必须分开

★★ 因为**两种工作的失败模式不同**：

| | 失败时看起来像什么 | 该催它做什么 |
|---|---|---|
| `hunt` | **没找到** | 多开一条线 |
| `forge` | **还在一条条散记，只是写得更长** | 长出新概念 |

★ 同一个动作（比如"多开一条线"）在 `hunt` 里是**治**，在 `forge` 里是**病**。
⇒ 所以它们的文档、优化、判据都不能混着放。
