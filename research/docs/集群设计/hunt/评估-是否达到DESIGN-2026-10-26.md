1. **「猜想必须标未验证」** —— 现在的合规是**表头级**的（列名叫"猜想（未验证）"），不是逐条标注。

2. **人造答案率从未进读数** —— 这是 DESIGN §7 的③，我到现在才粗测（57%）。**它是硬要求却没人守**。
3. **有出处 46%** —— 一半实验的出处**全是本仓**（49/91 一个外部都没有）。

### 但有一条硬边界

**判"补的" 34%（31/91）**，而且**四段持平**（40 / 40 / 25 / 44%）——
说明"先看读数再编预期"是**结构性习惯**，没有随机制改进而下降。

⇒ 诚实的说法：**创新是真的，但每三条"发现"里有一条是把事后解释当成事前预期**。
这正是收敛门**至今未通过**的原因（它把 31 条"补的"当证据引用）。
★ 我判不了"哪条现象是真意外"（内容判断），机器能做的（逐字 PREREG + 同侪审 + 作者自签拒绝）已经都做了。

## 三、能大量从网上获取灵感吗：**能，且不是自我循环**

### 能力面（用**生产 spec** 验过，纪律㊸）

```
runner.ts L368:  permissions: { only: [...ALL_TOOLS, ...WEB_TOOLS] }
paths.ts  WEB_TOOLS = web_search · fetch_content · get_search_content · source_check
```
⇒ 研究员手上**真的有** 4 个 web 工具（不是"装了就以为有"）。

### 使用面（落盘证据）

| 读数 | 值 |
|---|---|
| 带真实 `http(s)` 出处的实验 | **40/91（44%）** |
| 带 arXiv / DOI 的 | 11 |
| 带 RFC / ISO 标准号的 | 6 |
| 产物里带真实 URL 的 | 64/422 |
| 灵感叹道｜③外部材料 | **61（15%）** |
| 抽验 URL 真实性 | **5/6 HTTP 200**（第 6 条 `ncbi.nlm.nih.gov/pmc` 根路径 403/超时 —— 不是编的）|
| 域名分布 | rfc-editor · itl.nist.gov · arxiv · pmc.ncbi · icmje · man7 · MDN · junit · cwe.mitre · hl7 · tc39 · handwiki · pmd-code |

★ 域名横跨**标准组织 / 统计学手册 / 学术预印本 / 医学研究伦理 / 工具文档 / 安全分类法**——
不是同一个圈子的自我引用。

### 三条边界（照实写）

1. **"大量"只对一半成立**：49/91 实验**一个外部都没有**（纯本仓）。
   ⇒ 网上灵感是**主要通道之一**，不是全部。
2. **设计者投放的那 1 篇，引用 0**。
   今天才把**路径**写进处境表（之前只有聚合计数"外部材料 61"，它不知道有这个东西，
   这是第 22 次"写好了没接上"）。**只有 1 轮**，还看不出效果。
3. ★ **我量不到"搜了多少次"** —— 使用账只记我自己造的 5 个工具，
   `web_search`/`fetch_content` 是 pi-web-access 的，**没有日志**。
   ⇒ 我能说"多少灵感进了账"，不能说"它搜了多少"。
   **这是下一个要接的读数**（在扩展里包一层 `tool_call` 日志即可）。
