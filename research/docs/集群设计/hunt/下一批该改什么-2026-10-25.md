## 二、真正的结构问题：**两套账互不相通**

我打开 `CONVERGED.md`（这个 lab 的**收敛状态表**，决定"能不能停"）看它的形状：

```
| claim（一句话） | 证据 id | 状态 |
| 代价线在「要读全」的活上掉完整性 | `P25` | 🔁 被 P26 取代 |
| 服从由完成成本门控 | `P30`、`cross-off-small` | ⚠ +容量限定 |
```

**236 行状态表，证据 id 全是 `P*`（旧的自由文本产物）与脚本名。**

而新的结构化实验 `E1…E20`（可跑装置 + 现象 + 模型 + 同侪审查）
—— **一条都没进这张表**。

| 账 | 内容 | 谁在用 |
|---|---|---|
| `CONVERGED.md` 236 行 | 旧的 `P*` 文本 | ★ 决定「能不能停」 |
| `work/experiments.jsonl` 99 条 | 新的 `E*` 结构化 | ★ 只有我的读数在看 |

★★★ 后果：**我做的所有质量门（现象要被同侪认过、判补的不算发现型）
对"这个 lab 说自己收敛了没有"完全没有影响。**

它可以说"我收敛了"，而那张表里**没有一个结论经过新门**。
这正是 forge 曾经栽过的那个坑：**举证 ≠ 可用**；这里是 **有账 ≠ 入门**。

## 三、所以下一批只改一件事

> **收敛状态表的「证据 id」必须能指到结构化实验，且必须是
> 「被独立审过、且没被判补的」。**

这是**纯形式判据**（我能做），也是 DESIGN 要的形态：
forge 有共识门挡着书，hunt 现在需要一道门挡着**它自己的"我收敛了"**。

具体：
1. 解析 `CONVERGED.md` 状态表 → 取每行「证据 id」列 → 认 `E\d+`
2. 读数三项：
   - 状态表里引用了几条 `E*`
   - 其中**未审的**几条
   - 其中**被判补的**几条
3. 投递：把这个数摆出来，并说明「**没经过新门的结论，不许写进"我收敛了"**」
4. 收尾：把"状态表引用了未审/补的实验"列为**欠账**，下一轮先清

★ 不改的：`CONVERGED.md` 的内容（那是集群的活）。
★ 我只做**读数 + 门槛**，不替我判断哪条结论站得住。

## 四、一件必须照实说的话

**我做了一整轮质量门，但它接在自己身上，没接在这件事的出口上。**

- 出口是 `CONVERGED.md` → 谁能说"我收敛了"
- 而我的门装在了 `experiments.jsonl` → 只有我自己读的数

★ 这和「写好了没接上」是同一种病，只是这次**不是代码没接上，是判断没接上出口**。

⇒ 修法就是 §三。这也解释了为什么"审查覆盖率 40%"不是最要紧的：
就算 100% 审完，只要 `CONVERGED.md` 不认 `E*`，那个质量对 lab 的行为**零影响**。

## 五、改完的一轮实测（r21 / r22，各约 55 分钟）

| 判据 | r21 | r22 |
|---|---|---|
| 结构化实验 | 9 | 7 |
| 现象 / 模型 / 猜想 | 9/9/9 | 7/7/7 |
| 跨载体成立 | 5 | 5 |
| 现象被独立审 | 3（判补 1）| 4（判补 1）|
| **收敛门** | **未通过**（引用 E1·E2·E6，**E6 未审**）| **通过**（引用 E2，已审）|
| 链深 ≥3 的项目 | 2 | 2 |

★★★ **门一轮就动了**：r22 的状态表第一次引用了**结构化实验 E2**，而且是被人审过的。
在此之前（r20 之前）状态表的证据 id **全是 `P*`**。

### ★★ 但这道门有个明确的洞，必须写下来

r22 是**薄通过**：账上有 7 条结构化实验，它只引了 **1 条**。
门只判"引的对不对"，不判"引够了没有"。

⇒ 这就是"形式判据可被最省力满足"的老问题（我自己栽过多次）。
   **覆盖率**我单独报了（1/7），但**不放进门的判据里** —— 因为
   "引几条才够"是个内容判断（哪些结论需要证据），不是我的活。

### 下一批（按证据排序）

1. ★★★★ **覆盖率靠"欠账"推，不靠门槛卡**：收尾时把"账上有、状态表没引"的实验列成欠账，
   交给下一轮（这是 `closure.ts` 在缺陷账上验证过的手法：结账率 2% → 21%）。
2. ★★★ **一份 PREREG 服务多个实验**要堵（现在同一份 PREREG 可以给 N 条实验当"跑前预期"）。
3. ★★ 旧账 235 份不迁（纪律⑩），但要在读数里**永久并排**。
4. ★ 真外部 URL 波动 20%–75%：`本仓:` 是合法值，这就是它不看外面的口子。
