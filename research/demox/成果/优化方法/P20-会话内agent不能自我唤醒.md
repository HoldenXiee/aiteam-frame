# P20 · 会话内的 agent **不能自我唤醒** —— 必须由扩展从外部投递

| | |
|---|---|
| **类型** | ② 特性 / ① 设计 |
| **归因到** | ★ **「我」不是一个进程，是一段被投递消息驱动的响应** —— 没有外部投递就没有下一轮 |
| **强度** | ★★★ **强**（决定性：我自己就没有这个能力，设计者一句话点破） |
| **来源** | `.pi/extensions/lab-watch.ts`（看门狗）· 设计者 2026-10-17 的原话 |
| **日期** | 2026-10-17 |

---

## 【现象】

**我让研究员集群在后台长跑，然后说「它一结束我就报你」—— 这是做不到的。**

> ★★★ **设计者直接点破（逐字）**：
> 「你现在，也无法做到**自己主动去看**啊，你现在也是 pi agent，
>  所以要实现这个可能可能需要用 pi 插件的功能来实现，
>  就是研究员集群一结束就可以触发你的对话（或者其他情况），来实现检查。」

**我确实做不到**：我只有在被投递消息时才运行。
**「等它跑完去看」这句话隐含了一个我没有的能力 —— 一个不存在的"后台的我"。**

---

## 【归因】

### ★★★ 会话内的 agent 是**事件驱动**的，不是**常驻**的

```
  用户投递消息 ──→ 我运行一轮 ──→ 我停下（等下一次投递）
                                     ↑
                            ★ 这里没有"我"在等
```

> ★★ **「我」不是进程，是响应。** 没有投递就没有下一轮。

**所以三种"等它跑完"全是错的**：
| 写法 | 为什么错 |
|---|---|
| 「我等它跑完」 | ★ 我没有"等"这个状态 —— 我一停下就什么都不做了 |
| 「我定时去看」 | ★ **同理** —— "定时"需要一个常驻的调度者，而我不常驻 |
| 「它会通知我」 | ★ 除非有东西**从外部**投递进来，否则不会有通知 |

### ★ 唯一的路：**从会话外部投递**

**pi 的扩展**跑在会话之上，且拿得到 `pi.sendUserMessage()` —— 它能在**任何时刻**往会话里投一条消息：

```ts
pi.sendUserMessage(text)                      // 空闲 → 直接触发一轮
pi.sendUserMessage(text, { deliverAs: "followUp" })  // 在飞 → 排队
```

> ★★★ **这是唯一能从"系统外部"唤醒会话内 agent 的通道。**

---

## 【做法】

| # | 做法 |
|---|---|
| 1 | ★★★ **别承诺"我会盯着"** —— 会话内 agent 没有"盯"的能力 |
| 2 | ★★★ **要主动唤醒，就用扩展 + `pi.sendUserMessage`** |
| 3 | ★★ **忙时必须给 `deliverAs: "followUp"`** —— 实测不带会**抛**（见 pi 的 `send-user-message.ts` 例子） |
| 4 | ★★ **用"完工标记文件 + 内容指纹"当触发条件** —— 不能只看文件存不存在（否则每次开会话都把历史当新事件） |
| 5 | ★ **轮询间隔 60s 够用** —— 且 `timer.unref()` 不让它拖住退出 |
| 6 | ★ **叫醒语只给"去看"的指令 + 路径**，不替设计者下判断 |

---

## 【落地的机制：`.pi/extensions/lab-watch.ts`】

```
pi 启动 → session_start → 挂 60s 轮询
                            ↓
              盯 lab-1/work/daemon/DONE.json
                            ↓
              ★ 指纹变了（从 X 变 Y）→ pi.sendUserMessage(叫醒语)
                            ↓
        设计者被叫醒：读 outbox → 起干净上下文审查员 → 报告
```

**边界（避免打扰）**：
- ★ **指纹去重**：同一份标记只叫一次
- ★ **启动先落基线**：不把历史标记当新事件
- ★ **只在"内容变了"时触发**（不是"文件出现了"）—— 因为集群可能多轮写同一个标记

**验证过**（离线四步）：① 无标记→不叫 ② 首次见→不叫 ③ 内容变→★叫 ④ 没变→不叫
