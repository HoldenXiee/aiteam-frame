## 七、数据流（一轮真实互动的样子）

```
① researcher 读研究手册 → 读 lib/ → 读 research/demox/成果/
② 它设计一个实验 → 写 work/xxx.ts → bash 跑 → 读结果
③ 它写 outbox/A-发现.md
        ↓ ★ 代码看到 outbox 计数 +1
④ 起 inspector（干净上下文，只读）
   它读 outbox/A-发现.md + work/ 核实
   输出：鼓励 / DEFECT: … / VERDICT: …
        ↓
⑤ 它的输出落在哪？ ★★ **落在 _run-log.json 里 —— 但我没把它投回 researcher**
   ★★★ **这是断的。审完的意见没有回到研究员那里。**（见 §六.9）
⑥ researcher 继续（它不知道被审过）
```

★★★ **第 ⑤ 步是断的** —— 我核对了代码（`bench/lab-3.ts` L277-281）：

```ts
.then((r) => {
  tokens += r.usage?.totalTokens ?? 0;
  rec("done", `${s.kind} · tok=…`);   // ★★ 只记了 token，**`r.text`（审查意见正文）被丢掉了**
})
```

★★★ **审查意见的正文根本没落盘，也没投回 researcher。**
★ 所以：**审查员说了什么，只有它自己知道；研究员永远不会知道。**
★★ **这等于没审。**（我在写本文时才核对出来，§六.9）
