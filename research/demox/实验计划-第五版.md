# 实验规划（第五版）：**从"补缺"转向"设计"**

> **更新时间**：2026-10-16 晚 · 研究员指出「规划有问题、没有创新性实验」之后重写
> **本版的做法与前面几版不同** —— 见 §0。

---

## 0. ★ 这一版怎么来的（与前面四版的区别）

**前面四版的做法**：列候选 → 排优先级 → 一个个做。

**结果**：7 条成果**全是同一个形状** ——「它缺 X → 就绕过它 / 补上 X」。
**全是避坑，一条"利用"都没有。**

**本版的做法**（研究员指定的）：
> ★ **每次做之前，都用已有知识重新分析 `DESIGN.md` 的目标 —— 每次都会有不同的想法。**

所以我这次**没有列候选**，而是：

1. **把 `DESIGN.md` 逐句拆开**（§1）
2. **对每一句问：手里的知识能开出什么**（§2）
3. **去数据里挖新的现象**（§3，含一个独立视角的挖掘）
4. **把挖出来的东西变成实验**（§4）

**产出：一批与前面完全不同的实验。**

## 2. 用已有知识重新分析 —— 每句开出什么

### ★ ① 「具体类型该怎么去设计」→ 我从来没扫过**系统形态**本身

手里的知识：
- P3：分工要**代码写死**（模型不会自己分工）
- P6：交接面要**明确衰减或放大**
- P8：**返回值可编程**（往里面放什么，它感知到什么）

★ **这三条合起来指向一个从没做过的问题**：
> **同样是"多 agent"，不同的形态（流水线 / 星形 / 扇出 / 冗余）成本分布、错误模式有什么不同？**

### ★ ③ 「有什么特性可以怎么利用」→ P8 只开了一个头

**P8 证明了"往返回值里放东西"有效。那**还能放什么**？**

- 它**已经读过哪些**（直接治"读 17 遍"）
- **还剩什么没做**（进度）
- **上一步的产物在哪**（P5 的清单）
- **上一棒是怎么想的**（不只是结论）

★ **这不是"补缺"，这是"设计它感知到的世界"—— 而"世界"的边界就是我往里放什么。**

### ★ ④ 「怎么去分析」→ 我建了方法，但没沉淀

已有的分析方法**散在各处**，没变成可复用的条目：
质量分 / 超时两分类 / 跨任务不比质量 / 先问"哪个配置下的"。

★ **它们本身就是 `DESIGN.md` ④ 类的成果 —— 而我把它们当成了工具，没当成果。**

### ★ 第 60 行「人的位置」→ 这条最没碰，而它最根本

> 「**人**是以新的工具去'劳动'……**人的价值就在于去使用知识、工具来改造现实世界**」

重读之后，它问的是：
> ★ **在这个系统里，人**具体做什么动作**？**

**而我从没测过任何"人参与"的系统。**

## 3. ★ 去数据里挖新现象（这轮新做的）

**背景**：234 个 run 有 **11,709 次带参数的完整工具调用** —— 这批数据**此前从没开采过**。

**挖出来 6 个新现象**（细节见各自文档）：

| # | 现象 | 强度 | 属于 `DESIGN.md` 哪类 |
|---|---|---|---|
| N1 | ★★ **跨 agent 重复读 = 28.3%**（同一文件被多个角色各读一遍） | 强 | ① 设计 |
| N2 | ★ **过度合并 **4.4 倍**集中在多 agent**（1% → 7%） | 中 | ① 设计 |
| N3 | ★ **流水线里 S1 独占 63% token，而 S2/S3 在 conclusion 档几乎空转** | 中 | ① 设计 |
| N4 | **`idsFabricated>0` ⇒ 失败 8/8**（100% 精准的失败预测器） | 中 | ④ 分析 |
| N5 | **慢 rep == 胖 rep**（同产出差 40 倍 token，判据完全无感） | 中 | ④ 分析 |
| N6 | **`spawn_reviewer` 13 次调用参数全为空**（委派内容零信息） | 强 | ① 设计 |
| N7 | **成本中心位置随形态翻转**（流水线压在 S1，星型压在 coordinator） | 中 | ① 设计 |

> ★ **其中 N1 最锋利**：**委派省下了"注意力"，但没省下"读入"。**
> 上游读过的原文，下游**全部重读一遍**，而且方向**恒定沿流水线向后**。

## 4. ★ 新实验（从上面的分析里长出来的）

### ★★ 实验 I：**交接面到底该传什么** —— 用 N1 直接驱动

| 项 | 内容 |
|---|---|
| **由来** | N1：28.3% 的 read 是跨 agent 重复。**上游读过的，下游重读一遍** |
| **问题** | ★ **能不能把"读过什么"也当成一种交接物？** |
| **自变量** | 交接内容三档：① 只传结论（现状）② 结论 + **上游读过的文件清单** ③ 结论 + 清单 + **上游从每份里提炼的要点** |
| **观测量** | ★ **跨 agent 重复读率**（N1 的口径）、总 token、任务成败 |
| **为什么是新角度** | 这不是"给枚举手段"（P5，那是**不知道有哪些文件**）——<br>★ 这是**"上游已经知道的东西，怎么传下去"**，是 P8「往返回值里放东西」的推广 |
| **成本** | 低（改 `pipeline` 的一个参数） |
| **判据** | 现成 |

### ★★ 实验 II：**形态扫描** —— `DESIGN.md` ① 类的正面入口

| 项 | 内容 |
|---|---|
| **由来** | N2（过度合并 **4.4 倍**集中在多 agent）+ N3 + N7（成本中心随形态翻转） |
| **问题** | ★ **同一任务的四种形态，成本分布与错误模式各是什么样？** |
| **自变量** | **单 agent / 静态流水线(3) / 星形(1+N) / 冗余(N独立)** —— ★ **全部在同一任务、同一难度上** |
| **观测量** | token 分布（谁吃成本）、**错误模式**（过度合并？漏报？）、通过率 |
| **为什么是新角度** | ★ 我从没**在同一条件下**比较过形态。现有的比较全是跨实验混杂的 |
| **成本** | 中（四个系统都已有） |
| **★ 预期** | N2 的假设是"交接面把相邻的组糊在一起" —— **若静态流水线显著更容易过度合并，假设就成立了** |

### ★★ 实验 III：**把"已读清单"放进返回值** —— 治 N1 的另一半

| 项 | 内容 |
|---|---|
| **由来** | P8 证明了"往返回值里放东西"有效；而 N1 说明"重复读"是大头 |
| **问题** | ★ **在每次工具返回里带上「你已经读过这些文件」，它还会重读吗？** |
| **自变量** | `none` / `read-list`（附已读清单）/ `read-list + 提示语`（"这些你已经读过了"） |
| **观测量** | 重复读率、跨 agent 重复（配合实验 I）、token |
| **为什么是新角度** | **这是 P8 模式的第一步推广 —— 从"放代价"到"放记忆"** |
| **成本** | 低（`onResult` 一行） |

### ★ 实验 IV：**分析方法本身当成果**（④ 类）

| 项 | 内容 |
|---|---|
| **由来** | N4（`idsFabricated` 是 100% 精准的失败预测器）+ N5（胖 rep 判据无感） |
| **问题** | ★ **有没有比"过/不过"更好的**读数**？** |
| **做法** | 把已有的分析方法（质量分 / N4 / N5 / 读目录率 / 跨 agent 重复率）做成一个**标准读数集**，<br>用历史数据回算，看哪个读数**最能预测失败** |
| **为什么是新角度** | ★ 这是 `DESIGN.md` ④ 类 —— **产出是"方法"而不是"做法"**，而我一条都没有 |
| **成本** | ★ **零**（全离线） |

### ★★ 实验 V：**人的位置** —— 唯一没碰的方向

| 项 | 内容 |
|---|---|
| **由来** | `DESIGN.md` 第 60 行，**完全没碰** |
| **问题** | ★ **人在这个系统里，具体做什么动作？** |
| **设计** | 同一任务，三种人参与点：<br>① 全自动（现状）② **人在中途看一次产物、给一句反馈** ③ **人只在结尾验收** |
| **观测量** | 成功率的提升、人的介入次数、成本 |
| **为什么是新角度** | ★ **它把"人的位置"从一句话变成了可测的东西** |
| **成本** | **中**（要模拟"人"，可以先用另一个模型当评审） |
| **⚠ 风险** | 模拟的人和真人不同 —— 结论只能当"上界"看 |

## 5. 顺序与理由

```
① 实验 IV  分析方法（读数据集）      ← 零成本，而且它是后三个的**量尺**
② 实验 I   交接面传什么             ← 直接由最强的现象 N1 驱动
③ 实验 II  形态扫描                 ← DESIGN.md ① 类的正面入口，一次比较四种
④ 实验 III 已读清单进返回值         ← P8 模式的推广
⑤ 实验 V   人的位置                 ← 唯一没碰的方向
```

**为什么把 IV 排第一**：★ **N4/N5 说明我现在的读数（过/不过）对成本与坏模式完全不敏感。**
**先有量尺，后面的实验才有分辨率。**
