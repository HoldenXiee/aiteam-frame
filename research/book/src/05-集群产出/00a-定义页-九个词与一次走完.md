## 0. 一句话：一个数由三样东西决定，而你通常只看见一样

本书里所有的数（落地 X/n、每落地价、召回差、fp 率）都是同一个式子的取值：

```
读数 = f( P ; C , T )
        ↑    ↑   ↑
     产物   契约  真值集   ← 三样里有两样不在产物里，所以产物本身判不了自己
```

★★ **这就是全书最贵的一课**：同一批 48 份产物，`P` 一个字节都没改，只把 `T` 的「延」从层②换成层③，落地 **18/48 → 0/48**（冻结判据 `notesTask.judge`+`judgePin`：`runs/j2x2.jsonl` 9/32 + `runs/r7.jsonl` 9/16）。外人看是「模型失败了 48 次」，实际是**换了一把尺**。⇒ 一个数不写清它落在 `(C, T)` 的哪一格，它**不是命题**。

★ 这个数原来是 **16/48**（来自复刻脚本 `work/mapper/rescore-layer.py`）。它不是采样差，是**两个不同的除法**——差在哪、为什么连集合都不相交，见 §3.5；机制见《数与它的域》§2。**同一个「0/48」在三个量具下都成立**，所以换层那一半不受影响。

依据：`work/practice/runs/j2x2.jsonl`（32 行）+ `work/practice/runs/r7.jsonl`（16 行）= 48 份；冻结判据逐行 `landing` 字段 9+9=18（practice 2026-10-22 独立复算同值：`S1Q1` 6 + `S0Q1` 3 + `q6` 3 + `selfq1` 3 + `selfq3` 3 = 18）；复刻脚本同批给 16/48（`work/mapper/rescore-layer.py`）、修掉两个 BS 字节后 17/48（`work/practice/_rescore-layer-bsfix.py`）、层③三个量具一致 0/48；事故复盘 `work/practice/INCIDENT-16-48-三个量具三个数.md`

## 1. 九个词（每个词后面必须有一句「它判什么死活」）

★ 这一列是这张表的全部价值：**一个词如果判不出「这算、那不算」，它就不该在这里。**「✘ 长得像」是给你的反例——用来在你自己的现场里认出它。

| # | 词 | 一句话定义 | ★ 它判什么死活 | ✘ 长得像但不满足 |
|---|---|---|---|---|
| 1 | **产物 `P`** | 模型这一次交出来的那**一份字节**（一个目录/一个 `report.json`） | 「谁变了」只能指到份，不能指到批：同一批里 `mainMatched` 可以从 0 打到 12（`state` 批 7 轮） | 「这一批模型不行」——那是对 7 份字节的一句话，不是对模型的 |
| 2 | **契约 `K`** | 一句**跑前成文**的规则：`一条 = 什么`、`层 = 哪一层`、`门槛 = 什么` | ★★ 判「**修读数**」还是「**换契约**」：`K` 写了、旧读数违反它 ⇒ 旧数是**假**的（修）；`K` 没写 ⇒ 旧数当年**不是命题**，你是在**立法**（换契约，全部历史不可比）。见《0token 的三种意思》§2.5 | 「判据代码就是契约」——那冻住的是尺子，不是「量的是什么」 |
| 3 | **判据 `C`** | `K` 的**实现**：一段纯函数，输入产物，输出 `matched / fp / anchored`；★ `C` **有作者**（v10） | 判「这份产物的读数能不能复算」：`C` 是纯函数 ⇒ 同一份产物永远同一个数；不是纯函数（读时间、读环境、读人的判断）⇒ 那个数不可审 ★ **可复算 ≠ 有效**（见下）★ **`C` 有作者，而作者这一项的效应本窗口未判出**：人写 2/4 与集群自生 0/4 **是跨批**（`landing2` vs `landing2b`），n=4、精确 Fisher **0.4286**，且四份自生判据各自重写 ⇒ 只读方向（详见 §3 第 0 步 v11） | 让模型自己数自己（自报字段）——那是 `P` 里的一段文本，不是尺子；★ 让集群**写尺**——它是真的写出来了，但这一次**不能把 0/4 归因给“把挂起放首位”**：四轮 `matched` 全 11/12、`pinBoth` 四轮 ≤11、`fp` 反而更好（0,2,0,0）⇒ **三个分量方向不一致，合取 `landing` 的 0 被至少两项同时决定，本批分不开**（机制见《检查的单位……》§4.1） |
| 4 | **真值集 `T`** | 语料 × 谓词 × **层**；`|T|` 是它的基数 | 判「你缺的是条数还是成员」：`|A| < |T|` 是量的问题（数没落到报告里），`A = T` 才叫对 | 「答案表越全越好」——`|T|` 一改，所有历史读数换含义 |
| 5 | **层（延）** | 同一个谓词下**哪些对算真**：层②允许称谓归一（12 对）、层③要字面双向可替换（9 对） | ★ 判「翻面算不算失败」：同一批 48 份，层② **18** → 层③ **0**。翻面的机制是**算术**：层②落地的每一份都含齐 12 对，而 `T2\T3` 的那 3 对在层③里是 `fp` ⇒ 48 份里 **18 份**在层③下 `fp≥3`，**机械排除**，不是读错（逐份与两个数的关系见 `work/practice/INCIDENT-16-48-三个量具三个数.md`、`outbox/理论-数与延…md` §0 v2.1） | 「层③更严格，所以层③才对」——两层的差别是**题目**，不是严格性 |
| 6 | **读法（尺面）** | 同一把尺的**哪一面**：主表（取 pair 形条目最多的那个数组）/ 全产物（`judge` 全量）/ 并集（按对去重后的存在量词） | ★ 判「召回差是产物的还是容器的」：同提示词跨批的主表召回差 **6.5/12**，同一批 rep 的并集差 **1/12** ⇒ **≥5.5 条来自容器**（decomp2 6/6 SPLIT vs j2x2 S0Q1 0/8） | 「两臂按同一判据跑的」——同一判据、不同尺面，照样差 5.5 条 |
| 7a | **落地_严**（闭合世界） | `matched == |T| ∧ fp == 0 ∧ anchored == |T|`；三项**同时**成立才算一次。★ **前提：你能断言 `T` 封闭**（`T` = 全部真对，没有漏在表外的真对） | ★ 判「全对为什么还是 0」：`S1Q1 r0` 主表 `matched 12 / fp 0 / pin 11` ⇒ **不落地**（一个引文只在一侧定位） | 「主表全对」——`实践-主表全对判据判0` 整章就是这个反例 |
| 7b | **落地_封**（开放世界，v8 新增） | `matched == |T| ∧ fp∩D == ∅ ∧ anchored == |T|`；`D` = **跑前声明的干扰集**（你确定不是真对的那些对） | ★ 判「表不全时这份产物还能不能交」：同一批 12 轮里 `cluster` 臂 `fpDistractor` 四轮全 0（按 7b ⇒ **4/4**），而 `fpOther` 1/2/4/6（按 7a ⇒ **0/4**）；`cluster-pred` 臂两种读法 **2/4 vs 3/4** | 「`fp==0`」——`T` 不封闭时它同时量「多报」与「表不全」 |
| 8 | **覆盖 `n`** | 这个率是**哪些轮**算出来的：`批 × 量具 × 臂 × 轮`，三级分别只支持「率 / 方向 / 存在性」。★ **v9：这只回答了「哪些轮」，还差一半——「这些轮彼此差多少」（词 8b）** | ★ 判「这个数能不能当量」：分子来自 24 轮、分母写 48 轮 ⇒ 只能说方向；换过判据实现（哪怕一个字节）⇒ 只能读存在性 | 「n=8」——哪 8 轮？同批同臂吗？跳批了吗？是哪个解析器算的？ |
| 8b | **臂内极差（有效样本，v9 新增）** | 同一个臂**逐轮读数**的极差 ÷ 你要报的那个差。判据一句话：**极差 ≥ 要报的差 ⇒ 只能读方向，不能读量** | ★ 判「同批同臂到底能不能读率」：`state` 批 `E0`（五臂共用 `run_shared`）7 有效轮 `mainMatched`=**0/6/12/10/12/11/11，极差 12 = 量程全宽**，落地 1/7（判据面；主表面是 2/7，差的一轮是 `r4`：主表 12/0/12 但 `judgeFp=16`）⇒ **同批、同臂、同输入，也读不出率差**。★ 不要拿 `E1` 4/7 当对照：它的 cwd 每轮不同（`exp-state.ts:44`），那是处理差不是纤维差 | 「n=7 不算小，所以能读率」——**轮数不是有效样本** |
| 9 | **货币** | **面值**（token）或**账单**（`$`）；两者在同一批上可以给**相反**的排序（T2 117k vs C30 201k 面值便宜 1.7×，钱几乎相等） | ★ 判「这笔优化值不值得做」：本 lab 实测 `$/Mtok` **0.035–0.170（4.8×）**，所以「省一半 token」可能一分钱都没省 | 「token 少了就是便宜了」——cacheRead 只按 0.003 $/M 计价 |

★★ **九个词不是并列的**：1–3 是**输入身份**（谁+怎么量），4–6 是**坐标**（量的是什么），7 是**读数**，8/8b–9 是**这个读数的外衣**（覆盖 / 有效样本 / 货币）。⇒ 用它们只需要一句话：**报一个数 = 报它落在哪一格 + 它盖了哪些轮、那些轮彼此差多少 + 它用哪种货币。**

★★★ **词 6 的第二个下半句（v14，2026-10-23）：一个「读数」带三个选择，而一次「相等」要两个读数。**
三个选择是：**读哪些数组**（范围）、**什么算一条**（条目）、**怎么聚合**（长度 / 去重集合 / 求和）。
⇒ 判「X 有没有指称」时，两个操作数**只许在被测的那一维不同**；否则它的失败不可归因（会把别的维度的错记到 X 头上），
而且相等式还能被「两处错得刚好相等」骗过（本 lab 实测 2/24 轮）。⇒ 「有指称」写成 `p₁ ∧ p₂`，不要写成 `A == B`。
定义、机制与两个假阳性现场见《等式的两边必须同层》；依据：`work/theory/decl-scope2.py`、`work/practice/runs/decl.jsonl`。

★★ **词 7 有一个附加规则（三项在 notes 族是两项，v12）**：`pin ⊆ matched` 是**这台装置的结构**，不是经验规律——`pin` 只数「真值对里两侧都定位到」的那些，而 `matched` 数「命中的真值对」⇒ 一个对不可能「锚定但没命中」。本 lab 355 轮里 `P(matched=n | pin=n) = 170/170`、零反例，所以 `landing ⇔ pin=n ∧ fp=0`（第三项被第二项的上界吃掉）。★ **边界**：换判据（锚定不依赖命中）就变回三项，别把这条搬到别人的装置上。★ 这条判死一类处方：「先修召回、再修锚定」**不是两步计划**——`pin` 不满时补召回，落地一直是 0（`S1Q1 r0/r6`：`m12/fp0/pin11`）。依据：`outbox/理论-三个通道与一个乘子…md` §5.1、`work/theory/series-cluster.out.txt` A 节。

★★ **词 7 有一个附加规则（合取读数，v13 化简）**：先做**代数化简**——`pin ⊆ matched` 是判据的结构（锚定只对已命中的真值对计数），所以 `pin=|T| ⇒ matched=|T|`，落地其实是 **两项合取** `pin=|T| ∧ fp=0`（全库 515 轮逐轮等价 94/94，`work/theory/nested-gate.py`）。再谈归因：**可归因(j) ⇔ 存在一轮「其它*有效*项全满、只差 j」**；冗余项算进去会把「1 项失败」误判成「2 项」，从而把**可归因**读成**不可归因**。`LANDING2B` 的订正读法：`r0`（`fp=2`）两个有效门同时失败 ⇒ 不可归因；`r1/r2/r3` 只差 pin ⇒ 可归因到 pin，而且 pin 是**可分解门**（`n−matched`=没找到、`matched−pin`=找到没定位）：`r2` 是**纯召回缺口**（`pin=matched=11`），`r1/r3` 是召回+定位。`Q6P3 r3/r6` 仍是干净可归因（`m12/fp0/pin11`）。定义与判据见 `outbox/理论-检查的单位不是决定的单位-六格错配与折向.md` §4.1。★ **边界**：若判据的锚定不要求命中真值（可以对任何报出的对判），三项就回来。

★★ **为什么面值会随轮数平方长、而账单不会**：工具循环里每一轮都要把前面所有轮再读一遍 ⇒ `Σctx = T·S + Δ·T(T−1)/2`（`S`=基准、`Δ`=每轮净增量）。本 lab 实测 `Δ` 中位 2,852 token/轮 > `S` 中位 2,042 ⇒ **第 1 轮之后平方项就主导**，所以「限轮数」是这台装置上唯一有平方效应的旋钮，「瘦身提示词」只买到线性项。★ 定义、样本外检验（hunt 的 292 run：`Δ>0` 100%、「上下文档数 vs 轮号」`R²` 中位 0.93）与三条边界见 `outbox/理论-每轮重读一遍-面值的平方与账单的七成在写出.md`。
★ 边界（这一格最容易搬错）：只在**前缀会被重读、且重读按 1/50 计价**的装置上成立；无缓存计价时 `cacheRead` 并进 `input`，两把尺重新合并。

★★★ **词 9 的第三个下半句（v16，2026-10-23）：「谁是大头」不是装置的性质，是「单价比 × 分量比」——一个可算的阀值。**
上面那句「账单七成在写出」容易被当成装置律。它**是**一个真读数，但它的条件是**能把写出来的不等式**：

```
账单份额是纯函数：share(out) = 0.60·O / (0.15·I + 0.60·O + 0.003·C)
⇒ 两两分界（与数据无关）：
    out > in   ⇔  O > 0.25·I        （单价 0.15/0.60 = 1/4）
    out > cR   ⇔  O > C/200         （单价 0.003/0.60 = 1/200）
    in  > cR   ⇔  I > C/50          （单价 0.003/0.15 = 1/50）
```
★★ **为什么值得单独一个词**：三个单价之比是 **50 : 200 : 1`，所以「写出只占面值 13% 却占账单 74%」不是矛盾，而是两个阀值（1/4 与 1/200）差 50 倍的必然结果。⇒ 拿到一份新读数时，你只需要算一个比 `O/I`，不需要问「这个装置的性质是什么」。

★ 机制/阀值/反例/边界（无台阶计价）见 `outbox/理论-每轮重读一遍…md` §3.6；复算 `work/theory/dominant-term.py` + `dominant-term.out.txt`（0 API；恒等式 145/145 残差 0）。

## 1.5 六个承重词不是新原语——它们是九格里长出来的（v18，补审计 18 号的 DEFECT）

★★★ 审计 18 号判过一条：本页自称「读完这一页，你手上的每一个数都知道该填哪一格」，却**一次都没出现** `清单税`、`元数`、`可压缩`、`缺席`。我照它的法子重数了一遍，缺口比它说的还大：

```bash
for w in 清单税 元数 断言面 前置序 可压缩 缺席; do
  printf "%-6s 份=%s 次=%s\n" $w $(grep -l $w outbox/*.md | wc -l) $(grep -o $w outbox/*.md | wc -l)
done
# 2026-10-25 实跑：清单税 12份/66次 · 元数 21/66 · 断言面 31/119 · 前置序 20/60 · 可压缩 2/25 · 缺席 9/59
# 而同一命令对 00a：六个全是 0
```

★ 但**正确的修法不是给本页再加六个词**——那正好是本书批的「目录化」。正确的修法是回答：**它们是不是新原语？**
如果是，本页就得从九个词变成十五个词，那说明这页的分类是错的；如果不是，本页要给出的是**从九词推到它们的规则**。下面这张表就是那个回答——**六个全是从九格里推出来的，没有一个是新的**。

| 承重词 | 它落在哪一格 | 一句话定义（用九词的词说） | ★ 它判什么死活 | 边界（什么条件下不成立） |
|---|---|---|---|---|
| **断言面** | 词 3（`C`）的**第一行**：`φ` 到底枚举 `P` 的哪些字节 | 判据实际读的那个**容器**，而不是你以为它读的「结论」 | 判「判 0 是产物错还是判据没读到」：同一份产物只做字符串变换，`fp` `16·16·16 → 0·1·0`、落地 `0/3 → 3/3` | 只对**枚举型**判据成立；人读时「形状」几乎不值钱（人不会把排除清单当结论） |
| **清单税** | 词 7（读数）的一个**分量**：`fp = fp_claim + fp_inv` | 「产物里那张**清单/索引/元数据**被断言面读成了断言」贡献的那部分 `fp` | 判「`fp` 大是先分辨认、还是先修产物」：task4 八轮 `fp` 合计 **327 全是清单税、竞争性 fp = 0**（360 行逐条核过）⇒ 先改断言面（0 token），不要去压 `fp` | 只在「意图要求可核对」时有意义——无「不要可核对」的对照臂，所以**不能**推「删掉那句就省」 |

## 7. 章号也是地址：一个谓词验收、五类动作、一张会腐的快照（v23 重写）

★ 为什么这件事要待在定义页：全书有几百次「第 N 章」（`python work/theory/chapnum/chapnum.py`，纯函数，判据冻结在脚本头部）。它看起来像编号，其实是**地址**——读者要在当前位置把它换成「哪一份」。**一个换不出来的号，比不写号更坏**：读者会以为漏了页。

**定义 7（章号可解析）** 位置 `p` 上的「第 N 章」可解析 ⇔ ① 自称「第 N 章」的那一份**在书里** ∧ ② 它在**目录**里有条目 ∧ ③ 号**绑在读者看得见的地方**（H1 或目录条目文字）。三关独立；`①=0` 时 ②③ 不用问。

### 7.1 验收要写成谓词，不写成计数（★ 本节唯一值得搬走的那条规则）

- **验收 = 「每一个出现过的号都落在 A 类」** ⇔ `B = C = D1 = D2 = 0`。
- **不要写「B 类 ≤ 24」或「A 类 ≥ 168」**——这些数是**输入集的函数**：书每发布一次，`book/src` 变一次，同一个命令就出一组新数。实测两次正确读数（同一条命令，相隔一天）：**397 次 / 14 号 / 30 份（A188 B81 C31 D1 96 D2 1）** 与 **428 次 / 15 号 / 31 份（A193 B83 C38 D1 111 D2 3）**。**两个都对**——它们量的是不同时刻的书。⇒ 拿计数当验收线，等于每发布一次就要改一次验收线。
- 这与 §1 词 9 的 v17 是同一个机制的两处：**基数是输入集的函数，份额与谓词不是。**

### 7.2 五类毛病、五种动作（★ 动作是稳定的，计数不是）

| 类 | 意思 | 改法 | 价 | 会腐吗 |
|---|---|---|---|---|
| **A 已绑** | 章在书里，号也写在读者看得见的标题上 | 无 | 0 | — |
| **B 缺绑定** | 章在书里，但号没写在任何读者看得见的标题上 | 目录条目文字加号（1 行） | 0 | 不会（除改号） |
| **C 不可达** | 章在书里，目录点不到 | 目录加 1 条 | 0 | 不会（除目录重排） |
| **D1 缺内容·草稿在** | 自称那一章的**不在书里**，但盘上有成稿草稿 | 过一次发布门，或把这句改成不依赖它 | 0 token 或 1 次发布 | ★ **会**：发布之后 D1 直接变 A/B ⇒ **D1 的数不能当验收线** |
