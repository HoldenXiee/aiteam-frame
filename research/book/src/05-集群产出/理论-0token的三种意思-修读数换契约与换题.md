## 0. 现场：四张表都写着「0 token」，但只有一张在修产物

同一批产物、同一台机器，书里至少有四个「0 token 就能改读数」的现场：

| 从哪里来 | 动了什么 | 读数怎么变 | 变了以后，产物变了吗 |
|---|---|---|---|
| 《观测单元》§1.2 | 判据的**观测单元** `u`：元素=断言 / 地址=断言 / 2-id 探针 | 同一份 388 份产物：J 落地 56、P 62、A 56；`chan-inv-obj` 一份产物 J 判 `fp=16`、A 判 `fp=0` | **没变**，一个字节都没动 |
| 《数与延》§3.1 | 真值集的**层**：层②（12 对）/ 层③（9 对） | 同一批 48 份：**18/48 → 0/48** | **没变**，一个字节都没动 |
| 《前置序》§2-1a | 判据只读声明的断言通道（或把清单拍平成字符串） | `chan-inv-obj` 同一份产物：`fp 16 → 0`、落地 `false → true` | 若走「拍平」：**产物变了**（人手的 0 token）；若走「只读通道」：判据变了 |
| 《验收档位》§1.15 | 断言面的约定（把清单挪出判据读的容器） | 同一批 `open` 产物 0/4 → 4/4 | **没变**（改的是一句约定/一个键） |

★★★ **四个现场，三种性质。** 如果读者把「0 token」当成一个价签，他会得出「改判据总是比重跑便宜」——这句话在这一格里是**反的**：前两个现场即使把读数改到满意，**生产下一次仍然会产出同样的东西**；只有重跑（或人工把清单拍平）会改变下一次的产物。

本章要给的，是一条**能判死活**的区分，而不是一句「要小心」。

依据：`work/architect/snap-odomain-2026-10-20T05-44-49-970Z.out.txt`（388 份，J56/P62/A56）、`work/mapper/rescore-layer.py`、`work/mapper/runs/assert.jsonl`、`work/practice/runs/j2x2.jsonl`、`work/practice/runs/r7.jsonl`

## 1. 定义：一次读数是 `(P, C, T)` 的函数；「0 token」只动后两项

**定义 1（读数）** 记产物为 `P`，**契约**为 `C`（判据怎么读：观测单元 `u`、门槛、形状要求），**题**为 `T`（真值集：语料、谓词、**层**）。一次落地读数是

```
landing(P; C, T) = [ matched(P; C, T) == |T| ∧ fp(P; C, T) == 0 ∧ anchored(P; C, T) == |T| ]
```

★★ 三个自变量是**独立**的：`C` 变（换观测单元）不动 `T`；`T` 变（换层）不动 `C`；两者都不动才是同一份产物的同一个问题。

**定义 2（三类动作）** 对一次失败的读数，能让它变的动作只有三类：

| 动作 | 动的是 | 例 | 下一次生产会变吗 |
|---|---|---|---|
| **重跑** | `P`（让模型再产一份） | `solo`→`solo-fmt`（加 schema，K=4 中位 233k→96k） | **会** |
| **人工改产物** | `P`（人把形状/清单改掉，不重跑） | 《前置序》1a 的「把清单拍平成字符串」 | **会**（这一次的产物变了；下一次取决于你有没有改提示词） |
| **换契约 / 换题** | `C` 或 `T`（判据或真值集） | 换 `u`、换层、改断言面约定 | **不会**——同一个生产者会再产出一模一样的东西 |

★ 三类的 token 价分别是：**重跑 > 0**、**人工改产物 = 0（但有人时）**、**换契约/换题 = 0**。⇒ 「0 token」这句话**没有区分**后两类，而它们的后果完全不同：一个是产物真的变了，另一个只是尺子变了。

依据：《前置序》§2 表 1a/1b、`work/contract/format/runs/site/solo_r{0..3}` 与 `solo-fmt_r{0..3}`（8 轮，前置序 §2 报中位 233k→96k）、`work/mapper/runs/assert.jsonl`

## 2. 判据 v1：一句话分清「换契约」与「换题」——**但它判不了「修读数」**

> ★★ **v2 修订（2026-10-21）**：practice 用本章自己的第 3 行（判据 bug）作反例，证明 v1 的「修读数」格**结构性为空**、且格由措辞定。我在 §2.5 复现它的推理并接受；判据换成「**跑前契约是否定夺**」（§2.5）。v1 保留，因为它**能**判前两格（换契约 / 换题），且它失败的**原因**本身是本章要的机制。

★★ 换契约和修读数的区别不是「有没有花钱」（都不花），而是**旧读数是不是错的**。

**判据 v1（并排可同真；★ 语义判断，不是纯函数——可写死的只有措辞规则）**

> 把新旧两次读数**各写成一句关于世界的自然语言命题**，两句的主语必须是同一批产物 `P`。
> - 若两句**可以同时为真** ⇒ 你动的是 `C` 或 `T`：**换契约/换题**。旧读数没被修正，只是被放到了另一个坐标系。
> - 若两句**互斥**（同一个 `P`、同一个「错」的定义下不可能都真）⇒ **修读数**：旧读数是错的，必须撤回。

**三个现场跑一遍**

| 现场 | 命题 A | 命题 B | 可同真？ | 判 |
|---|---|---|---|---|
| 层② vs 层③ | 「这批产物在层②下有 16 份报满了 12 对且全部正确」 | 「同一批在层③下没有一份落地」 | ★ **能**（层③把 3 对移出真值，A 里的「全部正确」是对层②说的） | 换题 |
| `chan-inv-obj` J vs A | 「这份产物里有 12 条正确的配对」 | 「这份产物里有 16 行未配对清单，被判据 J 读成了 16 条错对」 | ★ **能**（两句说的是同一份产物的不同部分） | 换契约 |
| 判据 bug（假想） | 「这份产物的 `n12\|n38` 是错对」 | 「`n12\|n38` 是真值，判据把它算成 fp 是因为尾随空格没截断」 | **不能**（第一句是错的） | 修读数 |

★★★ **v1 能判什么**：它对「0 token」这个描述**完全不敏感**——它问的是「旧读数错了吗」，而不是「你花了多少钱」。所以它判出：**同一个动作在不同现场可以是三格中的任意一格**。`chan-inv-obj` 的「只读 `findings`」是换契约（J 与 A 可同真）；同一个动作若作用在一份**没有别的对象数组**的产物上，就什么也没改（可同真且完全相同）⇒ 空动作，不是修读数。

依据：`work/mapper/site-assert/chan-inv-obj_r0/report.json`、`work/architect/_addrjudge.ts`、`work/mapper/rescore-layer.py`、`work/edge/entail-analysis.txt`（三档答案集）

## 2.5 ★★★ v1 的死因，与替它上场的判据 v2

### 2.5.1 为什么 v1 的「修读数」格是空的（practice 的反例，我复现）

把 v1 用在**任何一次判据 bug** 上。旧读数出现的身份永远是「**仪器断言世界是 X**」，不是「世界是 X」。而仪器可以错。于是：

```
A = 「旧判据把 n12|n38 读成了错对」（关于仪器，真）
B = 「n12|n38 是真值」（关于世界，真）
⇒ A ∧ B 恒可同真 ⇒ v1 判「换契约」——每一次。
```

要让 v1 判出「修读数」，只能把 A 换成一句关于世界的**假命题**（「`n12|n38` 是错对」）：两句话就互斥了。★ 但那是**把结论写进前提**——「互斥」是我自己选的措辞造出来的，不是现场的性质。

⇒ 一般化（这是本章该记住的一句）：**v1 的输入是当事人在两种措辞里挑一种。凡是判决权在当事人手里的判据，都不是判据。** 同一现场两句话两种格（practice 的逐字演示：中性措辞 ⇒ 换契约，带「因为尾随空格没截断」⇒ 修读数）不是巧合，是 v1 的**定义**。

### 2.5.2 判据 v2：旧读数**当年**是不是一个命题

先补一个定义——它是 v1 缺的那件东西：

> **定义 3（契约 `K`）** 一个读数要成为**命题**，除了判据程序 `C`，还需要一句**跑前成文**的规则 `K`：写死「一条 = 什么（`u`）、真值集的延 = 哪一层（`T`）、门槛 = 什么」。`C` 是实现，`K` 是**含义**。
> ★ 只冻 `C` 不冻 `K`，你冻住的是尺子，不是「量的是什么」。

**判据 v2（三类动作 = 旧读数当年的身份）**

| 当年的状态 | 动作名 | 旧数是命题吗 | 历史怎么处置 |
|---|---|---|---|
| 有 `K`，按 `K` 读，旧读数与 `K` 推出的不同 | **修读数** | 是，且**假** | 撤回；只重算被该实现错误触及的那部分（范围 = 读者偏差 × 覆盖） |
| 无 `K`，或 `K` 对这一情形**沉默** | **换契约 / 换题** | ★ **不是**（是某个未定参数下的一次求值） | 该参数下的**全部**历史数一起作废：彼此仍可比（同参数），与新数**不可比** |
| 有 `K` 且旧读数合法 | 空动作 | 是，且真 | 无 |

**用它把 practice 的反例跑一遍**：`n12|n38` 带尾随空格这一格——若跑前 `K` 写着「一条 = 恰好两个 id」（或判据 spec 写着「trim 后比对」），则旧判据读成 fp 是**违反 K 的假读数** ⇒ **修读数**，与你说不说「因为空格」无关；若 `K` 没写 trim，则当年这一格的合法性**未定** ⇒ 那个「12 条全对」从来不是命题 ⇒ **立法**（换契约），且**该参数下全部历史数不可比**。⇒ 同一个反例，v2 判出两格，且**两格都由 `K` 定、不由措辞定**。

### 2.5.3 为什么 v2 不是「换个说法」，而是能拿去数东西的

因为两类动作在**最容易看的地方长得一模一样**（0 token、fp 变小、落地变高），差别只在**作废范围**，而作废范围是**可数**的：

| | 修读数 | 换契约/换题 |
|---|---|---|
| 变了的数 | 被判据误读的那几份 | 该参数下**全部**份——包括本来就对的那些 |
| 可核的签名 | 变更集中在「读者会错的那种条目」上，其余逐字节不变 | ★ 连**没落地**的份也换了含义（层②→层③：48 份里 **18 份**被 `\|T\|=9` 机械排除——层②落地的每一份都含齐 12 对，而 `T2\T3` 的那 3 对在层③里是 `fp`；它们不是「读错了」，是**题目变了**。★ 旧稿写「31 份」，那是「主表读法 × 旧分子」的混合口径，已被《数与延》v2.1 作废，2026-10-22 订正） |
| 价 | 重算（0 token）+ 未记覆盖的风险 | 重算 + **历史全部标注不可比** + 写 `K`（「写 `K` 的价」本 lab 未测；`entail` 实测的 13.3k/对·次 是**回源判读**的价，不是写 `K` 的价） |

★ 所以 v2 给读者的动作是：**先问「当年那句话写了没有」，再问「变化是不是集中在一种条目上」**。两问都答得出，才叫分类；答不出，诚实的标签只有一个——**未知**（而未知的操作含义是：这批历史数一律不可比，不许拿它做基线）。

### 2.5.4 边界（v2 什么条件下也不成立）

1. ★★★ **`K` 可以事后写得又宽又模糊**——立法权仍在人手里，只是从「措辞」挪到「写 K」。所以 `K` 必须**跑前落盘并进冻结文件**，否则 v2 退化成 v1。★ 本 lab 的实测（四条冻结逐一打开）：`_FREEZE-DECOMP.md5`、`_FREEZE-STATE.md5`、`_FREEZE-2x2.md5`、`J5-FREEZE.md5` 冻的是**判据源码 + 装置 + PREREG**，**没有一份冻一句「一条 = 什么」的契约文本**。⇒ 在这个 lab 里，「修读数」与「换契约」在账上**本来就分不开**——v1 之所以被写出来，是因为这个洞当时没人看见。
2. `K` 与 `C` 由同一个人在同一个窗口写 ⇒ 自证（「我按我写的读」）。需要第三方或对手臂，否则 v2 与 v1 一样没有判决权。
3. 修读数的作废范围靠**覆盖**（哪几份被误读了），而覆盖常常没记（见 00 §3.1 的三处「分子分母不同源」）⇒ 「只重算受影响部分」这句在无覆盖时不可执行。

依据：`work/practice/_FREEZE-DECOMP.md5`、`work/practice/_FREEZE-STATE.md5`、`work/practice/_FREEZE-2x2.md5`、`work/practice/J5-FREEZE.md5`（四条冻结的逐项内容，0 API）；practice 在 `work/signoffs.jsonl` 对本章的保留（语义判断 vs 纯函数，逐字演示两措辞两格）；`work/mapper/rescore-layer.py`（31/48 机械排除的那一列）

## 3. 机制：为什么只有「动产物」能提高落地率，而「0 token」买的从来不是知识

### 3.1 落地率是 `P` 的函数，`C`/`T` 是坐标系

```
landing(·) = ρ( P ; C, T )        ← P 是点，C、T 是坐标轴
```

换 `C`/`T` 只能让**同一个点**落在图上的另一个位置。这不是比喻：`18/48 → 0/48` 的 48 份 `P` 完全没变（§0 表第二行）；`fp 16 → 0` 的那份产物也没有变（§0 表第一行）。所以任何「改完之后落地率上升了」的说法，只要动的是 `C`/`T`，它**不是关于生产的陈述，是关于验收的陈述**。

★ 这是本书反复出现的同一个坑的第三次出现：**「自洽 ≠ 约束」**（《数从哪来》）、**「数买不到延」**（《数与延》）、这里是 **「读数变了 ≠ 产物变了」**。三次都是把「我这边看到的」当成「世界那边的」。

### 3.2 为什么 token 价是 0：因为 `C`/`T` 在盘上

判据是新写的一段纯函数、真值集是一张表，重算一遍不调模型 ⇒ 0 token。**但这只是 token 的账**。

★★ **「0 token」不是契约的性质，是「证据已经在你手上」的性质**（landing 的复算，我接受并把这一列补进 §8）：

```
换契约的 token 价 = N_hist × ( 证据在盘上 ? 0 : 每份回源价 )
```

| | 例 | 实测 |
|---|---|---|
| **舱内** | 只读产物里已有的字节：J→P→A 三种读法都是对同一份 `report.json` 重新解析 | 388 份产物重解析 = **0 token**，388/388 在盘（`snap-odomain…`）；落地 J56/P62/A56 |
| **外** | 要回源：层③的「字面原样可替换」——必须回读 `notes/` 逐字比对 | `work/edge/runs/entail.jsonl` **62 次 / 31 对 / 2 rep = 894,662 token** ⇒ **13.25k/对·次（中位）**、**28.9k/对（两 rep）** ⇒ 一份 12 对 = **160k / 320k**，而一份重跑副本 = **133.6k** |

⇒ **舱外换契约 ≈ 1.0–2.4 份副本/份（逐条回源），和重跑同价档，且价随历史份数线性增长**；★ 但**批量回源 ≈ 0.22–0.51 副本/份（便宜 2–4×）**——所以正确的说法不是「舱外永远比重跑贵」，而是「**舱外的价由组织方式决定**」（`work/edge/NOTES.md` §4.6.3，edge 的自纠：这条原本写成绝对句，已被它自己降级）。

★★ **这一格的边界（读者最容易踩）**：舱内 0 token **不是免费的**——它要求你的判据所需的全部证据**已经在产物里**；一旦判据要的东西不在产物里（层③的字面可替换、行号、跨文件一致性），你就从「0 token」掉进「N_hist × 回源价」。⇒ 判一个 0 token 处方便不便宜，先问一句：**它要的证据在哪？**

### 3.3 ★★★ 为什么「知识价」不是 0：能写出新契约的人，已经知道答案了

| 0 token 动作 | 它省下的 token | 它**必须事先拥有**的知识 | 那份知识的价钱（本书的实测） |
|---|---|---|---|
| 换层（`6+3` vs `6+6`） | 重跑 8 轮的 0.63M | 「层③才是你要的」——必须写成可执行程序 | ★ **本 lab 没测过**；最接近的收据是「**回源判读**」13.3k token/对·次（edge 62 次判读 895k）——**那不是在写程序的价**（v2.1 自纠，见下） |
| 改断言面（清单挪出去） | 重跑 4 轮的 ~0.8M | 「清单不是断言」——必须能说清哪一批条目下游谁复核 | 0（但这是**看到产物之后**才知道的，见 §4） |

## 4. 边界：0 token 的换契约什么时候合法

★★ 换契约本身不是错——错的是**在看过产物之后**换。合法的条件是两条，都可执行：

**条件 1（跑前可独立写出）** 一个没看过这批产物的第三方，能不能用你的契约说明 + 语料，写出同一段判据程序？
- 能 ⇒ 契约是**规范**，换它是合法的（《数与延》§5.1① 的判据就是这一条）；
- 不能 ⇒ 契约是**事后拟合**，它只对你已经看到的这批产物成立。

**条件 2（被移走的条目下游仍可复核）** 问一句：「这批条目如果有一条是错的，谁会在什么时候发现？」
- 答得出人/时点 ⇒ 你不是把税消掉了，只是挪了位置；
- 答不出 ⇒ ★ **你只是把错藏起来了**——这是《验收档位》§1.15 的洗白口子，原文的判别法就是这一句。

★ 两条都过，换契约就是一次**正当的重新验收**；差一条，它就是一次**洗白**。两者的读数长得一模一样（都是 fp 变小、落地率变高），**只有这两条能把它们分开**。

**其余边界（逐条）**

1. **契约没跑前冻结 ⇒ 修读数与换契约不可分**：你无法证明旧数是「错的」还是「问错了」。⇒ 本章的两个判据都以「`C`/`T` 有跑前版本」为前提；没有它，本书 §2 的判据只能判出「不知道」。
2. **换题（`T`）比换契约多付一样东西**：`|T|` 会变（12→9），所以不仅历史不可比，`N` 也换了。⇒ 换题之后，任何「同一个 N」的结论都要重写（《数与延》§1 的 `N` 是 `T` 的投影）。
3. **换契约后可以整体重算历史**（0 token，只要盘上有产物）⇒ 「不可比」不是「不能用」，是「必须整体重置并声明」。★ 反过来：**只要有一份历史产物没落盘，换契约就永久损失了那一格的可比性。**
4. **人工改产物不是免费**：人时没测（第七章 §6-6 登记过这个洞）。它的合法性判据是**内容同延**（改的是形状不是内容）；若改了内容，它是「重跑」的人肉版，读数变化是关于生产的，但要重新证明没改语义。
5. **判据不在你手里时，0 token 那一格不存在**（《验收档位》§5）：下游写死了判据，你只能改形状（花 token）或重跑。
6. **单模型、单语料、n=48/388/32**：本章不主张跨任务族可搬。

依据：`outbox/读者-验收档位-落地率不是一个可迁移的数.md` §1.15/§5、`outbox/理论-数与延-数约束的是格的量不是格的延.md` §5.1、`work/reader6/extensional.ts`
