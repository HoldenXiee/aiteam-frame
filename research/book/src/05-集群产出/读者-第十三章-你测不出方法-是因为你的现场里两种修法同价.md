## 0. 一句话

> **一个方法（或一章书、一条提示词、一道闸）只有在「朴素动作」与「正确动作」分岔的地方才有边际价值。**
> 如果你的现场里两条路都花 0、或者都花 30k，那你测出来的差异不是方法的，是噪声的。
> ★ 这不是"读者测试的技巧"，这是**你自己验收任何改动时都会撞上的同一件事**。

★★ **v4 修订（practice 的挑战成立，但不是它以为的那个变量）：这句话要分两层读，且两层由两个不同的量决定。**

| 层 | 你问的问题 | 决定它的是 | 本批的反例 |
|---|---|---|---|
| **动作/钱层** | 「他会不会花错钱」 | **Δcost**（两条修法的价差）——**这才是下文 `Δcost` 的定义**（§3 ①：朴素那条 vs 正确那条的价） | v4 的 P3：两条修法都是 0 token ⇒ 动作级只差 1 格（15 vs 14） |
| **原因层** | 「他有没有那个概念」 | **判据读到哪一层**（结论 vs 原因）——与价差基本无关 | v4 的 P3：Δcost=0，但原因级差 **4 格**（15 vs 11） |

⇒ 所以准确的说法是：**「同价就测不出」只在动作/钱层成立**；原因层的分辨力由**判据的粒度**决定，不由价差决定。
★ 两层的效应**不能互相顶替**：用原因级差去证明「这本书省钱」是错的（v4/P3 里读者一分钱没多花），用动作级差去证明「这本书没教出概念」也错。
★ 这也是本条律能被判死的地方之一（§6 反例 D）。

## 2. 机制：为什么"同价"就测不出东西

### 2.1 判据只看结论时，「蒙对」和「会」同分

v4 的第三份产物 P3：`findings` 8 对全对，但多带了 `evidence_index`（24 个单 id 对象）和 `coverage`（8 个双 id 对象）。

- 医生的病是：**判据把每一个对象数组元素都当一条断言**，于是 24 个单 id 条目 → 24 个假阳 → 落地 false。**产物没错，尺子把它算成了错。**
- 两个修法：① 删/拍平那两张表（0 token）；② 判据只读 `findings`（0 token）。
- 不读书的读者三轮都给了①：「删掉多余字段，0 token，不用重跑」——**动作对**，理由错（他们说成"schema 膨胀 / 越界自证 / 未要求的字段"）。
- 读书的读者三轮都给②，并说出「24 个假阳来自判据枚举容器」——**动作也对，理由也对**。

⇒ 如果判据只问"动作对不对"，两臂都是 15 分制的 5 分格，**书买 0 格**。要问出差别，判据必须问**理由**（I2 的原因级读法）：这时书买 4 格，不读 11/15。

★★ **这不是判据"太严"，是判据在回答另一个问题**：结论级判据回答"他能不能交付"，原因级判据回答"他有没有那个概念"。**报效应量而不报判据读哪一层，等于不报。**

### 2.2 两种修法同价时，方法本身没有东西可买

P3 的病有两种正确修法，但它们**都是 0 token**。而"不读书"的读者给出的修法**也是 0 token**。⇒ 在这个现场上，读不读书的**账单一样**。

v6 加了一份 P4：`findings` 只有 7 对，第 8 对 `t05|t21` 藏在 `coverage: [{bucket:"退款", notes:["t05","t21"], checked:true}]` 里。

- 用真判据跑（0 API）：`items 8 / matched 8 / fp 0 / landing true` ⇒ **原样就落地**。
- 读书的读者（3/3）：说出「那一对**已经在产物里**，是放错容器，0 token 挪进 `findings`」。
- 不读书的读者（0/3）：三轮都判「P4 漏检 / 不可交」，并把 `checked:true` 读成**假自证**——"检出了又在汇总时丢了"。于是下一笔钱：定向补检 1.5k + 验收 6k；或冲突召回 3 轮 6k；或覆盖对账 3k。

⇒ **代价差 Δcost = 0 对 1–7.5k。** 在这个现场上，"读不读书"直接改账单。读数：I6/I7 **3/3 vs 0/3**。

★ 把两个现场并排看，机制就一条：

```
方法的边际价值 ≤ min( 两条路的代价差 , 判据能分辨的那一层 )
```

P3 把第二项压到 0（两条路同价）；P4 把第一项抬起来（0 vs 1–7.5k）。**同一个方法，一次测出 0 格，一次测出 3/3。**

### 2.3 控制臂手里必须有"真实世界里它本来就有的东西"

v5 的第三个臂：不读书，但**给判据源码**（4119 字符，`parse`/`judge` 逐条照原实现，无注释、无任何"该怎么修"的话）。

结果：原因级 **14/15**（v4 的同臂是 11/15）。三轮都自己读出「`notes.length !== 2` ⇒ fp，24 个单 id 对象 ⇒ 24 假阳」，其中一轮把 `walk()` 里 `val.every(x => typeof x === 'object')` 那一行贴了出来。

⇒ **v4 那 3/3 的差不是书教出来的能力，是判据的实现细节——谁有源码谁就有。** 书的价钱（+9.4k/轮）在这件事上买的是"没有源码的人也能判"，而真实世界里读者**有**自己的判据。

★ 所以读者测试的对照臂设计有一条硬规则：**必须给控制臂它真实世界里本来就有的东西**（自己的判据源码、自己的真值表、自己的历史产物）。不给，你测的是信息差，不是方法差。给了之后剩下的差（v5 的 14 vs 15，那一格是"把判据事实转成*动作与价钱*"）才是方法真正买到的东西。

依据：work/reader7/runs/v4_nobook_r{0,1,2}.md（P3 的三种错理由）、v6_book_r{0,1,2}.md / v6_nobook_r{0,1,2}.md（P4）、v5_judge_r{0,1,2}.md（判据源码臂）

## 3. 三个量：拿到任何一次"我改了 X，效果怎样"上都能用

| 量 | 怎么量（0 API） | 判死的阈值 | 反例长什么样 |
|---|---|---|---|
| **① 代价差 Δcost** | 写出两条路的价：朴素那条、正确那条（轮 × 单价） | **Δcost ≈ 0 ⇒ 这次改动测不出**；Δcost ≥ 1 轮价 ⇒ 有得测 | v4 的 P3：两条都是 0 token ⇒ 两臂同分 |
| **② 判据能分辨到哪一层** | 问自己：判据看的是**动作**还是**理由**？把它写出来（哪一格只认理由） | 只认动作 ⇒ 你测的是"能不能交付"；要有概念，至少一格必须认理由 | v4 原因级 15 vs 11、结论级 15 vs 14 |
| **③ 控制臂手里有什么** | 列一遍：真值？判据源码？上一版产物？ | 控制臂缺了真实世界里有的东西 ⇒ 结果虚高；缺了它没有的东西 ⇒ 假难 | v5：给源码后 11 → 14 |

★ 这三条不是读者测试专用。你给集群写判据时，同样三问：**两条修法的价差是多少？判据只认结果还是也认根据？对照组拿到了它本来该有的东西吗？**

依据：PREREG-v4.md §3（I1–I5 冻结判据）、ANALYSIS-v4v5v6.md §2（两读法的差）、§4.1（I6/I7 跑前写死）

## 4. 读者动作：照这套做一遍要花多少

**判**：你手上的这次对照，是不是"两种修法同价"？是 ⇒ 别用它的结论（不是方法无用，是你的现场没有分辨力，跟"任务在天花板上"是同一堵墙）。

**选**：先花 0 token 把两条路的价写出来（`朴素 = 删字段/人工补 → 0；正确 = 重跑 → 1 轮 × 单价`）。**价差为 0 的那一格，任何方法都买不到分。** 要测方法，就去改现场：加一份"多余容器里装着唯一真对"的产物（P4 就是），价差立刻变成 0 vs 1–7.5k。

**算**：读者测试本身的价——
| 项 | 实测 |
|---|---|
| 一轮（情境 ≈ 7k 字符 + 两章 ≈ 11k） | 29.9–35.2k（v4/v5 各 3 轮中位；v6 的 9 行中位 33.7k、全批极差 29.3–54.4k） |
| 不读书的一轮 | **17.4–30.4k**（三批 15 轮逐轮极差；各批中位 v4 24.4k / v5 18.5k / v6 25.1k，`runs/v{4,5,6}.jsonl`） |
| 只给判据源码的一轮 | 20.5k |
| 6–9 轮一批（n=3/臂） | **0.12–0.28M**，墙钟 3–6 分钟（3 并发） |

**验**：跑前把两件事写死——① 五格（或六格）每格的**读法**（结论级还是原因级）；② **Δcost**（这一格里两条路的价）。跑完只许改读法并**两读法都报**，不许只报对自己有利的那一读。

★ 我在第一版里犯的就是这个错：`PREREG-v4` 的 I2 没写清读哪层，我先按原因级报了 15 vs 11（Δ=4）。同一批原文按结论级是 15 vs 14（Δ=1）。**报高了 3 格，方法是好的，量具放宽了。**

依据：runs/v4.jsonl·v5.jsonl·v6.jsonl（token 与墙钟）、work/practice/runs/r4.jsonl（10.6× 方差）

## 5. 边界（什么条件下这套不成立）

1. **没有真值、也没有 N 的现场**：判据连"动作对错"都判不了，只能判"有没有做"（引文锚、动作日志）。这时三个量都无处落，别硬套（这就是《第八章》的场景）。
2. **一轮就够的现场**：如果正确修法的价差小于一次读数的不确定度（同一 prompt 重跑能差 10.6×，见 `work/practice/runs/r4.jsonl`），Δcost 要按**方差**算，不是按单价算——分母是"一条能判死的读数"，不是"一次调用"。
3. **n=3 只做机制判别**：三批都是 n=3/臂，读数只能读"3/3 vs 0/3"这种方向，不能读率。要报率，≥8 轮/臂。
4. **书的价钱不是常数**：v4/v5/v6 的溢价是 6.5–11.4k/轮（≈两章的字数），换语料规模会变；别把 11k 当"一章的价"。
5. **这条不能反推"书没用"**：它只说明**什么现场能测出书的价值**。在 Δcost=0 的现场，书确实买 0 格；这不等于它在 Δcost>0 的现场也买 0 格——v6 就是反证（3/3 vs 0/3）。

依据：ANALYSIS-v4v5v6.md §3（n=3 的界限）、outbox/读者-第八章-没有真值时怎么判.md、work/practice/runs/r4.jsonl

## 6. 这条可以被判死的地方

1. **反例 A**：找到一个现场，两条修法同价（Δcost≈0），但读书臂仍然稳定多出 ≥2 格 ⇒ 说明方法的价值不在"改账单"，而在别处（比如"不再去花那 30k"这件事本身就是省钱——注意这会把 Δcost 从 0 变成 30k，属于我把度量写错，不是反例成立）。
2. **反例 B**：给控制臂判据源码**之后**，读书臂仍然稳定多出 ≥2 格（在原因级判据上）⇒ 说明书买的不只是契约，还有契约之外的东西（v5 实测只差 1 格：14 vs 15）。
3. **反例 C**：把 I6 的读法从"说出那一对已在产物里"放宽到"最终产物正确"，两臂拉平 ⇒ 说明 v6 的 3/3 vs 0/3 也只是措辞级的差——**这正是我第一版把 v4 报高 3 格的同一个坑**，需要第三方按冻结判据复核。
4. **★★ 反例 D（已成立，这是本版新增、也是这条律最该被读到的边界）：Δcost=0 的现场仍然测出了一个**原因层**的差。** v4/P3：两条修法（删多余字段 / 判据只读主表）**都是 0 token**，Δcost=0；按 §0 的旧写法应判「测不出」，但原因级实测 **15 vs 11（Δ=4）**。⇒ 旧头条只在**动作/钱层**成立；原因层由**判据读哪一层**决定。这也是 §0 v4 把头条拆成两层的直接原因。★ 谁能推翻它：给同一个 P3 现场换一个**只认动作**的判据（结论级），两臂应回到 15 vs 14（Δ=1）——本批已经是这个数，所以「4 格」不能当「这本书省钱」的证据。

依据：`work/reader7/ANALYSIS-v4v5v6.md`（逐格判分与两读法）、`work/reader7/runs/v4_*.md`·`v5_*.md`·`v6_*.md`（21 轮原文）、`work/reader7/judgeForScenario.ts`（v5 judge 臂与 0 API 自测用的判据）、`work/practice/notesTask.ts:371-495`（判据真实形状）

依据：PREREG-v4.md（I2 的原始措辞没写读层）、work/reader7/runs/v4_nobook_r0.md（结论级读法下它其实过）
