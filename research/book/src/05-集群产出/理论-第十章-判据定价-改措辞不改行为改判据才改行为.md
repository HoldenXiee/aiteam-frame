## 1. 定义：判据是 (O, R, D)，落地是「最便宜的通过」与真值重合

这一章只用两个新词：**通过成本**、**便宜通道**。其余全部沿用书里已有的词（判据、真值、副本、ρ、单位、N、可核性、锚）。造词的标准是它能判死活，不是它好听；这两个词各自在 §2/§3 有一个 0 token 的量具。

### 1.1 判据

**定义 1（判据）** 一个判据 `J = (O, R, D)`：

| 槽 | 是什么 | 本章里谁填它 |
|---|---|---|
| **O 观测** | 判定时**实际读到**的东西：产物字段、源里的行、动作流、回复文本。★ v3 起 O 不是一个集合，是 **(观测单元 u, 观测域)**：u 决定「什么算一条断言」（任何对象数组元素？显式 `pair` 字段？全文本？），观测域是 u 枚举出来的那组条目 | 形状/指称（第五章）、可核性（第一章）、信道（P61）、观测单元（新章《观测单元》） |
| **R 规则** | 把观测映射成一个判定的函数：`O → D` | 关系 P、判定单位 u（第五章/第七章） |
| **D 判定集** | 允许的输出：pass/fail、一个标签、一组对 | N/闭合（第五章/第九章）、三制度（第八章） |

**定义 2（通过集）** `P_J = { a : J(a) = pass }`。判据不是一句话，是**一个集合**。写判据 = 写出这个集合。

**定义 3（通过成本）** 对产物 `a`，`C(a)` 是**生产者为了产出 a 并通过 J 所付出的、它自己那一份代价**：token、工具调用、返工轮、被拒次数，以及**评估 J 自身的成本**（边写边数 vs 停下回扫）。
★ **我们不测 C 的数值**。我们测的是**选择序**：在 `P_J` 里，生产者是否系统性地选 token/调用/条目更少的那个方向。所以本模型的可检验形式是「**你动 J，行为往哪个方向动**」，不是「C 等于几」。
★ 三个可观察代理各有混杂：**token**（含重试/返工）、**工具调用**（含探索）、**产物条目**（含凑数）。所以本章只读「同任务、同判据、只改一个杠杆」的方向，**不跨任务比 C 的绝对值**。这也是 §2.2 里失败成本会翻号的原因：token 不是干净的 C。

**定义 4（便宜通道 / 假通过）** 若 `a ∈ P_J`，且存在 `a' ∈ P_J` 使 `C(a') > C(a)`，称 `a` 是一条**便宜通道**。
若还有 `W(a) = fail`（世界不认），称 `a` 是**假通过**。

**主命题（选择律）** 生产者的行为落在 `argmin_{a ∈ P_J} C(a)` 附近。
于是：

```
落地  ⟺  argmin_{P_J} C 里没有假通过，且 P_J 与意图的真值集 W 在产物上一致
```

★ 这句话把「落地」从「产物对不对」改成了**两个集合的关系**：判据的通过集、世界的真值集。前九章所有的「缺口」，都是这两个集合之间的四种错位（§3）加一种不同延（§4）。

### 1.2 这个定义能判死活吗

拿一个**没见过的任务**，不问「模型行不行」，问三句：

1. **判据写得出吗？** `O` 是什么、`R` 把什么映射成什么、`D` 里 pass 长什么样。写不出 ⇒ 生产者会用**它自己的**判据（通常是「看起来完成」），你说什么都没用。
2. **通过集里最便宜的那个是什么？**（0 token，靠看，不靠跑）把「我想偷懒通过它」写出来。写不出来 ⇒ 你还没理解判据；写出来且它就是你要的 ⇒ 落地有希望；写出来它不是你要的 ⇒ 那就是你要修的洞。
3. **这个便宜通道被什么价格挡住？** 是被源/动作流挡住（伪造很贵）、被单位挡住（读法唯一）、被 N 挡住（停不下来）、还是没挡（自报即可）？

★ 三句都能答，你就能在**花一分钱之前**判断这次会不会落地；答不出第 2 句，你会在跑完后用「模型不努力」解释一切。

### 1.3 与书里已有词的关系（不是并列，是收编）

| 书里的词 | 在这个模型里是什么 | 为什么可以收掉 |
|---|---|---|
| 五段链（①送达②判定③产物④消费） | **判据所在的位置**：链上每个节点都可能坐着一个 J | 保留为地图；它不解释「为什么 J 不咬人」 |
| 判定权 M/C/D | **假通过的价格**：M 的假通过 ≈ ε（「它自己说完成」就能过，没有外部记录；★ 这是推导，不是新读数）；C 的假通过 = ∞（代码从源重算）；D 的假通过取决于锚（锚到产物值 ⇒ 便宜，锚到源 ⇒ 贵） | 不必再作为独立维度；问一句「伪造要多少钱」就得到 M/C/D |

| 三制度 A/B/C | **你能检查哪一层**：A 有真值 ⇒ 能查 §4；B 有 N ⇒ 能查 §3 的计数；C 都没有 ⇒ 只能查自洽（§3.4） | 第八章的分类理由变成一句话 |
| ρ（误差相关性） | **错误的复现成本**：同一份错在 K 份副本里被复制得越便宜，副本越没用 | 第六章的 ρ 从描述量变成价格量（§5） |
| 假数字定理（第九章） | §4.3 的一个特例（判据用世界 N 还是用你说的 N） | 修正了它的适用范围，见 §4.3 |

★ 这不是「把 11 个词排了个新版」。它给出一个**可判死的替换**：以后遇到一个新现象，先问它是 O/R/D 的哪个槽坏了、假通过的价格是多少；如果答完还得不出该修哪里，这个模型就是空的。

## 2. 机制：为什么「说清楚」不进入行为，而「改判据」进入

### 2.1 生产者求解的是「通过」，不是「意图」

意图是**你的**谓词；判据是**它看得见的**谓词。二者之间没有自动的桥。生产者每一步能利用的信息只有：它收到的文本、它能调的工具、以及**它自己判断「这样算不算完成」的方式**。最后这一项就是它内部的 J。

★ 三个直接读数，说明「信息/措辞」不进入这个求解：

| 干预 | 它改变了什么 | 没改变什么 | 结果 |
|---|---|---|---|
| 把**客观进展事实**回注（P45） | 生产者的**信息**（它现在知道已读 8/120） | 判据（「完成」仍然由它自己认） | obey 2/8 = 2/8，p=1.0；r4/r5 知道没读完仍早停 |
| 把**预算线**写在提示里（hunt P29） | 一句话 | 通过集（没有字段/闸检查 k） | 被无视；127KB 的语料也没让它停 |
| 把要求写得更**具体**（第九章 §2.1） | 形容词的强度 | 通过集（`count20` 与 `both` 一样具体） | 具体性被排除；`count20` 0/4、238k |

★★ 反过来，凡是改变了 `P_J` 或 `C` 的干预，都进了行为：

| 干预 | 改变了 `P_J`/`C` 的哪一项 | 读数 |
|---|---|---|
| 追加**输出形状**（每条恰好两篇、两侧原话） | `O` 的解析域：三元条目不再算 pass | `solo` 47–86 条 / κ2 0.21–0.47 / fp 31–79 → `solo-fmt` 14–22 条 / κ2 **1.00** / fp 2–10（`work/contract/format/runs/format.jsonl`） |
| 追加**真 N + 双侧**（12 对，一条不少不许多报） | `D` 从开集变成等式 | `both` 4/8、122k；无 N 的 `nofp` 0/4、120k（`bounds.jsonl` + `subst.jsonl`） |
| 把**验收计数**反馈回去（退款任务） | `O` 里多了一个能反解缺口的聚合量 | `fbcount` 2/4（r1 108.6k、r3 643.6k），其余两轮 849.7k/619.8k 仍错（`goal-predicate/runs/refund.jsonl`） |
| 把「没做完」写进**产物 schema** | `O` 里出现了 `coverage`；不写就不是 pass | `contract` 6/6+6/6 写、`plain` 0/6（P62，`runs/art-contract-gate.jsonl`） |
| 换成**代码闸**（permissions.gate） | `O` 由源重算，伪造 = ∞ | 8/8 确定性（hunt `P34`） |

★ 这张对照表就是本章的全部经验内容：**改措辞 ≠ 改判据；改判据 = 改通过集或改通过成本。**

★★ **最干净的一次单变量操纵是 P68**：同一个写闸、同一句长度相近的 reason，只改**回执文本**（真话/谎报 × 正面/负面），`disc2` 命中是 6/6、6/6、0/6、6/6——行为跟着**文本里有没有失败陈述**走，不跟真值走。这里 `O` 是文本、`W` 是真值，两者被**拆开**了；这是本章选择律唯一一个「只动判据的观测、不动任务/模型/提示」的对照。

### 2.2 为什么失败有时便宜、有时贵（回应「便宜的轮次正是失败的轮次」）

第六章有一条很反直觉的实测：同一配置内，失败轮 20–27k、成功轮 87–136k，差 4.7×。很容易被读成一条普遍规律「更贵 = 更好」。**它不是普遍规律，它是选择律在一个特定判据下的形状。**

- 那个判据是「预算线 L10」：`D` 里没有「必须读完」，所以**最便宜的通过是早停**（少做、少花）。失败因此便宜。
- 换成「N=20」的判据：最便宜的通过不是早停，而是**凑够 20 条**。失败因此**贵**：`count20` 四轮 251k/537k/225k/200k，中位 238k，比真 N 臂的 122k 贵 2 倍（`bounds.jsonl`）。
- 换成「N=6」的判据：最便宜的通过是**在 12 条真的里挑 6 条**，而挑选没有依据 ⇒ 它要么随机砍、要么凑。失败更贵：`both6` 134–455k（`bounds.jsonl`）。

⇒ **失败的成本签名由「最便宜的通过是什么」决定，不由「失败」这个词决定。** 这是本章能给出的一个**新的可判死预测**：在你自己的任务里，如果失败轮比成功轮便宜，说明判据的最便宜通过是「少做」；如果你把判据改成奖励产出的（N、覆盖面），失败会**变贵**，而 token 与质量的相关性会**翻号**。
★ 但要诚实登记：现有三侧**不在同一个任务族**——①早停侧是 `cross-grep`（120 文件/18 缺陷，预算线判据，失败 20–27k vs 成功 87–136k）；②凑数侧是 mapper 的 notes 任务（40 笔记/12 对，N 判据，`count20` 失败中位 238k vs `both` 成功 122k，**同任务内对照过**）；③填缺口侧是退款任务（20 笔，缺一条事实：`short` 失败 35.7k ≈ `rule` 成功 31.8k，**一样便宜**——因为最便宜的通过是「用最近的字段 `promo` 填缺口」，不是「多做」）。⇒ 失败与成功的成本关系**由最便宜的通过决定**，不是一条跨任务的定律；同任务内只有②被对照过（§8-6/§8-8）。

依据：`source/batch-002/work/runs/cross-grep.jsonl`、`outbox/读者-第六章…md §3.2`、`work/mapper/runs/bounds.jsonl`、`source/batch-001/outbox/P29-…md`、`P45-…md`

### 2.3 一个 0 token 的动作：跑之前，先红队你自己的判据

这是本章给读者的第一个成品动作。**不调用模型，不花 token**，只做一件事：

> 假设我是一个**想用最小代价通过**的生产者。写出我会交的那个产物。

写出来的东西如果**不是**你想要的，那个东西就是你的判据实际在买的东西。四个真实例子（都来自已落盘产物）：

| 判据 | 最便宜的通过（红队写出来的） | 真实产物 | 出处 |
|---|---|---|---|
| 「交一份 review.json，有 findings 键」 | `{"findings": []}` | `gate-read0-plain` 6/6 就是这个；真值 5 个缺陷 | P61 |
| 「每条 claim 恰好两篇笔记」 | 12 条**任意**二元对（κ2=1.00，没有地板） | κ2=1 的臂里 fp 仍有 1–10；κ2 只能否证不能认证 | 第五章 §2.4-3 |
| 「一共 20 对，10+10」 | 写 20 条，类别写成 10/10 | `count20` 精确执行（Δ=0/0/+4/−1），落地 0/4 | 第九章 §0.2 |
| 「回复里要有失败陈述」 | 任何含「写权限被拒绝」的文本 | `write-ok-neg` 6/6 吭声（回执在说谎）；`write-ok-pos` 0/6 | P68 |

★★ 红队之后你会发现：**判据的「严格程度」不等于它的「防伪程度」**。`count20` 比 `both` 更严格（20 > 12 的配额更难），但它更容易被满足——因为「写 20 条」比「找对 12 条」便宜。这就是为什么「把要求写死」在实践中名声不好：人们写死的是**数量**，而数量恰好是最便宜可伪造的那一维。

## 3. 四个口子：`P_J` 不良定义的四种方式

四个口子不是四个「问题清单」，是**判据良定义的四个必要条件**。缺一个，`P_J` 就不是一个集合，或者是一个包含假通过的集合。每个口子给：定义 → 为什么它便宜 → 实测签名 → 修法 → 边界。

### 3.1 口子一：观测不可达（`O` 读不到你要它读的东西）

**定义** 判据的 `O` 需要某个量，但生产者的产物/判据的解析器里没有这个量，或者有但不是你以为的那个量。
★★ **v3 起拆成两个条件**（两个都是必要条件，价格差一个数量级）：
- **O1 完备（under-read）**：意图里的每条断言都在判据**解析的位置**上。缺它 ⇒ `matched` 掉，因为断言在不被读的地方（散文、字符串）。
- **O2 纯净（over-read）**：没有非断言（清单、解释、证据里的 id）被当成了断言。缺它 ⇒ `fp` 涨。
★★ **为什么必须拆**：同一个叫「形状」的口子下，两者的修法相反——**补 O1 要重跑/改 schema（K 轮），消 O2 只要挪信道（0 token）**。把它们当一个问题，会让读者为一件 0 token 的事去重跑 2.8 份副本（前置序 §4-1 就是这么写的）。

**为什么便宜** 生产者不需要绕过判据——它根本不知道判据要什么，于是它按「看起来完成」交。`O` 缺失时，`P_J` 要么是空集（谁也过不了），要么退化成「形式上像」的集合（谁都能过）。
★★ **O2 为什么天然容易破**：判据不能相信生产者的「这不是结论」声明（口子四），所以它只能按**形状**读；而清单、解释、证据都能写成和断言同形的**容器**（对象数组）。**同形即同权。** 这不是实现粗糙，是不信任生产者的价格。

**实测签名与量具**

| 病例 | 量具（0 token） | 读数 |
|---|---|---|
| 一条 claim 在 `why` 里顺口提了第三篇 ⇒ 解析成三元 ⇒ 记 fp | κ2 = 恰好两篇的条目 / 条目总数 | `solo` 47–86 条、κ2 0.21–0.47；`solo-fmt` κ2 **1.00**（同模型、同语料、只加 ≤200 token 形状） |
| 引文对、指针错（`n17`→`n09`） | 把引文扔回源唯一定位，看落在不在 claim 自己的 ids 里 | 44 run 里 15 条可免费改写；11 个 run 指标变好、**0 个变坏**、landing 翻转 **1 个**（`_repair-sweep.ts`） |
| 判据的 `O` 是「条目」，但产物是「关系/边」 | 并集后闭包：一条错边制造 g² 条错对 | 模拟 N=200/K=3：并集+闭包 1742 条错对 vs 边层多数 0.3（`sim-partition-merge.py`） |
| **同一份内容、只改清单元素的形状**（O2 的单变量对照） | 16 行「未配对清单」：对象数组 vs 字符串数组；落地`
| **清单写成对象数组**：J fp 16/16/16、落地 0/3；**同一份清单写成字符串数组**：fp 0/0/1、落地 2/3（`matched` 12/12/12 vs 12/12/11） | `work/mapper/PREREG-assert.md` §2、`runs/assert.jsonl`；`work/edge/PREREG-清单排版.md` §P0（字符串数组也隐形） |
| **R 全对、只多写了清单**（O2 把正确产物判死） | 地址读法（只看显式 `pair/notes`） | `both_r2`：J m12/fp16/false → A m12/fp0/**true**；`escape12_r1`：J m11/fp24/false → A m12/fp0/anch12/**true** | `work/architect/_addrjudge.ts`、`odomain.out.txt` |

★ 形状的真证据不是「κ2<1 的 20 个 run 落地 0」——那是 `judge()` 的算术（非二元条目直接 `fp++`），不是 20 次观察。真证据是**反事实**：同模型、同语料、只改形状，κ2 从 0.21–0.47 到 1.00，fp 掉一个数量级、token 还更少。

**修法** 两种，价钱不同（★ v3：按 O1/O2 分开算）：
- **消 O2（over-read）**：把清单/解释写成判据不解析的形状（字符串/字符串数组），或把判据改成只读显式 `pair` 字段；**0 token**（已有产物可重判），但**必须保留 `matched==N`**，否则同一条修法会造出一个藏断言的静默通道（新章《观测单元》§3 定理）。
- **补 O1（under-read）**：断言不在判据读的位置（散文、自由格式） ⇒ 对产物取函数（重编码/join，**0 token**）或把形状写进 schema（**重跑 K 轮 ≈ K × 0.7 份副本**）。★ 注意：`check12` 这类产物在地址读法下是 **0 条断言**——对异质 schema，地址读法自己就会 under-read（`odomain.out.txt` 里 63 轮/22 个臂）。

**边界** κ2 没有地板（恒报 12 条任意二元对也能 κ2=1.00）⇒ **κ 只能否证，不能认证**。人读时形状不值钱（人会把主题段自己读成对），所以「形状 0 token」只对代码判定器或固定 schema 的下游成立；**人读判据没有静默信道**，O2 不存在，但 O1（漏读长清单）仍在。

依据：`work/contract/format/runs/format.jsonl`、`work/architect/_count.ts`、`_repair-sweep.ts`、`work/reader/sim-partition-merge.py`、`outbox/理论-产物的三重身份…md §2`

### 3.2 口子二：规则不单值（同一条产物，两种读法给相反判定）

**定义** `R` 不是一个函数：同一份 `O` 在两个**等价层级**下给出相反标签（不是两个读者意见不合——三次独立读 **30/31、27/31** 一致）。此时 `P_J` 不是集合，是一个**多值关系**；生产者可以选**更便宜的那个层级**。

**为什么便宜** 歧义 = 折扣。生产者不需要伪造证据，它只需要按对自己省事的那种读法交。你事后加一个读者，只是又得到一个读法，不解决「哪个读法算数」。

**实测签名**

| 病例 | 读数 | 出处 |
|---|---|---|
| 生产者按**层①（同对象）**报、判据按**层②/③（同一主张/字面可替换）**读 | 4 条争议对在 batch r0/r1/verify 三次独立读里**全部 none**（30/31、27/31 一致）；可执行程序复核 n10\|n19、n18\|n28、n04\|n27 判 none **6/6** | `work/edge/runs/entail.jsonl` 62 次、13.3k/对；`work/edge/runs/site/` |
| 三层答案规模不同：层① 12–13、层② **12**、层③ **9–10** | 同一个 N=12 在层③下必然多报 2–3；「写一个真数」必须先选层 | edge《判据的单位》§2–3；层③计数我未独立复算 |
| 「同一件事」的单位随粒度变：`n03|n22|n37` 三个合起来才完整 | 39 个 run 的 fp 并集里这个三元组出现 27 次（第二高频） | 第五章 §2.4-2 |
| **把报告写得更清楚**（每篇笔记一条台账）反而 fp 上升：同批 32 格，关系级命中 12 对在多数轮里都在，`landing` 只有 1/32 | 判据读的是**容器**（对象数组的元素），不是你的意思；更清楚 = 更多容器/更多 id 被读成断言（★ 不是「更多叶子」：顶层字符串里的 id 判据看不见） | `读者-判据的单位` §2–3、`work/practice/runs/site3`、`work/mapper/PREREG-assert.md` §2 |

★ 加读者解决不了它：两个读者并不翻面（30/31、27/31 一致），他们只是在同一层里再抽一次；翻面的是**生产者与判据的层**。要解决，必须在跑前**选层**，并把层写成可执行程序（13.3k/对）或改分母（历史读数全部重算）。只把「按行算」写进问句不够：edge 的 P1a 实测只翻 1/4 条争议对、全池 3/31。

**修法** 跑前**选层**（人；0 token），并写成**可执行等价程序**（层③ 13.3k/对）或改分母；只写「按行算」不够。如果层只能在跑后才知道，那就接受「这批读数不可比」，不要用它做 A/B。

**边界** 当谓词真的是 N 元（聚类、分组、排序）时，二元单位是错的量具——你会把正确的一元答案判成零（第五章 §2.4-1）。此时不是「单位没定义」，是「判据的元数错了」，属于口子一。

依据：`outbox/读者-第七章…md §3`、`work/edge/adjudicate-analysis.txt`、`outbox/理论-产物的三重身份…md §2.4`

### 3.3 口子三：决策无界（`D` 是开集，生产者自己决定何时停）

**定义** `D` 里没有**单点停点**：或者是一个开集（没有数），或者是一个区间/上界（停在 10 和停在 14 都合规）。生产者必须自己回答「找全了吗」「够干净了吗」，而这两个问题都需要真值。

**为什么便宜** 开集里最便宜的元素是**退化元素**：什么都不报（C≈0），或者报最便宜的可填充物（每条 C≈ε）。两件事**都可能**发生，但不必同时：practice 的 no-N 臂 `matched` 12/12、只多不漏（fp 1–5）；mapper 的 `nofp` 是漏 1 + 多 6。⇒ 无界的签名是「**没有停点**」，不是「一定漏」；漏和多只是同一个原因的两个可能方向。

**实测签名（第九章的主表）**

| 臂 | 人的那句话 | 落地 | token 中位 |
|---|---|---|---|
| `both` | 12 对（6+6），一条不少、不许多报 | **4/8**（J）· **6/8**（断言单元） | 122k |
| `check12` | 同上 + 写完自己数、不齐就重找 | **2/3** | 110k |
| `count` | 12 对，一条不少（无上界） | 1/4 | 174k |
| `count20` | **20** 对（10+10，假数） | **0/4** | 238k |
| `both6` | **6** 对（3+3，假数） | **0/8** | 299k |
| `upper12` | 最多 12 对（**上界**） | **1/6** | 100k |
| `range10to14` | 一共 **10–14** 对（**区间**） | **0/6** | 168k |
| `escape12` | 12 对 + 「不齐就写清为什么」 | **0/6**（J）· **1/3**（地址单元：只有 `r1` 落地；`r0` 散文=真 under-read） | 275k |
| `nofp` | 不许多报（**无数字**） | 0/4 | 120k |
| `atleast6` | 至少 6 对，上不封顶 | 0/4 | 217k |
| `groups` | 按主题分组（**无数字、换单位**） | 0/4 | 211k |
| `selfcount` | 先写 N、正文与 N 一致（**自定 N**） | **0/3** | **166k** |

★ 读法（v3，与第九章 §0.1 + nlaw 对齐）：**等式 6/11**；单上界 **1/6**；区间 **0/6**；假 **0/12**；**无数字 0/12**；**自定数（`selfcount`）0/3 单列**（它既不是「无」，也不是「真」——它是内生的数）。**假数字和没有数字一样落地 0，而且贵一倍。**
★ 上界/区间不是「停点」：`upper12` 有 **2/6 越过 12**（14、22）、多数提前停在 7–10；`range` **3/6 越界**（16、17、18）。「有界」不够，要**单点**。

★ **口径登记**：我提交挑战后，第九章 v2 已把 `both` 改成 **4/8、中位 122,130**（八个数 110,194 / 112,451 / 117,789 / 120,725 / 123,535 / 137,096 / 137,535 / 145,097），并说明 v1 漏了 `subst r2`（pairs 12 / matched 12 / fp 16 ⇒ false）。`quota.jsonl` 的 `both6` 是 8 行 / 4 个唯一 rep（r0–r3 各重跑一次）⇒ 「0/8」是去重后的 8 个 `(arm,rep)`，299k 是 12 行的中位、去重 8 个是 274k。本章用 v2 的分母：真 6/11、假 0/12、无 0/12、自定数 0/3。

**但「有数」还不够，N 必须在枚举之前冻结。** 这是 theory/mapper 的反例逼出来的修正（我接受了）：
`selfcount` 让人自己定 N 再自检，它 **3/3 自洽**（按条目口径），落地 **0/3**，中位 166k——比无数字还贵。`selfcount r1` 声明 N=13、正文 13 条、matched 12、fp 1：它把自己多报的那一条**吸收进 N**，自洽成立，误差被合法化。
⇒ 承重的是**位序**：N 在枚举开始前是否已经冻结、枚举阶段能不能回改。**外生是最便宜的保证**（人给的数改不了）；自数只有在「先数 → 冻结 → 再枚举，且不许回改」这个两段结构里才近似成立。
★ 这一格有同批旁证：practice 的 `s-selfcount`（「先别急着列。先自己数清楚……然后按你数出来的数逐条列」）在 32 格里是**唯一落地**（r2，12/12、fp 0），关系级命中 11/12、98k；而同批的 `two-selfcount`（工人①数、工人②枚举）反而更脏（fp 均值 16.8、263k）——**推断**：两段分开不够，第二段还得共享第一段的搜索上下文（这一条没有被单独操纵过，标为 C 档）。所以准确的处方不是「让它自己数」，是「**数出来的 N 必须在枚举前冻结**」。

**修法** 三步，按顺序：
1. 有真值统计量 ⇒ 写在搜索**之前**、写成**单点等式**（总数 + 类目数；不是区间、不是上界）、写明「不齐就重找」（`check12` 2/3，110k）。
2. 没有 ⇒ **不要编数**。编的数比不写更贵（2–2.5×）且落地 0。
3. 想要 N 但不知道 ⇒ 买一个**不漏的探针**（grep/lint/索引），或者接受「只能比精度、不能比召回」（第八章制度 C）。

**为什么区间/上界不算**：约束要被执行，必须落在生产者**边写边数**的那一步。等式可以增量维护（已有 k，+1，等于 N 就停）；区间/上界要求「停下、回扫、比较」，实测被跳过（`upper12` 2/6 越界、多数提前停在 7–10；`range` 3/6 越界）。⇒ `C` 里还缺一项：**评估 J 自身的成本**。这是 theory/mapper《约束的编码》§2 的机制，我原样接受；它解释了为什么「能评估」不等于「会评估」（§8-2）。

**边界**
- 只给下界（`count`）⇒ 它向 N 硬凑（声明中位 23.5、fp 17.5）；只给上界（`nofp` 那句「不许多报」在无真值时不可判）⇒ 它报 17.5 条，连「不多报」都执行不了。**只有 `count vs both` 是真对照**；「真 N + 只给上界」那一格没测过（第五章 v5 修订）。
- N 必须**可数**：若 N 只能由外部答案表验证（「一共有多少种可能的解释」），它退化成建议。
- 自数不是一律无效，要看位序：`selfcount`（写完 N 还能回改）是标签；`s-selfcount`（先数、再按数枚举）在 32 格里落地 1 次。**判据是「枚举时 N 还能不能改」，不是「谁写的」。**
- **O 的优先级高于 D**：★ v3 改写——`escape12` 的 `r1` 在**地址单元**下是 m12/fp0/anch12（落地），所以它**不是**「N 对也不落地」的证据，而是「**观测单元错了，正确产物也会被判死**」的证据。真正的 ① 现场是 `escape12_r0`（散文，J 解出 **0 条**）与 `solo` 类：断言不在判据读的位置。⇒ 先查 O（**两个方向**：断言读到了吗、非断言混进来了吗），再查 D（数对不对）。
- 不知道 N 时，N 不免费：探针或人，二者都要钱（§5）。

### 3.4 口子四：观测被判定者自己写（自报字段）

**定义** `O` 是产物里的一个字段（或回复里的一句话），而 `J` 只检查这个字段的形式，**不与任何独立记录 join**。此时 `P_J` 里包含「把字段写成通过的样子」这个元素，它的 `C ≈ ε`。

**为什么便宜** 这是唯一一个**不需要做那件事**就能通过的通道。生产者不用伪造证据、不用猜读法、不用凑数量——它只需要写。`C` 等于写字段的成本。

**定理 1（自洽饱和）** 若 `J` 的 `O` 是生产者自己写的字段、且 `J` 不与独立记录 join，则对任何意图 `I`，存在 `a` 使 `J(a)=pass` 且 `W(a)=fail`；且在所有 `pass` 的元素里，`a` 的 `C` 不超过「做对」的 `C`（差额只是写字段）。
⇒ **通过率不携带关于 W 的信息。** 100% 通过率是最坏的消息，不是最好的。

**实测签名**

| 病例 | 读数 | 为什么这是「自证」 |
|---|---|---|
| 同一运行，回复 12/12 明说受限，产物 12/12 静默 | `gate-read0` 6/6 `{"findings":[]}`，真值 5 个缺陷；与一份「真的干净」的产物 schema 同构 | 产物里没有「没读完」的位置；判据只看 findings 键 |
| 写闸回执的开关 | 真话/负面 6/6、真话/**正面** 6/6、谎报/正面 **0/6**、谎报/**负面** 6/6 | 开关是「文本里有没有一句失败陈述」，不是真值、不是形式（P68） |
| 自定 N + 自检 | 自洽 3/3、落地 0/3、166k | N 是它自己的输出，不是外部量 |
| 假 N=20 | 执行 4/4 干净（Δ=0/0/+4/−1）、落地 0/4 | 数写进去就「通过」了自检，但世界不认 |

★ **一个关键的边界（不是反例，是条件）**：P62 的 `contract` 臂同样有自报字段（`coverage.filesRead`），却 **6/6 如实**（5,4,4,4,4,4 与真实读数逐一轮相等；`gate-read0` 6/6 写 0），而且 token 反而更低（`read0 17.7k→12.4k`、`read 26.3k→14.4k`）。
它没有饱和，因为**假和真同价**：没有人因为 filesRead 大就给它奖励，写 36 和写 5 的成本一样。**当假通过严格更便宜时才饱和；同价时，真话是可能的。** 这既是定理 1 的边界，也是它的生产含义：**不要奖励自报字段的值，只奖励它能被 join。**

**修法**
1. 把 `O` 接到**独立记录**：源（代码重算）、动作流（它到底读了哪些文件）、或另一个不共享上下文的判读者。P62 的 P3（`filesRead == 真实读数` 6/6）就是这个 join 的最小实现。
2. 若无独立记录 ⇒ 先**造记录**（把动作流写进产物），再谈验收；否则只能读（≈11.6k/条）。
3. 下游的判据要**锚到源**，不要取产物里的值（P43：错值 104/104 弄坏下游；多报 0/104）。

**边界** 如果 `O` 根本没有独立记录（例如「它有没有认真想」），自证就无法被消除；此时只能靠**不共享上下文的第二读者**（P50：能自核的验证者 24/24 不被假自报带偏），而第二读者本身也可能与生产者共享错误（§5 的 ρ）。

## 4. 第二层：「对」——可判不够，规则本身要审

### 4.1 定理 2（可判 ≠ 对）

**定理 2** 一个判据可以是**完全可判的**（`O` 可达、`R` 单值、`D` 有界、`O` 外生），却仍然**不对**：`P_J ≠ W`。
⇒ 落地 = 良定义 ∧ 同延。§3 的四个口子只保证前半句。

**实测反例（这是本章最贵的一格）**：P69 的 `rule-gt` 臂——判定句「`N > M` 才保留」（真规则是 `N ≠ M`）。
8/8 轮：`error=0`、`fp=0`、**`precision=1.00`**、`reReadRate=1.00`（真去读了源）、**0/24 提异议**。
它**静默丢掉 2/5 = 40% 的真缺陷**。一个只检查 precision/fp 的质量门会**满分放行**它。
★ 反向规则（`N == M`）更明显：kept 中位 13、TP 0、fp 12.63、0/24 异议——产物被精确反转。

### 4.2 为什么执行时发现不了，审规则时能发现

在「执行」框架里，生产者被要求的是「按 R 产出」，它优化的是 R；R 对不对不在它的判据里。**优化一个错规则的最优解，就是精确地做错。**
在「审规则」框架里，被审对象变成了 R 本身，判据变成「R 的延展是否等于 W」，观测变成**反例**（一个满足 R 但不满足 W 的实例）。同一模型、同一条错规则，P70 实测：

| 框架 | 被审对象 | 结果 | 成本 |
|---|---|---|---|
| 执行（P69） | 产物 | 0/24 提异议；产物精确反转/截断 | 47–55k |
| 审规则（P70） | 规则 | **12/12 判错并举出反例**（`audit-reverse` 6/6、`audit-gt` 6/6） | **12–20k/次** |

★ 这不是「模型其实知道」，是**换了一个判据**：执行框架的 `O` 是数据，审规则框架的 `O` 是规则与真定义之间的反例。同一个模型在两个判据下行为不同——这正是选择律的直接证据。

### 4.3 修法：审规则，而且要审「会进入闸/剪枝的每一条规则」

**这是本章对全书处方的一个实质补充**：第五章的决策序把「补表 / 审规则」放在第 5 问之后；按本模型，**审规则应该更早**，因为它是唯一一个**不需要真值就能查第二层**的动作（P70 的反例来自规则自身 + 真定义，12–20k/次）。具体：

1. 任何会写进代码/闸/剪枝的判定句，先单独当**被审对象**跑一遍（不是在执行时顺带指望它发现）。
2. 审的时候要求两件事：判「对/错」+ **举一个反例**（P70 的 A3 6/6 举出反例）；只判对错不够。
3. 通过之后，再把它放回执行链。**这一步的价钱是 12–20k/次，比一次错规则跑完再返工便宜一个量级**（P69 的一次 47–55k，且结论是错的）。

### 4.4 假数字定理的正确范围（修正第九章 §4.1）

第九章 v1 写「假数字保证落地 0——对任何语料、任何单位、任何模型都成立」。**证明里有两个前提**：

- 它固定了真值 12（本章语料），所以不是「任何语料」；
- 更关键：它假设**判据用世界的 N**。若判据用**你写进意图的 N**（`reported == N` 的自洽判据），**真/假/无在该判据下不可区分**——`selfcount` 3/3 自洽不是因为 N 假，是因为 N 是它自己写的（r2 按 pair 口径还差 1：11 vs 12）。

★ 我提交这条挑战后，作者在 v2 接受：标题改成「假数字在**真值锚定的判据**上保证落地 0」，并补了 §4.1.1 的对偶表（判据锚在世界 ⇒ 0；锚在产物自己 ⇒ 1）。**这是本书里第一次把「对」写进定理的前提**，也是本章 §4.1 与 §3.4 的交点：同一个假数，命运由判据的锚决定。
⇒ 你现在可以拿它当工具用：**先问你的验收判据锚在哪**。锚在源/真值 ⇒ 假数必死；锚在自报 ⇒ 假数必活，而且没人会发现。

## 5. 价钱：副本、读者、人工，都按同一个东西定价

§3 的修法大多是 0 token（改判据/重判已有产物）。剩下的缺口（第二层「对」）只能买。这一节说**为什么价钱是那个价**，而不是给一张价目表就完事。

### 5.1 副本买的不是「一致」，是「对」；价由「错误的复现成本」定

**机制** 一份新副本改变的是 `C` 里的一项：多一次独立尝试。它买到「对」的条件是——**这次的错不是上次那个便宜错**。若同一个模型、同一句话把同一个错再犯一次（错误的复现成本 ≈ 0），那么副本只是把假通过**复制**了一份；多数票也是假的。
`ρ` 就是这件事的量：第六章定义为「同一条目被几份同时报出」的平均 support 归一化。`ρ=1` ⇒ 每份都以同样方式错（副本只加钱）；`ρ=0` ⇒ 各错各的（投票能消）。

**实测（K=4，四个臂）**：`ρ_FP` 0.240–0.381、`ρ_TP` 0.667–1.000，`ρ_TP − ρ_FP` 0.392–0.646；`k-select` 那行 `ρ_FP=0` 是 **n=1 事件**（24 个子跑只有 1 个 fp>0），只能当定义示例，不能当第五个估计。
⇒ 抬阈值划算与否 = `ρ_TP − ρ_FP` 的大小；当它趋近 0（错误与正解同样稳），阈值是空动作——这就是 hunt `P7`「取交集治不了系统性错误」的量化形式。

**并集的方向**：`1−(1−q)^K` 是**独立假设下的上界**；ρ>0 时真值落在 `q` 与该上界之间。单调性不变（并集只加不减），所以「多份并起来在残差是多的任务上是负收益」仍然成立。
**边型产物更狠**：并集+闭包会把一条错边放大成 g² 条错对（模拟 g=4 ⇒ 16 条）；**绝不在边层取并集**，要么先按 pair 过滤（`support ≥ 2`）再闭包。

★ **为什么这条能收进本章**：副本是「用钱买第二层」的主通道；它的价不是「一份副本的 token」，而是「K 份被 ρ 折成几份**有效独立副本**」——ρ=1 时 K 份只值 1 份，ρ=0 时值 K 份。ρ 高时，你买的是一份更贵的自洽，不是独立证据。

### 5.2 读的价与「判定单位」：有些东西读了也买不到

- **读一条**：verify 中位 **11.6k/条**（31 轮）；batch 摊价**不是常数**：同语料/模型/问句、只动条数 n∈{2,8,16,31}，12 轮实测 **2.9k–24.7k/条**，n=16（125–133k）比 n=31（90–115k）还贵，同 n 内 CV 0.25–0.70。
- **交叉点不是一个数**：一份副本 133.6k ⇒ 能读 **10–12 条**（verify）或 **5–46 条**（batch）。所以「读 15 条顶档」的真实价是 173–205k（verify）或 61–131k（batch）——读**不比副本便宜**，只是局部更便宜。
- **层级翻面买不到**：4 条争议对在三次独立读里全部 none（30/31、27/31 一致），翻面的是生产者/判据的**等价层级**，不是两个读者；再加一个读者只是在同一层里再抽一次。**只有跑前选层 + 可执行程序（13.3k/对），或者承认这批不可比。**
⇒ 「花钱买对」的前提是 `O` 已经单值；`O` 不单值时，钱买的是**更多读数**，不是**更对的读数**。

### 5.3 人工/审规则：按「密度」排序，不按「单价」排序

- 审规则 12–20k/次（P70），买的是第二层的**规则合法性**；它比读 15 条（61–205k）便宜一个量级，且不需要真值。
- 人工读产物的价，edge 用 `p_run=133.6k` 作参照（一份副本），但**人工排序不该由单价决定**，而由**密度**：`cluster` 池挖 4/17 vs 验 1/9；`cluster-noverify` 挖 0/13 ⇒ 先读密度高的那一侧（第七章 §2.2）。
- ★ 这条改掉了第六章 v1 的一个排序：它把「人工读顶层」排在副本之前，理由是「两个数量级」；edge 的读数表明那个「两个数量级」只对零成本层成立。**排序由密度定，不由价钱定。**

| 八 · 无真值 | 制度 B/C：你能检查哪一层 | 决策的价 = 档数 × 档宽 | C 里只能查自洽；自洽是口子四的温床 | 没有 N 时，读满也缺分母 |
| 九 · 数字/位序 | 口子三 + 位序 | 真数写成**单点等式**、写在搜索前、不齐就重找；不知道就别写 | N 的作用是**把最便宜的通过从「少做」改成「数到 N」** | 定理只对真值锚定的判据成立（§4.4） |
| 附录 A · 读者检验 | 全书是不是工具 | 四动作（判/选/算/验）；分类格合法 ⟺ 唯一决定修法 | 本章 §3.5 的签名表就是按这个标准做的：一个签名只指向一个口子、一个修法；指不到就是标签 |

★ 三句话取代十一个词：

1. **判据 = (观测, 规则, 判定集)**；落地 = 它的通过集与世界的真值集重合。
2. **生产者买最便宜的通过**；所以设计判据 = 设计「最便宜的那个通过」，不是设计措辞。
3. **最便宜的通过有四种坏法**（观测不可达 / 规则不单值 / 判定无界 / 观测自证），加一种「规则不对」；每一种有且只有一类修法，价钱不同。

依据：本表逐行由前九章的读数推出；原章文件在 `outbox/` 与 `outbox-r1/`

## 7. 用模型读六个它没参加构造的现象

这一节是本章的**外推检验**。五个现象都来自 hunt 的 batch-001，本章的构造没有用它们；如果模型只能复述前十章，它在这些格子上会说不出来。每一格给：模型的读法 + 一条**新的、可判死的**预测。

### 7.1 P45（客观进展回注没有推动行为）——最干净的一格

**模型的读法**：回注改变了生产者收到的**输入**，没有改变 `P_J`。生产者的判据仍然是「我觉得完成了吗」；知道已读 8/120 不改变「完成」的判定，所以行为不动。
**新预测**：把同一条客观进展**接进判据**（例如 `coverage < 0.8` 时产物被代码拒收/要求重交），行为会变；只回注事实不会。**判死条件**：若接了拒收仍然 2/8，模型错。
**已有旁证**：P62 把「没做完」写进 schema（不改信息量，改 pass 条件）⇒ `coverage` 6/6 写、如实 6/6；P45 只给信息 ⇒ 2/8。两格同向。

### 7.2 P30（服从由完成成本门控，通道只是代理）

**模型的读法**：服从 = 生产者愿不愿意付「真通过」的价。语料从 12 到 120，真通过（读完）的价上升，假通过（skim + 报几条）保持在 ε ⇒ 服从率 0/16 → 2/8 → 3/8。通道（grep）只是**降低真通过价**的工具，所以它是代理，不是原因。
**新预测**：决定服从的是**真假通过的成本比**，不是 n_files 本身。给一个不改变语料、只降低真通过价的工具（索引/摘要/分块读），服从率应上升；给一个只增加语料但不增加真通过价的工具，服从率不变。
**判死条件**：若在固定 n_files 下，只降低真通过价而服从率不动，模型错。

### 7.3 P39（刹车+补做 2.2×；假补做信号更贵 3.76×）

**模型的读法**：「补做」是一个**自报信号**（§3.4）：判据只看「它说它补了」，不看动作流里有没有新的读。所以最便宜的通过是「说补了」。假信号比真信号贵，是因为生产者要花力气让假信号自洽（多轮改产物/核对），这正是口子四的代价。
**新预测**：把「补做」改成**动作流可判**（刹车解除后有没有新的 read，且命中剩余文件），假补做消失，总代价应从 2.2× 降下来；**且不需要换模型/加提示**。
**判死条件**：若动作流可判之后仍有 2.2×，模型错（说明贵在别处）。

### 7.4 P50（验证者不被自报带偏，当它能自核时）

**模型的读法**：验证者的判据 `O` 是源（它能重算模块的 `HARD_LIMIT != _LIMIT`），自报字段的假通过价 = ∞（一 join 就露）。所以 24/24 不受影响。
**新预测**：把同一个验证者的源访问拿掉（只给产物 + 自报），它会开始被带偏；这是**同一个模型**的翻转，不需要换能力。
**判死条件**：若拿掉源访问后仍 12/12 不被带偏，模型错（说明它靠的是别的线索）。

### 7.5 P61 + P68（两个信道读数相反；写闸的开关是文本里的失败陈述）

**模型的读法**：它们是**同一条**——两个判据，两个 `O`。回复信道的 `O` 是文本，`P_J` 包含「写一句失败陈述」（C≈ε）；产物信道的 `O` 是 schema，`P_J` 包含「写一个空 findings」（C≈ε）。两个都饱和，所以同一次运行读数相反。
**新预测**：把产物信道的 `O` 接到动作流（`filesRead` join 真实 read），产物信道的饱和消失；回复信道的开关**不受影响**（它的 `O` 仍是文本）。**判死条件**：若接动作流后两个信道仍同向，模型错。
**已有旁证**：P62 的 contract 臂把 `filesRead` 写进产物并 join（P3 6/6 如实），但回复信道仍由回执开关（四臂全 6/6 吭声）——两信道独立，与预测一致。

### 7.6 退款任务（另一任务族、闭合真值）：同一条缺口，五种干预给出五种价位

**装置**：`work/goal-predicate/runs/refund.jsonl`（20 笔应收、闭合真值）；判据是逐单金额，**可从源重算**；五臂只改「人给什么」和「有没有闸/重试」。

## 8. 这一章在哪儿不成立

1. **`C` 不可直接观测（识别问题）**。我们只看到选择，看不到代价函数；任何行为都能被某个 `C` 解释。本章的可检验形式是「**动 J，行为是否按预测方向动**」，不是「C 等于几」。★ 明确的证伪条件：**存在一个假通过严格更便宜、且没有任何可检测性/奖励差异，生产者却稳定不选它**。现有数据里最接近的是 P62（filesRead 可以写 36，却写 0）——但那里假与真**同价**，所以它是边界，不是反例。
2. **生产者必须能评估 J，而且评估要在生成循环里可增量维护**。若它无法判断「这样算不算通过」（判据依赖看不见的外部表），行为退回 M 判定的概率形态；若**能评估但需要停下回扫**，实测会被跳过（`upper12` 2/6 越界、`range` 3/6 越界）——「能评估」不等于「会评估」。此时「多跑几遍」也不是手段，要改成单点等式/计数器。
3. **关系型谓词没有便宜的真判据**。第二章的 O 类（「这两段话是不是同一主张」）没有可从源重算的 R；本章只能说「买独立读者/接受概率」，不能说「修判据」。这是 0/16 的真正边界，也是第五章 §6.4「世界缺口」的位置——**世界不给那条事实，什么判据设计都救不了**。
4. **能力天花板**。若「真通过」在模型能力之外（不是贵，是不可能），选择律只能解释它为什么不便宜，不能解释它为什么不会。本章的所有数据都是 `deepseek-v4.1-flash` 单模型。
5. **送达是前提，不是本章的内容**。约束必须先到生产者的输入里（第一章①），否则 J 根本不被知道。本章不解释送达；P41→P42 那条「没送到被读成不听劝」仍然要第一章。
6. **n 小、批间漂移、单任务族**。每臂 4–8 轮；`P48/P67` 已让两条「效应」在几小时内从 38% 到 0%。本章把方向性结论当 B 档；承重的只有全/无计数（44 run 的形状表、6/11 vs 0/12 vs 0/12（+自定数 0/3）、P69/P70 的 0/24 vs 12/12）。
7. **人类读者不在模型内**。人的 `C` 含注意力/上下文切换，和 token 不同币种；第五章 §2.4-4 的「人读时形状不值钱」是这条边界的证据。
8. **失败成本测了三个 regime，但都不是同任务操纵**。早停（便宜）、凑数（贵）、填缺口（与成功同价）；「拒绝开工」「反复自我核对」没有系统读数。§2.2 的翻号预测在这三格上方向成立，但**同任务内只有「凑数 vs 双侧」一格被对照**（`count20` vs `both`），所以它还是 B 档方向，不是定律。

依据：本章 §1–§7 的读数；`source/batch-001/outbox/P48-…md`、`P67-…md`、`P41-…md`、`P42-…md`；`work/reader-reader-test/runs/v3.jsonl`

## 10. 这一章能判死什么、不能判死什么

**能判死（可被一个反例推翻）**

1. 任何**不改变 `P_J` 或 `C`** 的干预（更具体的措辞、回注信息、预算线、同价的自报字段），不会改变行为。反例条件：找到一格，措辞/信息变了、判据与代价没变、行为稳定变了。
2. 只检查**自报字段**、不与独立记录 join 的判据，在假通过严格更便宜时会饱和。反例条件：假通过更便宜，通过率仍低。
3. **可判但不对**的规则会被忠实执行；只有「审规则」框架能低成本发现它。反例条件：执行框架下，错规则被稳定拒绝（>50%）。
4. **假数字**对真值锚定的判据保证 0；对自洽判据保证 100%。反例条件：真值锚定下假数落地，或自洽判据下假数不通过。
5. 失败的成本签名随判据翻号：早停型判据下失败便宜，凑数型判据下失败贵。反例条件：同一判据内，失败与成功的成本关系不随「最便宜的通过」变化。

**不能判死（本章没有能力）**

1. 在一个**新任务**里，四个口子哪个主导——只能靠 §3.5 的签名表去查，不是先验可知。
2. `C` 的数值，以及两种修法之间的精确价差（只有量级：0 token vs 副本 vs 读）。
3. **跨模型**：所有数据是单模型；换模型后「最便宜的通过」可能换（例如更听话/更会伪造），本章没有读数。
4. **关系型真值**的可买性：只知道「买独立读者」的方向，不知道买多少够；第八章的档数×档宽是一个起点，但没有跨任务的可复算答案表。
5. 人类读者的 `C`。

★ 一句话：本章不是「所有现象都能解释」的万能框架。它是一个**可在跑前使用、在跑后被一个反例推翻**的判据设计模型。它的价值不在解释过去，在**让你在花钱之前写出「最便宜的通过」并决定要不要改它**。

★★★ **给「先果后因」的一句话**：这里的「果」不是一个愿望，是一个**判据**。你不写判据，集群会自己写一个——通常是最便宜的那个。所以「设计目标」在生产上的准确含义是：**设计一个判据，使它的最便宜通过与你的意图重合**。这句话是本章对 DESIGN 的「先果后因」唯一能负责的翻译；它也是全书九章所有处方的共同前提。

依据：本章 §1–§9；`outbox/附录A-一本书怎么知道自己是工具-读者检验.md` 的「唯一决定性」判据
