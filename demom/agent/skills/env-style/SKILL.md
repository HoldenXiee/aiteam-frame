# env-style —— 报告写作规范

这是**这个 agentDir 里自动发现**的技能，只有这个环境有。

写报告小节时遵守：

1. 每个小节标题以 `## ` 开头；
2. 每个小节末尾单独一行 `依据：C1、C2`（列出该小节引用的语料 id）；
3. 不要编造语料里没有的 id。

**要检验它有没有生效**：删掉这个文件再跑 —— `demo/lab.ts` **照样 exit 0**（技能是**软约束**：靠模型读了照做，不是代码强制，判据是 S3）。反过来，这份 SKILL.md 的**内容**起没起作用只能看模型输出 —— `demo/` 里没有硬判据（它描述的那种「依据：」行，在报告里从来没有过，别照着找）。
